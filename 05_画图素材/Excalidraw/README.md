# Excalidraw 可视化

本目录用于知识库的卡片式视觉导航。

- `系统架构设计师知识库.excalidraw`：全局章节看板。
- `计算机系统基础知识看板.excalidraw`：第2章 5 个真实目录的紧凑总览。
- `计算机系统基础/01_计算机组成与体系结构.excalidraw`
- `计算机系统基础/02_操作系统.excalidraw`
- `计算机系统基础/03_计算机网络.excalidraw`
- `计算机系统基础/04_计算机软件与语言.excalidraw`
- `计算机系统基础/05_多媒体.excalidraw`
- `信息安全技术知识看板.excalidraw`：信息安全技术 5 个真实目录的紧凑总览。
- `信息安全技术/01_密码学与PKI.excalidraw`
- `信息安全技术/02_身份认证与访问控制.excalidraw`
- `信息安全技术/03_网络与通信安全.excalidraw`
- `信息安全技术/04_应用安全与攻击防护.excalidraw`
- `信息安全技术/05_安全架构治理与可信.excalidraw`

规则：

- 看板层级必须优先镜像仓库真实目录。
- 目录总览只展示子目录，不把所有原子知识点塞进一张超宽画布。
- 详细看板只展示对应目录中的知识点。
- 每个知识点只绑定一个 Excalidraw link：**标题文字本身是链接**，背景不绑定。查看模式直接单击标题跳转；编辑模式使用 `Cmd/Ctrl + 单击标题`。
- Markdown 是结构与内容的事实源，Excalidraw 负责视觉导航。
- 默认卡片布局、0 条无意义连线。
