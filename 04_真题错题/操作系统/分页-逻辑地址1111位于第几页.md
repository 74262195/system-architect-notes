# 分页：逻辑地址 1111 位于第几页

## 题目

分页系统页面大小为 **512B**，某逻辑地址为十进制 **1111**。该逻辑地址位于哪一页？

- A. 0
- B. 1
- C. 2
- D. 3

## 我的错误答案

**B**

## 正确答案

**C**

## 我为什么错

没有先把每一页对应的地址范围列出来，并且对“页号从 0 开始”还不够牢固。

页面大小为 512B，因此：

- 第 0 页：0 ~ 511
- 第 1 页：512 ~ 1023
- 第 2 页：1024 ~ 1535

地址 **1111** 落在 **1024 ~ 1535** 之间，所以位于 **第 2 页**。

## 正确题干关键词

- 页面大小：512B
- 逻辑地址：1111
- 求：页号

## 下次看到什么词应该想到它

看到“**页面大小 + 逻辑地址 + 求页号**”，先想：

> 把逻辑地址按页面大小切成一段一段，页号通常从 0 开始。

## 最简记忆点

> 512B 一页：0~511 是第0页，512~1023 是第1页，1024~1535 是第2页。
