# 软考真题错题索引

> 用于整理真题、错题、错因分析和复训记录。

## 待复习错题

````markdown
```dataview
TABLE chapter, topic, difficulty, wrong-reason, correct-keypoint
FROM "04_真题错题"
WHERE type = "错题"
SORT difficulty DESC
```
````

## 错题分类

| 分类 | 说明 |
| --- | --- |
| 概念混淆 | 两个知识点记混 |
| 关键词没识别 | 题干线索没抓住 |
| 计算错误 | 公式、代入、单位错误 |
| 流程遗漏 | 步骤不完整 |
| 案例表达弱 | 知道但写不出来 |
| 论文素材不足 | 没有项目背景或论据 |

## 复盘要求

每道错题都要回答：

1. 我为什么错？
2. 正确题干关键词是什么？
3. 下次看到什么词应该想到它？
4. 是否需要补一张图或一个表格？
