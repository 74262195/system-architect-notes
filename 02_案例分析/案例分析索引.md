# 软考案例分析索引

> 用于整理案例分析题、答题框架、案例图和错因分析。

## 常用答题框架

### 架构方案选择题

1. 先判断业务目标。
2. 再判断质量属性：性能、可用性、安全性、可修改性、可扩展性。
3. 对候选架构逐项比较。
4. 给出最终选择并说明理由。

### 数据库设计题

1. 找实体。
2. 找关系。
3. 画 ER 图。
4. 判断范式。
5. 说明主键、外键和约束。

### 安全设计题

1. 识别资产。
2. 识别威胁。
3. 选择安全机制。
4. 说明部署位置。
5. 说明审计和应急。
