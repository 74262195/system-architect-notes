# 考前速记与模块复习总纲

## 运行时必读

按顺序读取当前 main 上的规则文件（本技能不复述结构与验收条款）：

1. `AGENTS.md`（含复习材料落盘位置的硬约束）
2. `prompts/00-全局写作规范.md`
3. 全章考前速记 → `prompts/50-考前速记生成.md`；模块复习总纲 → `prompts/55-模块复习总纲生成.md`
4. 需要教材证据或解释深度判断时 → `prompts/65-教材证据与笔记校验.md`

## 执行要点

- 只从**已审核的原子卡与章节知识库**提炼，不引入未经验证的新结论、新出处、新数字。
- 复习材料不是新的知识事实源：与原子卡冲突时以原子卡与教材证据为准，并回头修正复习材料。
- 速记与总纲职责分离，不要把总纲写成第二份速记，也不新增重复首页 / MOC / 知识地图。
- 易错点写“为什么容易错”，不要写成绝对化口诀；公式保留变量含义、单位与适用条件。
- 模块总纲落在仓库既定位置（以 `AGENTS.md` 为准），并镜像真实“章节目录 → 模块目录”层级。

## 交付与校验

- 在 Vault 根执行 `node scripts/check-vault.mjs`。
- Git 交付按 `AGENTS.md`；除非用户明确要求，不自动 commit / push。
