# 历年真题解析与索引

## 运行时必读

按顺序读取当前 main 上的规则文件（本技能不复述条款）：

1. `AGENTS.md`
2. `prompts/00-全局写作规范.md`
3. `prompts/60-历年真题解析与索引.md`（事实来源、标准化、去重、映射、频次的唯一真源）
4. `prompts/65-教材证据与笔记校验.md`

## 执行要点

- 输入是**真题资料**，不是原子笔记正文：不套用原子卡的故事写法，不为好看改写题干事实。
- 不杜撰真题出处、年份、答案、分值或官方章节编号；证据缺失时显式标记待核验。
- 加工前先查既有标准化产物与映射，避免重复映射或改写既有结论。
- 真题与笔记的映射只建立真实存在的目标；改动被引用的笔记时同步更新真题侧引用。
- 涉及抽文本脚本时，先看 `scripts/` 现有脚本与 `历年真题/AI题库/` 的现状，复用而非另起一套。

## 交付与校验

- 在 Vault 根执行 `node scripts/check-vault.mjs`，确认索引链接可解析。
- Git 交付按 `AGENTS.md`；除非用户明确要求，不自动 commit / push。
