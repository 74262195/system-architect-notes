# RC1-05 身份访问自测呈现与数据库索引状态修复

## 信息安全路径

沿 [[身份认证]] → [[访问控制基础]] → [[DAC自主访问控制]] → [[MAC强制访问控制]] → [[RBAC基于角色访问控制]]，并读 [[Kerberos认证]] → [[单点登录SSO]] 的自测段。认证和授权的角色、三种访问控制策略、票据与 SSO 的正文判据已有可读落点。本批发现同模块六篇自测都使用外层 `> [!question]` 包住多题，答案再嵌套为二级 callout；题干与答案的阅读入口不符合当前通用写作规范。

已对六篇逐篇做最小呈现修复：题干普通展开，每题紧跟一级 `> [!answer]-` 折叠答案；原题、答案与解析均保留。修复前后共 **15 题、15 个答案**。三篇原来缺少 `review_status` 的学习笔记已补为 `待复习`，其余三篇继续保持 `待复习`。这只完成 Markdown 结构核验；本批未在 Obsidian 主题中目测折叠渲染，不能把脚本通过写成视觉验收。
