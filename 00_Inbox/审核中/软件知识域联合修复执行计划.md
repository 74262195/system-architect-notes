# 一、这次修复的核心目标

这次不能只做到“把 UML 等已知缺口补上”，而要同时修复两层问题：

## 1. 单篇教学闭环

解决：**这一张笔记能不能真正学懂、真正用于做题。**

固定检查六个动作：

1. 承接与定位；
2. 具体问题；
3. 直接答案；
4. 核心机制；
5. 考试动作；
6. 收口与下一站。

一句话：

> **教学闭环保证“这一张学得懂”。**

## 2. 章节覆盖闭环

解决：**该学的有没有漏，已有文件是不是真的承接了大纲。**

固定链路：

> 大纲全集 → 大纲原子项 → 稳定 Atom ID → 主事实源 → 正文具体落点 → 教材深度 → 真题考法 → 覆盖状态 → 反向检查

硬门槛：

- 第一轮结束：`unmapped = 0`；
- 最终完成：`partial = 0`；
- 合法状态只能是 `covered / link_only`；
- 假覆盖 = 0；
- 重复主事实源冲突 = 0；
- 每个 `link_only` 都必须指向有效且已经 `covered` 的主事实源。

一句话：

> **覆盖闭环保证“这一章没有漏”。**

最终原则：

> **覆盖闭环决定学什么，教学闭环决定怎么讲懂，三轮审核决定是否真的完成。**

## B. 软件工程
