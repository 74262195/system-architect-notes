### 两层闭环的固定理解

**单篇教学闭环：**

> 承接与定位 → 具体问题 → 直接答案 → 核心机制 → 考试动作 → 收口与下一站

回答：**这张笔记能不能真正学懂、拿来做题？**

**章节覆盖闭环：**

> 大纲全集 → Atom 原子化 → 主事实源 → 正文具体落点 → 教材/真题核验 → 正向反向检查 → `unmapped=0` → `partial=0`

回答：**该学的有没有漏？**

### 为什么以前仍会漏

旧规则虽然已经强调“大纲 → 真题 → 教材 → 当前笔记”，但旧审核记录没有强制形成“**每个大纲原子项 → 正文具体段落**”的逐行矩阵，容易出现：

- 有上位主题就推断下位项已覆盖；
- 文件存在就推断正文完整；
- 一张卡教学质量很好，就误认为整章范围也完整；
- 跨章节只是提到术语，却没有登记唯一主事实源。

本次不再添加“不要漏 UML”之类特例，而是用当前新规则直接重建事实基线。

- `covered`：已有可独立阅读的真实正文，并达到当前 Atom 的最小考试闭环；

- `link_only`：本章不是主事实源，本地定位后链接到另章已经 `covered` 的唯一主事实源。
