> **教学闭环**负责“一张卡是否真正学得懂”；**章节覆盖闭环**负责“该章应该学的是否全部有真实落点”。两者不能互相替代。

# 一、批次 1：规则闭环核验结论

当前 `main` 中的规则已经形成完整“两层闭环”。批次 3 又根据用户对 UML 样稿的直接反馈，把 `prompts/00-全局写作规范.md` 的教学要求进一步明确为：

> **具体场景/对象 → 发生了什么问题 → 大白话一句话答案 → 正式术语/教材口径 → 考试动作。**

抽象定义即使事实正确，如果零基础读者第一遍仍需再次“翻译”才能懂，也判为教学未闭环。

| 规则 | 当前职责 | 结论 |
| --- | --- | --- |
| `00-全局写作规范` | 单篇最小教学闭环 + “先形成具体画面” | 已强化 |
| `10-原子考点卡生成` | 从矩阵 `unmapped / partial` 领取任务；一卡一主问题 | 保留 |
| `20-章节检查与重构` | Atom ID、覆盖矩阵、正向/反向检查、唯一主事实源 | 保留 |
| `65-教材证据与笔记校验` | 大纲 → 真题 → 主教材 → 当前正文具体落点 | 保留 |
| `66-章节三轮审查` | 第一轮 `unmapped=0`，最终 `partial=0` | 保留 |

固定理解：

> **单篇教学闭环**：承接与定位 → 具体问题 → 大白话直接答案 → 核心机制 → 考试动作 → 收口与下一站。
>
> **章节覆盖闭环**：大纲全集 → Atom → 主事实源 → 正文具体落点 → 教材/真题核验 → 正向反向检查 → `unmapped=0` → `partial=0`。

# 二、状态定义与当前统计

## 2.1 状态定义

- `covered`：主事实源已有可独立阅读的真实正文，并达到当前 Atom 的最小考试闭环；
- `partial`：已有实质正文，但缺必要机制、边界、辨析、考试动作或跨章承接；
- `unmapped`：没有实质正文落点，或只有一句提及/骨架/TODO；
- `link_only`：当前章节不是主事实源，本地完成最小定位后链接到另章已经 `covered` 的唯一主事实源。
