# 一、规则闭环与结构原则

当前规则保持：

> **单篇教学闭环**：承接与定位 → 具体问题 → 大白话直接答案 → 核心机制 → 考试动作 → 收口与下一站。
>
> **章节覆盖闭环**：大纲全集 → Atom → 主事实源 → 正文具体落点 → 教材/真题核验 → 正向反向检查 → `unmapped=0` → `partial=0`。

结构原则继续有效：

1. 考试归属不等于最佳教学位置；UML 完整教学主事实源固定在软件工程 OOA/OOD 主线；
2. 跨章节只能有一个完整主事实源，非主事实源只做定位 + wikilink；
3. Atom ID 不随文件移动重编号；
4. 软件架构生命周期六阶段 ≠ ABSD 六子过程；
5. ADL、UML、4+1、IEEE 1471-2000 不在同一分类层次；
6. 架构风格按主要组织机制识别，同一分类问题下固定成员不机械拆碎；
7. 架构复用不退化为复制代码；DSSA 单独承接特定领域共性架构。
