# G5 案例能力建设总控计划

> [!success] 当前证据范围内已收口
> ARCH coverage gate 已 PASS。G5-01～G5-11 已形成十一类互不重复的代表答题动作；G5-12 候选审计没有找到同时满足“可靠可解析文本、能新增答题动作、不依赖缺失图表”的候选，因此结论为 `NO_BUILD`。

## 一、阶段目标与完成标准

G5 训练：

> **题干证据识别 → 考点映射 → 分点作答 → 错因回链**

完成标准不是铺满所有年份或为 22 个大纲案例入口各造一篇正文，而是形成一组来源边界清楚、答题动作互不重复、能够回链理论主事实源的代表样本。

## 三、不再作为未完成任务的事项

- 22 个大纲案例入口均已映射到有效理论 Atom；没有代表案例正文的入口保留为可选训练来源，不构成 coverage 缺口。
- CASE-COM-01 的完整网络切换与 CASE-COM-02 的 IPv4/IPv6 融合，当前没有满足门槛的可靠完整文本案例，不据此制造伪案例。
- 缺图、缺表、OCR 不完整的题目不靠记忆补造。
- 理论已有主事实源时，案例页只做调用与表达训练，不复制第二套正文。

## 四、重开条件

只有满足以下任一条件才重开 G5：

1. 获得来源边界清楚、题干与答案信息完整的新案例证据；
2. 新候选能形成现有十一类动作之外的独立答题能力；
3. 用户明确指定某道题进行训练；
4. 复习反馈证明现有某类案例动作不足，需要定点补强。

否则返回全局控制，下一阶段为 `PAPER-00-SCOPE-GATE`。
