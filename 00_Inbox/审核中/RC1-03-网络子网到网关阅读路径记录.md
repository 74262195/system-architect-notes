# RC1-03 网络子网到网关阅读路径记录

沿 [[子网掩码与CIDR]] → [[子网划分与地址范围计算]] → [[ARP地址解析]] → [[路由表与最长前缀匹配]] 阅读。`/27` 的 32 地址块、`.70` 所在 `.64～.95`、跨子网先交网关、网关再按目的 IP 查路由，现有正文能串成一条动作链；没有机制重写的依据。

本批具体断点在 [[子网划分与地址范围计算]] 的自测：五个短问分别核块范围、特殊地址和网关 MAC，却没有一道同时给出源地址、前缀、网关和跨子网目标，让读者在选择题中判断**最终目的 IP 与第一跳目的 MAC 分属不同角色**。已用正文的 `.70/27 → .100` 情境补一题四选一，注明自编非真题，逐项解释把跨网段目标当本地下一跳、把 IP 目的改为网关的误判。[[ARP地址解析]] 和 [[路由表与最长前缀匹配]] 现有同网段/跨网段、下一跳与 LPM 解释可承接，不作重复扩写。
