# 提示词使用约定

本仓库只保留**软考知识库真正需要的提示词**，不再把通用 AI 工具、网页抓取 skill、通用改写命令一起塞进 Vault。

## ChatGPT / Codex 仓库任务提示词

位于 `prompts/` 根目录：

- `00-全局写作规范.md`：所有笔记任务共同规则，包含故事驱动写作和样稿门禁。
- `00-Inbox自动整理.md`：整理 `00_Inbox/`。
- `10-原子考点卡生成.md`：新建/重写原子考点卡。
- `20-章节检查与重构.md`：整章查漏、拆目录、纠错、补链；涉及正文重写时先做样稿。
- `30-Excalidraw章节知识看板.md`：章节视觉导航。
- `50-考前速记生成.md`：从已审核笔记生成速记。
- `40-Mermaid与Obsidian样式修复.md`：修复大型流程图缩放、黑底和主题兼容问题。

这些文件不会因为存在于 GitHub 就自动生效；`AGENTS.md` 负责按任务显式路由。

## 黄金风格基准

新增/大幅重写原子考点卡时，必须实际读取：

- `01_综合知识/01_计算机基础知识/01_计算机组成与体系结构/Cache.md`
- `01_综合知识/01_计算机基础知识/01_计算机组成与体系结构/指令流水线.md`

它们是**叙事方法样例**：从具体矛盾出发，让知识点作为解决方案自然出现，再落到机制与考试。不要机械复制具体故事。

## 批量正文重写

首次处理新章节，或一次计划生成/重写 3 篇及以上原子卡：

1. 先读黄金样例；
2. 先写 1 篇代表性样稿；
3. 用户审核确认风格；
4. 再批量。

用户明确要求“无需样稿直接批量”时除外。纯目录、链接、Excalidraw、frontmatter 修复不需要样稿。

## Obsidian Copilot

仅保留与软考直接相关的两类：

- `system-prompts/软考系统架构师.md`：Copilot 默认软考系统提示词。
- `copilot-custom-prompts/软考/`：考点卡、错题卡、论文素材、Mermaid 等软考手工命令。

## 维护规则

- 新规则优先进入 `AGENTS.md` 或对应根级任务提示词。
- 不新增第三套“总提示词”。
- 新增 Copilot 命令必须直接服务于软考学习、案例、论文、错题或知识可视化。
- 提示词不保存 Token、私钥、账号或未脱敏项目资料。
