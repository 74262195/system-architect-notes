# 提示词使用约定

本仓库只保留软考知识库真正需要的提示词。原则是：

> **一个规则只维护一个事实源；AGENTS 负责路由，专用提示词负责细节。**

## 任务提示词

| 文件 | 唯一职责 |
| --- | --- |
| `00-全局写作规范.md` | 通用教学语言、故事驱动、事实与版本边界 |
| `00-Inbox自动整理.md` | Inbox 整理 |
| `10-原子考点卡生成.md` | 原子性、黄金样例、原子卡批量样稿门禁 |
| `20-章节检查与重构.md` | 章节级查漏、目录、补链、结构重构流程 |
| `30-Excalidraw章节知识看板.md` | Excalidraw 章节导航看板 |
| `40-Mermaid与Obsidian样式修复.md` | 所有详细正文可视化路由、Mermaid/教学图验收 |
| `50-考前速记生成.md` | 全章考前速记 |
| `55-模块复习总纲生成.md` | 模块级快速复习总纲 |
| `60-历年真题解析与索引.md` | 真题抽取、标准化、去重、映射、频次 |
| `65-教材证据与笔记校验.md` | 教材证据优先级、抽取可靠性、笔记校验 |

这些文件不会因为存在于 GitHub 就自动生效；必须按 `AGENTS.md` 路由显式读取。

## 黄金样例

黄金样例只由 `10-原子考点卡生成.md` 维护，当前为：

- `01_综合知识/01_计算机基础知识/01_计算机组成与体系结构/冯·诺依曼结构与哈佛结构.md`
- `01_综合知识/01_计算机基础知识/01_计算机组成与体系结构/指令流水线-性能计算.md`

README 只作导航说明；若样例变化，以 `10` 为准，不在其他提示词重复维护完整规则。

## 维护规则

- 新规则先判断“它属于哪个唯一职责”，只写入对应文件。
- 其他任务若需要该规则，只写“执行 XX 提示词”，不复制完整条款。
- 不新增第三套总提示词，也不在外部 Skill 复制固定仓库规范。
- Obsidian Copilot 只保留与软考直接相关的手工命令；不会自动覆盖仓库规则。
- 提示词不保存 Token、私钥、账号或未脱敏项目资料。
