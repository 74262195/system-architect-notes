# 提示词使用约定

仓库现在只保留两类提示词，职责必须分开。

## 1. ChatGPT / Codex 仓库任务提示词（自动化规则）

位于 `prompts/` 根目录：

- `00-全局写作规范.md`：所有笔记任务的共同规则。
- `00-Inbox自动整理.md`：本地 Codex App 整理 Inbox。
- `10-原子考点卡生成.md`：新建/重写原子考点卡。
- `20-章节检查与重构.md`：整章查漏、拆目录、纠错、补链。
- `30-Excalidraw章节知识看板.md`：卡片式章节视觉导航。
- `50-考前速记生成.md`：从已审核笔记生成速记。

**这些文件不会因为“存在于 GitHub”就自动生效。** `AGENTS.md` 已提供明确任务路由，执行任务时必须读取对应文件。

## 2. Obsidian Copilot 提示词（手工调用）

- `system-prompts/软考系统架构师.md`：Copilot 的默认系统提示词，只保留这一份，避免多套系统规则互相打架。
- `copilot-custom-prompts/软考/`：软考考点卡、错题卡、论文素材、Mermaid 等手工命令。
- `copilot-custom-prompts/网页剪藏/`：网页/YouTube 剪藏命令。
- `copilot-custom-prompts/通用/`：摘要、简化、翻译、语法修正等通用手工命令。

这些文件只有在 Obsidian Copilot 中被选择、斜杠调用或右键调用时才会生效；Codex/ChatGPT 不会自动读取它们。

## 已清理的重复项

- 删除旧 `system-prompts/通用笔记.md`：它与软考系统提示词重复，而且包含“总览用 Canvas”“写文件前等待确认”等已经过时、与当前仓库规则冲突的要求。
- 删除 `提示词索引.md`：与本 README 重复维护，容易再次产生两套说明。

## 维护规则

- 新规则优先写入 `AGENTS.md` 或对应根级任务提示词，不再新增第三套“总提示词”。
- Copilot 系统提示词只保留一个默认文件。
- 新增 Copilot 手工命令时必须有明确使用场景；没有调用入口、只是复制别处内容的提示词不要加入仓库。
- 提示词不保存 Token、私钥、账号或未脱敏项目资料。
