# 原子考点卡生成

输入：目标知识点、所属章节、章节知识库、真实目录、相邻笔记和可靠来源。

## 执行

1. 先确认仓库是否已有同名/同义笔记，避免重复卡。
2. 若原材料包含多个可独立成文的平级概念，先拆分，不把多个考点硬塞进一篇。
3. 按 `00-全局写作规范.md` 生成完整 Markdown：
   - 为什么要学/痛点；
   - 讲人话；
   - 定义；
   - 核心机制；
   - 考试怎么认；
   - 易混/避坑；
   - 口诀或总结；
   - 例题/自测；
   - 下一站。
4. 若有计算，给公式、变量、完整示例、单位和易错点；若有流程/交互，选合适 Mermaid。
5. 不复制已有笔记的大段内容，不杜撰真题或来源。
6. 同步章节知识库与相邻主线链接；不要额外创建重复 MOC/首页。

## Git

手动模式：只输出文件内容、建议路径和需同步文件清单。

PR 模式：创建 `ai/<topic>-YYYYMMDD` 分支，写入目标路径，同步索引和相邻链接，运行仓库校验并提交 PR。若用户已有“完成后直接合并 main”的明确约定，校验通过后 squash merge；仍不得绕过 PR 直接写 main。
