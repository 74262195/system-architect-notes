# Inbox 自动整理任务

当 `00_Inbox/AI草稿/` 出现新的 Markdown 时，Codex App 按以下顺序处理；没有新文件则不产生提交。

1. 确认仓库当前在 `main` 且工作区无未提交改动；否则暂停并报告。
2. 读取新草稿、`AGENTS.md`、`STYLE.md`、[[Inbox索引]]、对应章节知识库、真实目录和必要相邻笔记。
3. 搜索同名、aliases 和相似主题；已有笔记则合并/更新，不重复创建。
4. 补齐 frontmatter；保留原始事实和公式，纠正明显错误但不要杜撰来源。
5. 按零基础原子卡结构重写，计算使用 LaTeX，结构/流程使用 Mermaid。
6. 将成品放入**现有真实章节目录**，更新章节知识库、学习路线、前后“下一站”和必要的 Excalidraw/Dataview 完整路径。
7. 需要人工判断的内容移到 `00_Inbox/审核中/`，不要强行猜。
8. 运行 `node scripts/check-vault.mjs` 与 `git diff --check`。
9. 同一批 Inbox 整理尽量形成一个清晰提交，不逐文件制造大量小提交；检查通过后推送 `main`，提交信息使用 `notes: inbox整理 <主题>`。

安全边界：不得提交认证文件、Token、私钥、未脱敏工作资料、教材扫描件；不得 force push；不得在未确认成品可追溯前删除原始草稿。
