# 章节三轮审查

用于任何“整章生成、整章补全、整章重构、章节是否完成”的任务。目标不是把同一批文字重复看三次，而是用三个不同问题分别验收。

本文件只负责：**三轮分别审什么，以及什么时候才允许说“这一章完成了”**。章节覆盖矩阵与 Atom ID 的建立执行 `20`，教材证据执行 `65`，原子卡正文执行 `10`。

## 一、章节完成硬门槛

只有同时满足以下条件，才允许写“章节完成 / 已审核 / 可进入下一章”：

1. 已按 `20` 建立本章**大纲原子项全集、稳定 Atom ID 和完整覆盖矩阵**；
2. 第一轮通过时 `unmapped = 0`，不存在假覆盖、重复主事实源或无效 `link_only`；
3. 最终完成时 `partial = 0`，所有保留 Atom 均为可验证的 `covered` 或合法 `link_only`；
4. 章节范围内保留的 P0/P1/P2 原子卡都有可独立阅读的正文；
5. 至少经过三轮**目的不同**的审查；
6. 每轮发现的问题已经修复并重新检查；
7. 三轮结果有章节级审核报告或等价可追溯记录，且保留完整覆盖矩阵；
8. 索引、学习路线、优先级和正文状态一致；
9. 仓库结构/链接检查通过。

**P0/P1/P2 只决定复习优先级和讲解深度。P1/P2 不能因为优先级低而长期只有标题或占位说明。**

## 二、第 1 轮：范围与遗漏审查

### 只回答一个问题

**大纲范围内的每个原子项是否都有真实、唯一、可验证的承接，而且不是目录幻觉？**

### 固定输入

必须读取：

- 最新适用考试大纲；
- `20` 建立的完整章节覆盖矩阵；
- 当前真实目录和正文集合；
- 必要的大纲/教材/真题证据；
- 涉及跨章节内容时，同时读取目标主事实源正文和链接。

### 固定检查顺序

1. 检查大纲原子项全集是否完整，所有 Atom 是否有稳定 ID；不能从现有目录反推“应该有的范围”；
2. 逐行检查矩阵：Atom 是否映射到正文文件和**正文具体落点**，或明确标为待修；
3. 扫描假覆盖：目录、索引、文件名、frontmatter、tag/alias、一句话定义、TODO、占位卡、上位章节名都不得单独计为 `covered`；
4. 检查 `unmapped`：任何一个 `unmapped` 都说明本轮尚未通过；
5. 检查跨章节唯一主事实源：同一事实/机制不得多章重复完整展开；
6. 检查 `link_only`：目标链接必须有效，目标主事实源必须真实存在且已经 `covered`；
7. 执行反向检查：从当前正文集合反查每张实质考点卡/主要知识段落是否对应 Atom ID 或有明确补充理由；
8. 检查重复卡、同义卡、错归章节、正文孤岛和断掉的导航。

### 第一轮硬门禁

以下任一项不满足，第一轮必须记录为“未通过”，不能写“基本完整”或“主线已覆盖”：

- 大纲原子项全集已建立；
- 每个 Atom 有稳定 ID；
- `unmapped = 0`；
- 假覆盖计数 = 0；
- 跨章节主事实源冲突 = 0；
- 所有 `link_only` 均指向有效、已 `covered` 的主事实源；
- 已完成正文集合反向检查；
- 每个保留的 P0/P1/P2 都有实质正文，而非占位。

第一轮发现缺项后应先修复，再重新执行本轮。允许“第一次检查发现 `unmapped > 0` → 修复 → 复查归零”，但审核报告必须保留发现、修复和复查记录，不能把第一次失败抹掉。

## 三、第 2 轮：概念、机制与边界审查

### 只回答一个问题

**覆盖矩阵里的每个 Atom，实际正文落点是否被可靠证据支持，而且解释到了考试所需深度？**

### 证据顺序

执行 `prompts/65-教材证据与笔记校验.md`：

**大纲 → 可靠真题 → 官方最新版主教材 → 当前正文具体落点。**

### 审查单位

第二轮不能只遍历“现有卡片”。必须**逐 Atom ID / 逐矩阵行**核验；同一文件承载多个 Atom 时，要分别指出各自正文落点和证据。

### 至少检查

- 正文具体落点是否真实存在，而不是只映射到文件名；
- 定义是否准确；
- “为什么存在”是否讲清；
- 核心机制/步骤是否缺环；
- 前置概念与当前概念是否混层；
- 条件、例外、版本口径是否被写成绝对规律；
- 公式/计算是否真的需要、变量是否完整；
- 教材要求的必要机制/关系/边界是否达到最小解释深度；
- 真题是否要求额外的辨析、识图、计算或案例动作，而正文没有承接；
- 相邻卡之间是否重复或互相矛盾；
- 大纲弱要求内容是否被教材篇幅误抬成重点；
- 旧真题是否越过新版大纲强行扩张章节范围；
- 原标 `covered` 的 Atom 是否其实只有一句定义或顺带提及；若是，必须退回 `partial / unmapped` 再修。

### 通过标准

- 每个 `covered` Atom 都有可追溯证据和足够的正文落点；
- 教材核验发现的定义、机制、条件、边界问题全部修复；
- 真题要求的实际考试动作已落到正文；
- 没有用“考试大概不会考”跳过事实错误；
- 第二轮结束后，因事实/深度问题产生的 `partial` 已全部修复并复查。

## 四、第 3 轮：软考可用性与阅读性审查

### 只回答一个问题

**每个承担主事实源的正文落点，对零基础学习者是否形成完整教学闭环，并能在题目里实际使用？**

### 审查单位

以覆盖矩阵中承担 `covered` 的**主事实源正文**为主；`link_only` 只检查本地定位是否够用、链接是否自然有效，不要求复制主事实源教学正文。

### 六要素教学闭环

每个主事实源必须能指出正文中的具体位置，完成：

1. **承接与定位**：上一站是什么、当前概念属于哪里；
2. **具体问题**：为什么现在需要它，解决什么判断困难/限制；
3. **直接答案**：问题提出后是否先用一句完整结论回答；
4. **核心机制**：零基础读者能否跟着对象/状态/关系把机制走通；
5. **考试动作**：题干出现什么信号，第一步判断、排除或计算什么；
6. **收口与下一站**：本篇解决了什么，还剩什么，因此下一站为什么出现。

不能只回答“有、符合”。必须指出对应正文落点。

### 其他至少检查

- 快速复习卡能在 20–40 秒内召回关键结论；
- 有可靠真题证据的卡，正文中能看到“考过什么判断点”；
- 计算题有可执行动作链，不只留公式；
- P1/P2 仍然可读，只是篇幅和复习权重低于 P0；
- 不出现“高频/必考”等无证据标签；
- 学习路线使用知识关系和优先级，不把“第一轮/第二轮”当成正文完成度；
- 上一站/下一站、章节索引和 wikilink 连通；
- 需要图才能避免误解的空间/结构问题，按 `40` 补图，不能用 ASCII 图凑数；
- 文字没有为了覆盖教材而堆成章节摘要；
- 多个 Atom 落在同一文件时，仍保持“一卡一主问题”，没有为覆盖矩阵机械塞成胖卡。

### 通过标准

- 每个主事实源都通过六要素教学闭环；
- `partial = 0`；
- 所有 `link_only` 都有自然定位和有效承接；
- 章节既能当知识库，也能直接用于软考复习；不是“资料都在，但不知道怎么学”。

## 五、最终联合反查

三轮都完成后，必须再做一次最终状态核对，防止修正文时产生新的覆盖漂移：

1. 从 Atom 全集正向确认所有行最终均为 `covered / link_only`；
2. 确认 `unmapped = 0`、`partial = 0`；
3. 从正文集合反向确认没有新的正文孤岛、重复主事实源或无法解释的超纲扩写；
4. 检查所有 `link_only` 目标仍有效且主事实源仍为 `covered`；
5. 检查新增、移动、拆分后的索引、上一站/下一站和 wikilink；
6. 最终矩阵必须与仓库真实正文状态一致，不能使用修复前的旧矩阵宣布完成。

## 六、审核报告必须记录什么

至少记录：

- 日期、章节、原子卡数量、P0/P1/P2 分布；
- **大纲 Atom 总数和完整“大纲原子项 → 主事实源 → 正文文件 → 正文具体落点 → 状态”矩阵**；
- `unmapped / partial / covered / link_only` 的轮前、修复后数量；
- 使用的大纲/教材/真题证据层级；
- 覆盖—减负处置清单：新增、补强、链接、合并/降级、删除各自的对象、证据和结果；删除项必须标明替代卡或确认无替代的超纲理由；
- 假覆盖检查结果；
- 正向检查发现的漏项；
- 反向检查发现的正文孤岛、重复主事实源、胖卡及处理结果；
- 第 1 轮发现的问题、修复、复查结果；
- 第 2 轮逐 Atom 发现的问题、修复、复查结果；
- 第 3 轮教学闭环问题、修复、复查结果；
- 有争议或暂不纳入的范围边界及理由；
- 最终是否允许标记“章节完成”。

如果某一轮没通过，报告写“未通过/待修复”，不得为了推进学习路线而提前宣布完成。

## 七、优先级与正文深度

减负的正确方式是**不同深度，不是有无正文**：

- **P0 核心掌握**：完整机制 + 做题动作 + 可靠真题判断点 + 易错点；
- **P1 建议掌握**：完整定义/机制 + 主要判断入口 + 必要真题/易混点；
- **P2 了解定位**：至少说明是什么、属于哪里、为什么存在、关键结论、题干如何识别；不扩写低收益细节；
- **P3 暂不复习/扩展**：只有证据明确为低信号或扩展时使用，仍需在索引中说明为何降级。

因此，发现 P1/P2 是空占位时，应补成“短但完整”的正文，而不是直接升优先级或删除。

## 八、与其他提示词的关系

- 原子卡正文怎么写、样稿门禁：`10-原子考点卡生成.md`
- 通用语言和公式门禁：`00-全局写作规范.md`
- Atom ID、覆盖矩阵、主事实源和章节结构怎么拆：`20-章节检查与重构.md`
- 真题证据怎么去重：`60-历年真题解析与索引.md`
- 教材证据与 Atom 级解释深度：`65-教材证据与笔记校验.md`
- 图表：`40-Mermaid与Obsidian样式修复.md`

本文件不重复维护这些细则，只负责：**用三轮独立审查把覆盖、正确性和教学可用性全部验收到可宣布完成。**
