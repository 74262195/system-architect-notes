# 模块复习总纲生成

用于为章节下的一个真实子目录生成 5～15 分钟快速复习总纲。总纲是原子卡与全章考前速记之间的中间层，不是新的知识事实源。

## 读取范围

生成前必须读取：

- `AGENTS.md`、`STYLE.md`、`prompts/00-全局写作规范.md`；
- 目标模块中的全部原子卡或模块索引；
- 上一级章节知识库与全章考前速记；
- 相邻模块总纲，确保前后链接一致。

只从已审核原子卡和章节知识库提炼，不补写当前知识库没有依据的新结论。发现缺失知识时记录为待完善项，不在总纲里假装补齐。

## 保存目录

- 综合知识的模块总纲统一放在 `01_综合知识/00_复习总纲/<章节目录>/<模块目录>/`；
- 章节目录和模块目录沿用原学习笔记的编号与名称，不重新发明分类；
- 例如：`01_综合知识/00_复习总纲/01_计算机基础知识/02_操作系统/操作系统-复习总纲.md`；
- 原学习目录只保留原子卡和模块索引，通过短 wikilink 连接总纲。

## 固定结构

1. **用法**：标明预计复习时长和“先闭卷、卡住再点原子卡”；
2. **30 秒主线**：用 3～6 句或一条紧凑链路串起模块，直接链接真实原子卡；
3. **题干关键词 → 知识点**：优先使用表格；
4. **核心公式/流程**：每组公式必须依次写清“这条公式算什么 → 每个符号的中文含义与单位 → LaTeX 公式 → 一句中文读法 → 适用条件”；
5. **高频对比**：三种以上概念用表格写“核心区分、典型例子、考试问法/陷阱”；
6. **最容易丢分的地方**：解释为什么错，不只写口诀；
7. **跨模块联系**：至少连接上一模块、下一模块或相关底层知识；
8. **闭卷自测**：按模块体量给 8～12 题，答案能在链接的原子卡中找到；
9. **下一站**：顺着五模块复习主线前进，并可回到上一模块或全章入口。

## 篇幅与表达

- 大模块控制在约 10～15 分钟，小模块可缩短到 5～8 分钟，不为统一长度重复内容；
- 表格能讲清时不画图；只有流程关系明显且 1～5 个短节点时才考虑 Mermaid；
- 不复制原子卡的完整教学过程，不重新展开长例题；
- 禁止只列公式不解释符号。英文缩写和希腊字母首次出现时必须写中文含义；$\sum$、$\lfloor x\rfloor$、$\bmod$、$\leftarrow$ 等不直观运算符必须说明怎样读；
- 同一公式中的单位必须能够约掉或统一。时间、容量、速率等单位换算要明确提醒 bit/Byte、Hz/kHz、s/ms 等关系；
- 中文读法要让零基础读者不看符号也能复述计算步骤，不能只是把变量名照抄一遍；
- 不创建重复 MOC。入口同步到上级章节知识库、现有模块索引和全章考前速记；
- 文件名统一为 `<模块名>-复习总纲.md`，frontmatter 的 `type` 使用 `考前速记`，`topic` 使用 `模块复习总纲`。

## 验收

- 每个关键结论都有真实原子卡可回看；
- 每条公式都有用途、符号中文含义、单位、中文读法和适用条件；
- 模块间“下一站”形成单向主线，上一站可返回；
- 上级索引能一跳进入全部模块总纲；
- 运行 `node scripts/check-vault.mjs` 与 `git diff --check`。
