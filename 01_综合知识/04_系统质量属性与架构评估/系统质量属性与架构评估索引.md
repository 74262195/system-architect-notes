# 系统质量属性与架构评估 · 知识库

> [!important] 本章定位
> 主线不是背 14 个名词，而是：**先把“快、稳、安全、好改”写成可测量场景，再用架构评估找敏感点、权衡和投资优先级。**

## 01 · 质量属性

学习顺序：
1. [[质量属性-开发期与运行期]]：先知道质量属性在问什么。
2. [[质量属性场景六要素]]：把模糊要求变成可度量场景。
3. [[性能质量属性场景]]：时间、吞吐、负载。
4. [[可靠性与可用性]]：少故障 vs 能服务。
5. [[安全性质量属性场景]]：攻击、保护、检测、恢复。
6. [[可修改性质量属性场景]]：修改范围、成本、工作量。
7. [[可测试性质量属性场景]]：可控制、可观察、测试成本。
8. [[易用性质量属性场景]]：用户学习、操作、错误与满意度。

## 02 · 架构评估

学习顺序：
1. [[架构评估-问卷场景与度量]]：先区分三类评估方式。
2. [[敏感点与权衡点]]：认识架构“关键旋钮”。
3. [[SAAM架构评估]]：场景与可修改性。
4. [[ATAM架构权衡分析]]：多质量属性的敏感与权衡。
5. [[ATAM效用树]]：场景组织和优先级。
6. [[CBAM成本效益分析]]：把成本收益加入架构决策。

## 考场快速分流

| 题眼 | 优先想到 |
| --- | --- |
| 谁触发/环境/响应/度量 | 质量属性场景六要素 |
| 延迟/吞吐/期限 | 性能 |
| MTBF/MTTR/恢复 | 可靠性与可用性 |
| 修改成本/影响构件 | 可修改性 |
| 可观察/可控制/测试时间 | 可测试性 |
| 场景交互、可修改性评估 | SAAM |
| 敏感点、权衡点、多质量属性 | ATAM |
| 效用树、场景优先级 | ATAM 效用树 |
| 效用、成本、ROI、预算 | CBAM |
