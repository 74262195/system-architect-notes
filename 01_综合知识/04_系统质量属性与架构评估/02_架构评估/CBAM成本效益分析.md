# CBAM：两个架构方案都能提升质量时，钱怎么决定

ATAM 找到风险和权衡后，现实项目还要问：

> **哪个架构策略值得花钱？**

一个方案性能提升很大但成本极高；另一个提升略少，却便宜得多。只谈技术效果无法做投资决策。

CBAM 在 ATAM 基础上，把**成本、收益和效用**加入架构选择。

## 核心逻辑

~~~mermaid
flowchart LR
    A[质量场景] --> B[架构策略]
    B --> C[质量收益]
    C --> D[估算成本]
    D --> E[比较 ROI]
~~~

核心不是死背八步，而是理解：

> **架构策略改变质量属性 → 利益相关者获得效用 → 再和实现成本比较。**

## 八步压成四段

1. **挑场景**：从 ATAM 场景中选高优先级项并求精。
2. **给效用**：确定场景权重和不同响应级别的价值。
3. **算收益**：判断策略把响应提升到什么程度，计算总收益。
4. **看成本与 ROI**：估算成本，按投入产出排序。

## ATAM vs CBAM
- ATAM：这个决策对多个质量属性有什么风险和权衡？
- CBAM：在权衡看清后，哪个策略最值得投资？
