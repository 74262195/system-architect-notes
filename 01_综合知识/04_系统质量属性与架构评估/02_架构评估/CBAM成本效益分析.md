# CBAM：怎样在质量收益和实施成本之间选择架构策略

## 先定位：它把经济因素引入架构决策

ATAM 能识别质量属性风险和权衡，但不能直接回答“有限预算先投哪个策略”。**CBAM（成本效益分析法）**在场景和架构策略分析基础上，为不同质量响应赋予效用，估算策略收益与成本，再比较投资回报。

## 参与对象

- 高优先级质量属性场景；
- 可选架构策略；
- 利益相关者对不同响应级别的效用判断；
- 策略实施成本和预算约束。

## 一次分析怎样闭环

~~~mermaid
flowchart LR
    A[整理并求精场景] --> B[确定优先级与效用]
    B --> C[提出架构策略]
    C --> D[估算策略收益]
    D --> E[估算成本]
    E --> F[按ROI和约束选择]
~~~

1. 从评估结果中选出重要场景并明确响应度量。
2. 为场景分配权重，并确定最差、当前、期望、最好响应对应的效用。
3. 分析每个架构策略会把各场景响应改善到什么程度。
4. 汇总该策略在所有场景上的效用增量，得到总收益。
5. 估算策略成本，并按教材口径计算受成本约束的 ROI。
6. 在预算、依赖和风险约束下选择策略；最高 ROI 不一定在所有现实约束下都能实施。

概念上可记为：

\[
ROI=\frac{\text{策略带来的总收益}}{\text{实施成本}}
\]

具体题目若给出不同收益或 ROI 公式，以题干为准。

## ATAM 与 CBAM

| ATAM | CBAM |
| --- | --- |
| 找质量场景、风险、敏感点和权衡点 | 给策略的质量改善和成本赋值 |
| 回答“技术上影响什么” | 回答“经济上先投什么” |
| 主要产出风险与权衡认识 | 主要产出策略投资优先级 |

## 易错点

- CBAM 不是只选“成本最低”的方案。
- 效用是利益相关者对质量响应价值的度量，不等于性能数值本身。
- ROI 高表示单位成本收益高，不代表绝对收益最大。
