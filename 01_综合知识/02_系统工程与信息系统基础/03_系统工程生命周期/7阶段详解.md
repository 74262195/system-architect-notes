# 系统工程生命周期 7 阶段详解

> **提示**：先看本页末尾的 7 阶段总表建立顺序，再回到各阶段细节。

---

## 阶段 1：探索性研究（Exploratory Research）

| 维度        | 内容                         |
| :-------- | :------------------------- |
| **核心目标**  | 识别利益相关者需求，探索技术可行性          |
| **关键活动**  | 初步需求分析、技术可行性研究、市场调研、风险评估   |
| **典型交付物** | 《可行性分析报告》                  |
| **大白话**   | “这个系统能不能做？有没有人用？技术上能不能实现？” |

> **易混淆**：探索性研究问的是 **“能不能做”**（可行性）；概念阶段问的是 **“做什么”**（需求定义）。


## 阶段 2：概念阶段（Concept Stage）

| 维度 | 内容 |
| :--- | :--- |
| **核心目标** | 将利益相关者需求转化为系统的顶层概念 |
| **关键活动** | 定义系统目标、总体架构、关键性能指标（KPI）、约束条件 |
| **典型交付物** | 《系统需求规格说明书》(SRS) |
| **大白话** | “这个系统到底要实现哪些功能？长什么样？有哪些限制？” |


## 阶段 3：开发阶段（Development Stage）

| 维度 | 内容 |
| :--- | :--- |
| **核心目标** | 将概念设计转化为可用的系统 |
| **关键活动** | 详细设计、原型开发、编码、单元测试、集成测试 |
| **典型交付物** | 《系统设计文档》(SDD)、可运行的原型 |
| **大白话** | “正式开始写代码、做硬件、搭建系统，把它从图纸变成实物。” |

> **易混淆**：开发阶段是 **“做样品”**；生产阶段是 **“批量复制”**。


## 阶段 4：生产阶段（Production Stage）

| 维度 | 内容 |
| :--- | :--- |
| **核心目标** | 进行系统的制造、编码或构建（批量） |
| **关键活动** | 批量生产、系统集成、全面质量控制（QC/QA） |
| **典型交付物** | 符合质量标准的最终产品 |
| **大白话** | “样品确认没问题了，开始批量生产，卖给客户。” |

> **提示**：对于软件系统，“生产阶段”指大规模部署和分发，不一定是物理制造。


## 阶段 5：使用阶段（Utilization Stage）

| 维度        | 内容                       |
| :-------- | :----------------------- |
| **核心目标**  | 系统交付给最终用户并正式运行           |
| **关键活动**  | 系统部署、用户培训、日常运营、用户反馈收集    |
| **典型交付物** | 《运维手册》、系统运行日志            |
| **大白话**   | “系统上线了，用户开始用了，我们看着它跑起来。” |


## 阶段 6：保障阶段（Support Stage）

| 维度 | 内容 |
| :--- | :--- |
| **核心目标** | 提供持续维护，确保系统稳定运行 |
| **关键活动** | 故障修复、性能监控、系统升级、配置管理、技术支持 |
| **典型交付物** | 《系统监控报告》、变更记录 |
| **大白话** | “系统出问题了我们修，性能不够了我们升级，保障它持续服务。” |

> **易混淆**：使用阶段是 **“用系统”**；保障阶段是 **“修系统/维护系统”**。


## 阶段 7：退役阶段（Retirement Stage）

| 维度 | 内容 |
| :--- | :--- |
| **核心目标** | 系统生命周期终结，安全、有序地退出 |
| **关键活动** | 数据迁移/备份、系统停用、硬件资源回收、替代系统切换 |
| **典型交付物** | 《退役报告》 |
| **大白话** | “系统老了，业务变了，把数据导出来，把系统关掉，换新的。” |


## 进阶考法：每个阶段的“核心问题”

| 阶段    | 核心问题（一句话） |
| :---- | :-------- |
| 探索性研究 | 能做吗？      |
| 概念阶段  | 做什么？      |
| 开发阶段  | 怎么做出来？    |
| 生产阶段  | 怎么复制？     |
| 使用阶段  | 怎么用好？     |
| 保障阶段  | 怎么维好？     |
| 退役阶段  | 怎么送走？     |
