# DSS（决策支持系统）

> **定位**：企业信息化的 **“高层”** ，服务于高管/老板。
> **层级**：战略决策层（高层管理者）
> ⚠️ **软考绝对重点！** 每年必考 1-2 题！

---

## 一、一句话定义

DSS 是一个 **“智能参谋”**，通过建立 **数据模型** 对历史数据进行分析和推演，预测不同决策方案可能带来的结果，供管理者参考。

> **大白话**：**“老板的军师”**。MIS告诉老板“上个月卖了100万”，DSS告诉老板“如果降价10%，下个月大概卖120万；如果涨价10%，大概卖80万，老板您选哪个？”

---

## 三、DSS 的三大绝对考点（必背！考场专门考这些！）

| 考点       | 正确说法                  | 错误说法（出题陷阱）         |
| :------- | :-------------------- | :----------------- |
| **决策角色** | **“支援”** 人做决策         | “代替”人做决策 ❌         |
| **问题类型** | 解决 **“半结构化/非结构化”** 问题 | “结构化”问题 ❌（那是MIS干的） |
| **追求目标** | 追求决策的 **“有效性”**       | 追求决策的“效率” ❌        |

---

## 三点五、DSS 的系统组成（⭐必背，常考细节）

| 结构 | 组成 | 考点说明 |
| :--- | :--- | :--- |
| **两库结构**（核心） | **数据库 + 模型库** | 基础标配，考得最多 |
| **三库结构** | 两库 + **方法库** | 加"怎么做"的算法库 |
| **五库结构** | 三库 + **知识库 + 文本库** | 加"经验规则 + 文档资料" |

> **必记组件角色**：
> - **数据库**：存决策所需的历史/实时数据
> - **模型库**：存决策模型（预测、优化、What-if）——**DSS 区别于 MIS 的关键**
> - **对话子系统（人机接口）**：用户与系统交互的窗口，"一问一答"
>
> **防混淆**：**ES 的核心是"知识库+推理机"，DSS 的核心是"数据库+模型库"**。看到"推理机"选 ES，看到"模型库"选 DSS。

---

## 四、MIS vs DSS（必考对比）

| 对比维度 | **MIS** | **DSS** |
| :--- | :--- | :--- |
| **解决问题** | **结构化**（有标准公式） | **半结构化/非结构化**（无标准答案） |
| **目标** | **效率**（报表出得快） | **有效性**（决策正确） |
| **分析能力** | 事后统计 | 事前预测 |
| **决策角色** | **替代**人力 | **支援**人（参谋，不拍板） |
| **核心驱动力** | 数据驱动 | **模型驱动** |

---

## 五、考场秒杀

| 题干关键词 | 秒选 |
| :--- | :--- |
| “预测模型”“如果…会怎样…”“推演” | **DSS** |
| “支援”“参谋” “不代替” | **DSS** |
| “半结构化”“非结构化” | **DSS** |
| “有效性”（不是效率） | **DSS** |

> **考场口诀**：看到"预测"、"模型"、"如果" → 选 DSS；看到"代替"、"结构化"、"效率" → 排除 DSS，那是 MIS。
