# 商业智能（Business Intelligence, BI）

> [!important] 核心理解
> **BI 就是把企业海量数据"变"成决策依据**的一套技术栈：数据仓库 + ETL + OLAP/数据挖掘 + 可视化。它是 **DSS 在数据时代的发展形态**，考的是"数据→信息→决策"这条链。

---

## 一、一句话定义

**商业智能** = 对企业的**业务数据进行采集、清洗、整合、分析**，最终以报表/仪表盘/图表形式**支撑决策**。

> 大白话：**"把公司各个系统的数据倒进一个'大池子'，洗干净，再变成老板看得懂的图表和结论。"**

---

## 二、BI 的四层技术栈（⭐必背顺序）

| 层次 | 组件 | 大白话 |
| :--- | :--- | :--- |
| ① 数据源 | 业务系统数据库（ERP/CRM/财务…） | 各系统的原始数据 |
| ② 数据仓库 | **ETL**（抽取-转换-加载）导入**数据仓库/数据湖** | 洗数据、统一格式，存进大池子 |
| ③ 分析引擎 | **OLAP**（联机分析处理）、**数据挖掘** | 从多维度切数据、挖规律 |
| ④ 展示层 | 报表、**仪表盘**、可视化大屏 | 把结论画给老板看 |

> **口诀：源 → 仓 → 析 → 显**（源头倒水、仓库存水、分析滤水、大屏看水）

---

## 三、BI  vs  DSS（考场对比）

| 对比维度 | **DSS** | **BI** |
| :--- | :--- | :--- |
| 定位 | 面向特定决策问题的"参谋" | 面向全企业日常分析的"数据工厂" |
| 数据规模 | 小、专题数据 | **海量**、全量数据 |
| 驱动方式 | **模型驱动**（What-if 推演） | **数据驱动**（报表/分析） |
| 使用对象 | 高层管理者 | 各级管理者 + 业务人员 |
| 关系 | 传统形态 | **现代发展形态**（BI 可视为 DSS 的数据化升级） |

---

## 四、高频关联考点

- **ETL**：抽取（Extract）→ 转换（Transform）→ 加载（Load），BI 的"水管工程"（详见 [[企业应用集成EAI]] 数据集成层）
- **OLAP vs OLTP**：
  - **OLTP**：在线事务处理——日常增删改查（TPS 干的活）
  - **OLAP**：在线分析处理——多维分析（BI 干的活）
- **数据挖掘**：从海量数据中找规律（关联规则、聚类、分类）——如"啤酒与尿布"
- **数据仓库特点**：面向主题、集成、非易失（不删改）、随时间变化

## 五、考场秒杀表

| 题干关键词 | 秒选 |
| :--- | :--- |
| "数据仓库 + ETL + OLAP + 可视化" | **BI** |
| "把多系统数据整合做分析报表" | **BI** |
| "仪表盘""数据大屏""多维分析" | **BI（OLAP）** |
| "事务处理""日常增删改查" | **OLTP**（不是 BI） |
| "啤酒与尿布""关联规则" | **数据挖掘** |

---

## 六、一句话总结

> **TPS 记流水，MIS 出报表，DSS 做推演，BI 是给全公司装了一台"数据决策发动机"。** 看到"数据仓库+OLAP"就想到 BI。
