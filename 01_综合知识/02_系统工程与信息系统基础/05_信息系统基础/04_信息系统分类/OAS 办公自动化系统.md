# OAS（办公自动化系统）

## 零基础先抓住

> [!question] 为什么要学这个
> 不同管理层级和业务任务需要不同类型的信息系统。这里要学会根据“谁在用、解决什么问题”识别系统类型。

> [!important] 考试怎么认
> 看到与“**OAS 办公自动化系统**”相关的阶段、方法、系统类型或关键术语时，先判断它解决什么问题、面向什么对象，再做选择。


> **定位**：企业信息化的 **“通用工具”** ，服务于全体员工。
> **层级**：通用（各级办公人员）

---

## 一、一句话定义

OAS 是利用计算机技术和通信技术，**辅助办公活动** 的系统，将传统的纸质办公变为 **无纸化、流程化、协同化** 的电子办公。

> **大白话**：**“电子文具盒”**。管理你的邮件、日程、审批单和文档。

---

## 二、典型场景

| 场景 | 说明 |
| :--- | :--- |
| 企业邮箱 | 收发邮件、日程管理 |
| OA 审批流 | 请假申请、报销申请、合同审批 |
| 电子文档管理 | 共享网盘、文档在线协作 |
| 视频会议系统 | Zoom、腾讯会议、Teams |
| 公告通知 | 公司新闻、制度发布 |

---

## 三、核心特征

| 特征 | 大白话 |
| :--- | :--- |
| **协同工作** | 多人同时编辑文档、协同审批 |
| **流程自动化** | 审批流自动流转，不用人拿着单子到处跑 |
| **无纸化** | 签字、盖章变成线上操作 |
| **信息共享** | 文档统一存储，全员可查 |

---

## 四、OAS 与 MIS 的区别

| 对比维度 | **OAS** | **MIS** |
| :--- | :--- | :--- |
| **核心任务** | 辅助**办公活动**（文档、邮件、审批） | 辅助**管理决策**（统计、报表） |
| **服务对象** | 全体员工 | 中层管理者 |
| **关注点** | **效率**（办公速度快不快） | **信息**（数据准不准） |
