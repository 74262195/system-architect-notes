# 操作系统索引：先按大纲定边界，再按专题完成学习

> [!important] 这页怎么用
> 本页是操作系统的**总导航和减负入口**：先看真实专题结构，再按 **P0 → P1 → P2 → P3** 安排复习。专题导航卡负责展开每一组原子卡，原子卡负责解释概念、机制和做题动作。
>
> 当前操作系统核心共有 **45 张考点卡：P0 3、P1 24、P2 17、P3 1**；另有 7 张专题导航卡。[[嵌入式系统]] 虽然暂存于本目录，但属于大纲 1.4 的独立模块，不计入这 45 张。

## 大纲边界先看清

系统架构设计师第 2 版大纲中：

- **1.3.2 操作系统**：组成、作用、特点、基本原理，以及批处理、分时、网络、分布式、嵌入式/实时操作系统等类型；
- **1.3.4 文件系统**：定义、作用、类型、组成、基本原理、存取方式和存储管理；
- **1.4 嵌入式系统及软件**：独立考试模块，不是“磁盘调度之后的操作系统小节”。

因此：

- [[嵌入式系统]]：独立模块，当前为 P0；这里只保留边界说明和入口。
- [[单缓冲与双缓冲]]：归“计算机组成与体系结构 → 总线与 I/O”，这里只保留跨模块题型链接。
- 专题导航卡、复习总纲不计入 45 张原子考点卡。

## 真题题型入口：看到题干先做什么

| 题干信号 | 第一反应 | 原子卡 |
| --- | --- | --- |
| “静态代码”“正在执行”“是否同一个进程” | 先区分程序、进程、父子进程 | [[程序与进程]] · [[父进程与子进程]] |
| “共享什么”“哪些必须独立” | 先列线程共享的进程资源，再列私有执行现场 | [[线程与进程]] |
| “运行、就绪、阻塞” | 先判断是获得 CPU、等待资源/I/O，还是等待事件完成 | [[进程三态与状态转换]] |
| “谁先获得 CPU”“周转时间” | 先画执行顺序和完成时刻，再计算时间 | [[进程调度]] |
| “前趋图”“必须先后” | 只按题目给出的直接箭头判断，不自动补边 | [[前趋图与进程先后关系]] |
| “互斥”“同步”“empty/full/mutex” | 先分清不能同时还是必须先后，再检查 P/V 顺序 | [[PV操作实现互斥]] · [[PV操作实现同步]] |
| “同类资源最少数量” | 让每个进程都尽量只差 1 个，再额外留 1 个破局资源 | [[避免同类资源死锁的最少资源数]] |
| “Available、Max、Allocation、Need” | 先检查数据含义，再做安全性检查或资源请求 | [[银行家算法基本数据]] · [[银行家算法安全性检查]] · [[银行家算法资源请求]] |
| “页框位图大小” | 先数物理页框，再按一框一 bit 换算 | [[页框位图]] |
| “逻辑地址、页号、页内偏移” | 页号查页表换页框，页内偏移保持不变 | [[分页地址转换]] |
| “缺页”“换入换出”“淘汰哪一页” | 先判断有无空闲页框，再确定置换算法依据 | [[缺页处理过程]] · [[LRU页面置换算法]] · [[Clock页面置换算法]] |
| “目录、inode、文件块、打开文件” | 沿文件名 → 目录项 → FCB/inode → 块地址定位 | [[目录与文件打开过程]] · [[FCB与inode]] |
| “直接/一级/二级索引” | 先算索引块能容纳多少地址项，再划分寻址范围 | [[文件多级索引]] |
| “空闲磁盘块、位图” | 先算物理块总数，再一块一 bit；问位置时再做定位 | [[位示图与空闲空间管理]] |
| “磁头移动、初始方向” | 先确定当前磁头、请求队列和方向，再逐段累加 | [[磁盘调度算法]] |
