# 文件多级索引：一级、二级“间接”在哪里

> [!summary] 快速复习卡片
> **作用/定位**：多级索引用“索引块里再放地址”扩大单个文件能够定位的数据块数量，解决 inode/FCB 中直接指针数量有限的问题。
> **核心结论**：一级间接指针先指向一个索引块，这个索引块本质上就是“数据块地址清单”；二级间接则先指向一批一级索引块地址，再由它们指向数据块。
> **经典题型怎么做**：先算一个索引块能装多少个地址项 → 一级间接能定位“这么多个数据块” → 二级间接再乘一次“每索引块地址项数” → 最后按题目数据块大小换算容量。
> **易错点 / 考试重点**：一级间接不是“索引再指向索引块”，而是指针直接找到索引块，索引块里的每一项再指向真实数据块。

## 先定位：这是索引分配解决大文件寻址的方法

元数据中的地址项有限。直接地址直接给出数据块号；间接地址先指向一个索引块，再由索引块保存更多块号。层级越深，容量越大，但首次访问需要读取更多索引块。

## 三种地址怎样走

~~~mermaid
flowchart TD
    A[文件逻辑块号] --> B{落在哪个区间}
    B -->|直接区| C[数据块]
    B -->|一级间接区| D[一级索引块]
    D --> C
    B -->|二级间接区| E[一级目录索引]
    E --> F[二级索引块]
    F --> C
~~~

- **直接地址**：地址项就是数据块号。
- **一级间接**：地址项指向一个索引块，索引块的每项再指向数据块。
- **二级间接**：第一层索引项指向第二层索引块，第二层项再指向数据块。

## 容量公式

若块大小为 (B) 字节，每个块号占 (a) 字节，则每个索引块可存：

[
n=rac{B}{a}
]

若有 (d) 个直接地址、一个一级间接地址和一个二级间接地址，可寻址的数据块数为：

[
d+n+n^2
]

最大文件容量为：

[
(d+n+n^2)	imes B
]

例：(B=4	ext{KB})、(a=4	ext{B})，则 (n=1024)。一级间接覆盖 1024 个数据块，二级间接覆盖 (1024^2) 个数据块。

## 块号边界题怎么做

1. 先确认题目从 0 还是从 1 编号。
2. 先扣除直接地址覆盖的块数。
3. 再判断落入一级还是二级间接区。
4. 进入某层后，用整除求索引项、取模求层内偏移。

> [!warning] 最常见错误
> 索引块本身保存的是“地址项”，不是文件数据；题目问可存多少数据时，不要把索引块当成数据块重复计入。若题目另给指针层数或索引块也占文件空间，按题干口径计算。

## 代价与适用性

小文件多用直接地址，访问路径短；文件变大才进入间接层。多级索引避免预留巨大的连续空间，但索引块占空间，冷缓存时也会增加 I/O 次数。
