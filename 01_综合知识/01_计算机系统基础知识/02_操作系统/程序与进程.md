# 程序与进程：静态代码怎样变成受管理的执行实例

> [!summary] 快速复习卡片
> **作用/定位**：程序是静态的代码和数据，进程是程序的一次动态执行过程；操作系统真正调度和管理的是进程。
> **核心结论**：一个程序可以对应多个进程；同一进程在运行期间会经历状态变化并拥有自己的运行现场。
> **题干怎么认**：看到“静态/动态、一次执行、资源占用、调度对象”时，先区分程序与进程。
> **易错点 / 考试重点**：程序不等于进程；“程序放在磁盘上”不能说明它正在运行。

## 先定位：程序是材料，进程是一次运行

程序是存储介质上的指令与数据集合，本身是静态的；进程是程序在某个输入和资源环境中的一次执行活动，是操作系统分配资源和进行管理的基本对象之一。

## 创建一个进程发生什么

1. 操作系统建立进程标识和 PCB。
2. 为进程建立地址空间或相关内存映射，装入/映射程序代码和初始数据。
3. 初始化寄存器上下文、栈、打开文件等运行环境。
4. 将进程置为就绪，等待调度器分配 CPU。
5. 获得 CPU 后运行；阻塞、抢占或结束时，OS 更新 PCB 和资源状态。

同一个程序可同时产生多个进程。它们通常拥有各自的地址空间、PCB、运行现场和资源引用，所以执行位置、输入与结果可以不同。

| 对比 | 程序 | 进程 |
| --- | --- | --- |
| 性质 | 静态代码与数据 | 动态执行实例 |
| 是否有状态转换 | 没有 | 有就绪、运行、阻塞等 |
| 是否有 PCB | 没有 | 有 |
| 与程序关系 | 可被多次执行 | 一个进程可装入程序并在运行中切换映像 |

> [!warning] “进程就是运行中的程序”只适合入门记忆
> 进程还包括地址空间、CPU 上下文和资源等；现代系统中一个进程也可包含多个线程。

## 考试怎么认

- “静态、有序指令集合” → 程序。
- “动态、并发、状态转换、资源与 PCB” → 进程。
- “同一程序运行两次” → 通常是两个独立进程实例。
