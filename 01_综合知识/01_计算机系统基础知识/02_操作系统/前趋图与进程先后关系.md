# 前趋图：箭头到底表示谁必须先完成

> [!summary] 快速复习卡片
> **作用/定位**：前趋图用有向无环图描述进程或程序段的先后约束。
> **核心结论**：箭头 **Pi → Pj** 表示 **Pi 必须先完成，Pj 才能开始**。
> **经典题型怎么做**：逐条沿图上的箭头抄成有序对 → 核对箭头方向 → 不要把“能沿多条边间接到达”自动补成一条直接边。
> **真题信号**：2019、2020、2022 都直接考过“图 ↔ 前趋关系集合”。
> **易错点**：没有前趋的结点叫初始结点；没有后继的结点叫终止结点。前趋图必须无环，否则先后约束会自相矛盾。

## 为什么它和同步有关

如果 P1 的结果必须被 P2 使用，那么 P2 就不能抢在 P1 完成之前执行。

前趋图只是把这种依赖关系画出来：

~~~mermaid
flowchart LR
    P1[P1] --> P2[P2]
    P1 --> P3[P3]
    P2 --> P4[P4]
    P3 --> P4
~~~

读图：

- P1 必须在 P2 前完成；
- P1 必须在 P3 前完成；
- P2、P3 都完成后，P4 才具备完整前置条件。

## 选择题固定动作

1. 从一个结点出发，看它**实际画了哪些出边**。
2. 每条箭头记成“起点在前、终点在后”的有序对。
3. 对照选项逐条排除方向颠倒、漏边、多边。
4. 不要因为 P1 → P2 → P4，就擅自把 P1 → P4 当成图中直接边。
