## 高频题型的第一反应

| 看到题干 | 先做什么 |
| --- | --- |
| “静态指令集合”与“正在执行” | 区分程序和进程；再看是否出现 PCB、状态或资源 |
| 父子进程 | 分开判断进程身份、PCB、地址空间与资源继承，不把“有关系”当成“同一个进程” |
| 运行、就绪、阻塞 | 先判断事件是获得 CPU、等待资源/I/O，还是等待事件完成 |
| 互斥、同步、empty/full/mutex | 先分“不能同时”还是“必须先后”，再检查 P/V 顺序 |
| 同类资源最少数量 | 让进程尽量都处在“还差 1 个”的状态，再留 1 个资源打破僵局 |
| 页框位图 | 先数物理页框，再按一框一 bit 换算单位 |
| 分页地址 | 页号查页表换页框，页内偏移保持不变 |
| 文件多级索引 | 先算一个索引块能容纳多少地址项，再判断直接/一级/二级范围 |
| 磁盘调度 | 先定当前磁头、请求顺序和初始方向，再逐段累加移动距离 |

## P1 只抓必要动作

- OS入口：能把题干定位到处理机、存储、文件或设备管理；特点、类型和微内核分别回到对应原子卡。
- 进程：会区分程序/进程，读懂 PCB、状态转换、调度和前趋图。
- PV：会判断信号量初值、P/V职责，以及生产者—消费者的先后顺序。
- 分页/虚拟存储：会做页框位图、地址转换、缺页和 LRU/Clock 的最小推演。
- 文件：会沿“目录项 → FCB/inode → 块映射 → 数据块”定位，并处理多级索引和位示图。
- 设备：P2 先掌握 SPOOLing 和磁盘调度的题干识别，不提前扩写缓冲细节。
