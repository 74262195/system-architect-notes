# 虚拟存储与页面置换：专题入口

旧卡把“为什么能不全装、缺页怎么处理、四种置换算法”放在一起。现在拆成：

1. [[虚拟存储的基本概念]]
2. [[缺页处理过程]]
3. [[OPT页面置换算法]]
4. [[FIFO页面置换算法]]
5. [[LRU页面置换算法]]
6. [[Clock页面置换算法]]

主线不要倒过来：

> **虚拟存储允许不全装 → 访问未驻留页发生缺页 → 有空框直接装 → 没空框才需要页面置换 → 四种算法只是在回答“换谁”。**

> [!important] 当前优先级
> 第一轮先抓 **虚拟存储、缺页、LRU、Clock（P1）**；OPT、FIFO 当前 P2。2019 题还出现“访问位 + 修改位”组合，做题时要识别访问历史和写回代价。
