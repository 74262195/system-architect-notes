# 机器指令格式：CPU 怎样知道做什么、数据在哪里

> [!summary]- 快速复习卡片（学完再看）
> **核心结论**：机器指令至少要表达“做什么”和“对谁做”，通常表现为操作码与地址码。
> **地址数判断**：三地址写两源一结果；二地址常让一个地址兼作结果；一地址依赖累加器；零地址常依赖栈顶。
> **再分一层**：地址数看“显式写了几个地址字段”；寻址方式看“CPU 怎样解释字段并找到操作数”。
> **易错点**：地址数减少不等于不需要操作数；“二地址指令”和“直接寻址”也不是同一个分类维度。

高级语言中的 `a = b + c` 对人很清楚，但 CPU 还需要知道：执行加法还是减法？`b`、`c` 在哪里？结果放到哪里？

**直接答案：操作码告诉 CPU“做什么”，地址码告诉 CPU“操作数或结果在哪里”；没有写在指令里的位置，也可能由累加器、栈顶或程序计数器等约定隐含。**

## 一条指令需要表达哪些信息

| 信息 | 作用 |
| --- | --- |
| 操作码 | 指明加、减、传送、跳转等操作性质 |
| 操作数地址 | 指明输入数据从哪里取得 |
| 结果地址 | 指明处理结果保存到哪里 |
| 下条指令地址 | 大多数情况下由程序计数器顺序给出；发生转移时由指令改变 |

教材把机器指令概括为由**操作码和操作数**组成；在指令格式中，操作数、结果等位置通常通过地址码表达。这里的“地址”不一定只指主存单元，也可能指寄存器或指令格式允许的其他操作数位置，具体由指令系统规定。

## 地址码已经写了位置，为什么还需要“寻址方式”

这里最容易混的是**地址码**和**寻址方式**。

- **地址码/地址字段**：是指令格式里实际写进去的一段信息，回答“这条指令给了 CPU 什么位置线索”；
- **寻址方式**：是 CPU 解释这段信息的规则，回答“这段线索到底怎样得到真正的操作数或有效地址”。

所以，“二地址、三地址”是在数**一条指令显式写了几个地址字段**；“立即、寄存器、直接、间接、变址”等是在判断**CPU 怎样解释操作数位置**。它们是两个不同维度，不能互相替代。

例如，看到某个地址字段里写了一个值，仅凭这个值本身还不能判断它究竟是操作数本身、寄存器位置、主存地址，还是还需要继续求真正地址；要结合寻址规则才能确定。

> [!important] 唯一主事实源
> 本章只负责把“指令格式”与“寻址方式”接起来，不在这里复制五种寻址方式的完整机制。立即、寄存器、直接、间接、变址以及有效地址怎样判断，统一看 CPU 章节的 [[指令寻址方式]]。

**考试第一动作**：题干问“几地址指令”，先数显式地址字段；题干问“操作数在哪里、真正地址怎样得到、EA 怎样确定”，就进入**寻址方式**，不要继续按地址字段数量判断。

## 零、一、二、三地址到底少了什么

用“把 `B + C` 的结果放入 `A`”观察最直观：

| 类型 | 示意 | 没写出的信息从哪里来 |
| --- | --- | --- |
| 三地址指令 | `ADD A, B, C` | 两个源和结果都显式给出 |
| 二地址指令 | `ADD A, B` | 通常 `A` 既是一个源，又接收结果 |
| 一地址指令 | `ADD B` | 另一个源和结果通常隐含在累加器中 |
| 零地址指令 | `ADD` | 操作数通常隐含在栈顶，结果压回栈中 |

“三地址、二地址”说的是一条指令中**显式地址字段的数量**，不是程序一共访问多少次内存，也不是指令只能处理几个数据。

## CPU 执行时怎样用这些字段

```mermaid
flowchart LR
    A[取出指令] --> B[识别操作码]
    B --> C[按地址码取得操作数]
    C --> D[执行操作]
    D --> E[保存结果]
```

这条流程把前面“高级语言最终变成机器指令”继续落到了 CPU 可执行的字段上。具体机器码因 x86、ARM 等指令集而异，考试应掌握稳定结构，不背一串脱离平台的二进制。

> [!question] 自测
> 1. 二地址指令比三地址指令少写的结果位置通常怎样处理？
>
> > [!answer]- 第 1 题答案与解析
> > **答案**：通常让其中一个地址既表示源操作数，也表示结果位置。
> > **解析**：地址字段减少靠约定复用或隐含信息，不代表计算不产生结果。
>
> 2. 零地址指令为什么仍然能够完成加法？
>
> > [!answer]- 第 2 题答案与解析
> > **答案**：操作数位置由运行模型隐含，典型情况是从栈顶取得两个操作数并把结果压回栈中。
>
> 3. “二地址指令”和“直接寻址”是在回答同一个问题吗？
>
> > [!answer]- 第 3 题答案与解析
> > **答案**：不是。
> > **解析**：二地址是在数指令中显式写了几个地址字段；直接寻址是在说明 CPU 怎样解释字段并定位操作数。完整寻址机制见 [[指令寻址方式]]。
