# 汇编语言语句：哪些交给 CPU，哪些只指挥汇编器

> [!summary]- 快速复习卡片（学完再看）
> **核心结论**：指令语句通常生成机器指令；伪指令只指导汇编过程；宏指令先展开成一组语句再汇编。
> **题干信号**：`MOV/ADD` → 指令；定义数据、分配存储、标记段等 → 伪指令；用一个宏名代替一组语句 → 宏指令。
> **易错点**：汇编源程序中的每一行不都会被 CPU 直接执行。

机器指令是一串二进制，直接书写和维护都很困难。汇编语言用 `MOV`、`ADD` 等助记符代替操作码，但汇编源程序中还需要告诉翻译工具怎样组织数据和程序。

**直接答案：指令语句描述 CPU 要执行的动作；伪指令描述汇编器在翻译期间要做的事；宏指令让汇编器先把一个名字展开成预先定义的一组语句。**

## 三类语句怎样区分

| 类型 | 谁处理 | 是否直接对应一条机器指令 | 主要作用 |
| --- | --- | --- | --- |
| 指令语句 | 汇编后交给 CPU 执行 | 通常是 | 表达传送、运算、跳转等机器操作 |
| 伪指令语句 | 汇编器 | 否 | 定义数据、分配存储、组织段或控制汇编过程 |
| 宏指令语句 | 汇编器先展开 | 不一定；展开后可能对应多条 | 用一个宏名复用一组常用语句 |

## 一条汇编语句通常有哪些字段

教材给出的基本观察方式是：一条语句可以包含**标号、操作码或伪操作、操作数、注释**等字段。并不是每条语句都必须把所有字段写全。

- **标号**：给某个位置起名字，便于跳转或引用；
- **操作码/伪操作**：说明执行什么机器动作，或要求汇编器做什么；
- **操作数**：给出寄存器、数据或地址等对象；
- **注释**：供人阅读，不参与机器执行。

## 从源语句到 CPU 执行

```mermaid
flowchart LR
    A[汇编源程序] --> B[展开宏]
    B --> C[处理伪指令]
    C --> D[翻译指令语句]
    D --> E[生成机器代码]
```

这张图的重点不是规定所有汇编器都必须按同一内部阶段实现，而是区分三类语句最终的去向：**伪指令本身不作为机器动作执行，宏也要先展开，真正交给 CPU 的是生成后的机器指令。**

## 自测

1. “为变量预留若干存储单元”更可能属于指令还是伪指令？

> [!answer]- 第 1 题答案与解析
> **答案**：伪指令。
> **解析**：它是在指导汇编器组织数据和存储，不是要求 CPU 在运行时执行一次运算。

2. 宏指令为什么不能简单等同于一条机器指令？

> [!answer]- 第 2 题答案与解析
> **答案**：宏名会先展开为预先定义的一组语句，展开结果可能包含多条指令。
