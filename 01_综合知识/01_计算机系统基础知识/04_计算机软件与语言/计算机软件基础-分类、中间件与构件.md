# 计算机软件与语言：软件从哪里来，怎样交给机器执行

操作系统解决了“谁来管理 CPU、内存和设备”，但计算机上还要运行各种软件。接下来要回答两个连续问题：**软件按用途怎样分类？人写出的程序怎样一步步变成 CPU 能执行的指令？**

## 本章学习主线

```mermaid
flowchart LR
    A[软件分类] --> B[公共运行服务]
    B --> C[构件复用]
    C --> D[计算机语言]
    D --> E[机器指令]
    E --> F[汇编语句]
```

程序不仅要被执行，还要在编码前表达结构、在关键场景下精确说明约束，因此语言主线继续到建模语言和形式化语言。

```mermaid
flowchart LR
    A[汇编与高级语言] --> B[建模语言]
    B --> C[形式化规格]
    C --> D[多媒体]
```

## 按顺序学习

1. [[计算机软件分类]]：系统软件和应用软件分别解决什么问题；应用软件怎样区分通用与专用。
2. [[中间件]]：异构系统之间为什么需要公共服务层。
3. [[软件构件与构件组装]]：软件怎样通过统一接口被复用和组装。
4. [[计算机语言-编译与解释]]：机器、汇编、高级语言是什么关系，编译与解释怎样区分。
5. [[机器指令格式与地址数]]：CPU 最终执行的指令由哪些字段组成，零/一/二/三地址是什么意思。
6. [[汇编语言的指令、伪指令与宏指令]]：汇编源程序中的语句是否都会变成机器指令。
7. [[建模语言与UML]]：UML 为什么属于建模语言，但完整内容放到软件工程学习。
8. [[形式化语言与规格说明]]：怎样用精确符号消除需求歧义，并贯穿开发过程。

> [!tip] 做题入口
> 管理资源 → 系统软件；解决业务 → 应用软件；跨平台公共服务 → 中间件；统一接口复用 → 构件；操作码和地址码 → 机器指令；助记符 → 汇编；词法/语法/语义 → 编译过程；图形化描述系统 → UML；精确可推理的规格 → 形式化语言。
