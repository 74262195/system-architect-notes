# 数据表示与编码：冲刺复习

> [!summary] 5 分钟目标
> 先回答一个问题：**现实中的数值和字符，进入计算机以后怎样变成 0 和 1。**

## 优先拿分

### P1：原码、反码、补码、移码
- 正数的原码、反码、补码通常相同。
- 负数求补码：**符号位不动，数值位取反再加 1**。
- 补码还原负数也可以用“取反 + 1”理解。
- 移码常用于方便比较阶码大小；在常见题型中，可理解为补码最高位取反。

### P1：定点数与浮点数
- **定点数**：小数点位置事先约定，表示范围有限，但实现简单。
- **浮点数**：把数拆成阶码和尾数，用更大的表示范围换来更复杂的表示。
- 做题先区分题目问的是“数值怎样写成二进制”，还是“这个二进制数采用什么机器表示方式”。

## 第二轮扫一遍

### 进制转换
- 二进制转十进制：按位权相加。
- 十进制整数转二进制：不断除以 2，余数倒序。
- 十进制小数转二进制：不断乘以 2，依次取整数部分。

### 字符编码
- 字符编码解决的是“字符如何用二进制编号表示”，不是数值运算。
- 看题时区分 ASCII、Unicode 等“字符编号体系”和数值的原反补码。

## 最容易混淆

| 易混点 | 正确记法 |
| --- | --- |
| 有符号数是不是负数？ | 不是；有符号数包括正数、0、负数 |
| 补码只有负数才有吗？ | 不是；正数也有补码 |
| 浮点数是不是“小数专用”？ | 不是；它是一种扩大数值表示范围的方法 |
| 字符编码和二进制数值表示一样吗？ | 不一样；一个给字符编号，一个表示数值 |

## 考前自测

1. 负数怎样从原码得到补码？
2. 补码怎样还原负数的绝对值？
3. 定点数和浮点数最核心的区别是什么？
4. 二进制转十进制时“权”是什么意思？
