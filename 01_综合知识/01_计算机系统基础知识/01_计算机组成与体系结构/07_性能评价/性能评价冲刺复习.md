# 性能评价：冲刺复习

> [!summary] 5 分钟目标
> 前面所有设计最后都要回答：**到底快不快，快在哪里，局部优化对整体到底值不值。**

## P1：CPU 性能指标

不要只看到“主频高”就判断更快。

CPU 执行时间受：
- 要执行多少条指令；
- 每条指令平均需要多少时钟周期；
- 一个时钟周期有多长。

MIPS、主频、CPI 都只是某个角度；跨指令集、跨工作负载时不能机械拿单个指标比较。

## 性能评价与基准测试

常见维度不只有速度：
- 响应时间；
- 吞吐量；
- 成本；
- 功耗；
- 可靠性；
- 可扩展性。

基准测试的价值是用约定工作负载比较系统，但必须注意测试负载是否代表真实场景。

## P1：Amdahl 定律

Amdahl 的核心不是背公式，而是：

> **整体加速受“没有被优化的那部分”限制。**

如果程序只有一小部分能被加速，那么即使把这一小部分提速很多，整体收益仍然有限。

做题先找两个量：
1. 可优化部分占整体多少；
2. 这部分被加速了多少倍。

## 最容易混淆

| 易混点 | 正确记法 |
| --- | --- |
| 主频高一定更快？ | 不一定，还看 CPI、指令数和负载 |
| MIPS 越大一定更强？ | 不适合脱离指令集和负载直接横比 |
| 局部加速无限大，整体也能无限快？ | 不能，未优化部分形成上限 |
| 吞吐量和响应时间一样吗？ | 不一样；一个看单位时间完成多少，一个看一次任务多久完成 |

## 考前自测

1. CPU 执行时间受哪三个核心因素影响？
2. 为什么不能只用主频判断 CPU 性能？
3. Amdahl 定律为什么强调“不可优化部分”？
4. 响应时间和吞吐量的关注点分别是什么？
