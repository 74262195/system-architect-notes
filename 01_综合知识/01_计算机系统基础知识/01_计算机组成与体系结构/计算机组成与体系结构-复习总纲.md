重点：
- P1：[[数据表示与编码-原反补移码]]

一句话：

## 2. CPU 怎样执行这些数据和指令

常见寄存器：
- PC：下一条指令地址；
- IR：当前指令；
- MAR：访存地址；
- MDR：访存数据。

指令主线：
> **取指 → 译码 → 执行 → 下一条。**

流水线：
> **让多条指令的不同阶段重叠，提高吞吐。**

冒险：
- 结构：抢硬件；
- 数据：等结果；
- 控制：不知道下一条去哪。

## 3. 数据放在哪里

存储层次的根本原因：
> **快、容量大、便宜无法同时做到，所以采用分层。**

P1：
- [[Cache-命中率与平均访问时间]]
- [[Cache-映射方式]]

必须会区分：
- SRAM vs DRAM；
- 位扩展 vs 字扩展；
- 直接映射 / 全相联 / 组相联；
- RAID 0 / 1 / 5 / 10。

Cache 计算题先用自然语言：
> **命中走快路径，未命中走慢路径，按概率算平均。**

总线三类：
- 数据：传什么；

I/O 控制看 CPU 参与程度：

DMA：
> **大块数据主要在设备和主存之间搬运。**

## 5. 数据传错了怎么办

| 方法 | 主要能力 | 记忆点 |
| --- | --- | --- |
| 奇偶校验 | 简单检错 | 偶数位同时翻转可能漏检 |
| CRC | 强检错 | 补 0 → 模 2 除 → 余数 |
| 海明码 | 单比特纠错 | 校验位在 1、2、4、8…… |

CRC：
> **生成多项式对应二进制有 n 位，就补 n-1 个 0，再做模 2 除法。**

海明码保留的重要关系：

$$2^r \ge m+r+1$$

---

## 6. 一台机器还能怎样组织

先分清几个维度：

- 冯·诺依曼 / 哈佛：**指令和数据的存储/通路组织方式**。
- MPU / MCU / DSP / SoC / FPGA / GPU：**处理器或计算平台定位**。
- Flynn：**指令流 × 数据流分类**。
- 共享内存 / 消息传递：**并行任务之间怎样通信**。

Flynn 四类：
- SISD
- SIMD
- MISD
- MIMD

最容易错：
> **Flynn 分类和共享内存/消息传递不是同一套分类。**
