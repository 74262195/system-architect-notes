# I/O 接口：CPU 和外设为什么不能直接硬接

> [!summary] 快速复习卡片
> **作用/定位**：I/O 接口位于 CPU/系统总线与具体外设之间，负责把两边的速度、格式和控制方式适配起来  
> **核心职责**：地址译码、数据缓冲、状态/控制、格式转换、时序协调  
> **经典题型怎么做**：题干即使没出现“I/O 接口”，只要出现“**系统间异步串行通信 + 串/并或并/串转换**”，就要先想到串行通信接口内部的**移位寄存器**  
> **隐藏前提**：CPU 一侧通常按字节/字并行处理，通信线路按位串行发送；两种格式之间必须有一个接口电路完成转换，这个角色就是串行 I/O 接口（如 UART 一类接口）  
> **动作直觉**：发送时 CPU 把一组并行位交给接口，接口移位寄存器再逐位发出；接收时逐位移入，凑成一组后再交给 CPU  
> **易错点**：看到“移位”不要自动想到 CPU；题目问的是**系统通信路径上的格式转换由谁负责**，通常由接口硬件承担


## CPU 快、格式统一，外设却又慢又杂

键盘、打印机、磁盘、串口设备的速度、数据格式和控制方式都不同。CPU 若直接适配每一种设备，会把设备差异全部拖进 CPU 设计。

I/O 接口就是中间的“翻译和缓冲层”，典型职责包括：

- **地址译码**：判断 CPU 正在访问哪个设备/寄存器。
- **数据缓冲**：缓解 CPU 与外设速度差。
- **状态与控制寄存器**：交换“忙/就绪/错误”和控制命令。
- **格式转换**：例如串行与并行之间转换。
- **协调时序**：适配不同速度和通信节奏。

2009 年真题曾考异步串行通信中的串并转换，经典实现会使用接口中的**移位寄存器**。

~~~mermaid
flowchart LR
    CPU[CPU/系统总线] <--> IF[I/O 接口]
    IF <--> DEV[外部设备]
~~~

## 一句话记住

> **I/O 接口负责“认设备、缓速度、换格式、报状态、收控制”，把千奇百怪的外设隔离在 CPU 外面。**
