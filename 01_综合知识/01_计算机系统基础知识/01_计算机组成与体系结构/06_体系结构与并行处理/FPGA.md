# FPGA：为什么它不像 CPU 那样“执行程序”，却也能做计算

## 先定位：FPGA 是可重配置数字硬件，不是另一种普通 CPU

前面的 CPU、GPU 都有一个共同点：芯片内部的主要硬件结构已经设计好，运行时通过指令决定它们做什么。

**FPGA（Field-Programmable Gate Array，现场可编程门阵列）** 则属于**可编程逻辑器件**。用户可以在芯片制造完成以后，重新配置内部逻辑单元和互连关系，让它变成针对某项任务的数据通路。

所以 FPGA 的“可编程”和 CPU 的“写程序”不是同一层意思：

> **CPU/GPU 主要是给固定硬件换指令；FPGA 可以把硬件逻辑本身重新配置。**

在这一章把它放在 GPU 后面，是为了继续认识不同的计算实现路线。**FPGA 与 Flynn 分类不是前后推导关系**：FPGA 是一种可重配置硬件实现方式，Flynn 是按指令流和数据流划分计算机体系结构的分类方法。


## CPU 换软件，FPGA 可以重配硬件逻辑

CPU 的硬件数据通路基本固定，靠指令控制它做不同工作；FPGA 内部有大量可编程逻辑和互连资源，可以按设计重新配置成特定数字电路。

因此 FPGA 的核心优势是：

- **并行度高**：多个逻辑单元可真正同时工作。
- **可定制**：针对特定算法构造专用数据通路。
- **可重配置**：不像固定 ASIC 那样制造后就完全不能改变。

代价是开发方式、工具链和硬件资源约束都与普通 CPU 编程不同。

## 一句话记住

> **CPU 是“固定硬件跑不同指令”，FPGA 是“把可编程逻辑重新接成需要的硬件”。**
