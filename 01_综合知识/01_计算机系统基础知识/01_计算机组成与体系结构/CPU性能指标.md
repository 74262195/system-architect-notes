# CPU 性能指标：主频高为什么不等于程序一定快

## 先定位：为什么从 CPU 结构又走到了“性能指标”

前面学 CPU 时主要在回答“CPU **由什么组成、怎样执行指令**”。现在开始换一个观察角度：

> **同样都能执行程序，两颗 CPU 到底谁更快？快在哪里？**

因此这篇讲的不是新的 CPU 部件，而是**衡量 CPU 执行能力的一组指标**。主频描述时钟节拍有多快，CPI 描述一条指令平均需要多少拍，指令数描述程序一共要做多少工作；它们共同影响 CPU 执行时间。

这张卡属于 [[计算机性能指标与Amdahl定律|性能专题]] 的第一站：先认识“怎么量”，后面再看 [[性能评价与基准测试]] 为什么不能只拿一个硬件参数比较整台机器。


## “快”至少要区分节拍、每条指令成本和指令数量

### 时钟周期与主频

$$f=\frac{1}{T_{clock}}$$

主频越高，每秒时钟节拍越多，但程序还要看每条指令需要多少周期。

某些经典题还会给外频与倍频：

$$主频=外频\times倍频$$

2018 年真题就直接考过这一关系。

### CPI 与 CPU 时间

$$CPI=\frac{总时钟周期数}{指令条数}$$

$$T_{CPU}=IC\times CPI\times T_{clock}$$

其中 $IC$ 是指令条数。

### MIPS

$$MIPS=\frac{主频}{CPI\times10^6}$$

MIPS 表示每秒执行多少百万条指令，但不同指令集的一条“指令”工作量可能不同，所以不能脱离指令集和负载直接比较机器优劣。

2012 年真题考过由机器周期推算 Peak MIPS。

## 一句话记住

> **主频管节拍，CPI 管每条指令要几拍，IC 管一共几条；程序时间三者缺一不可。**
