# 存储层次与局部性：为什么不用一种存储器包打天下

## 又快、又大、又便宜，三件事很难同时满足

寄存器和 Cache 很快，但昂贵且容量小；外存容量大、便宜，却慢得多。如果只选一种存储器，就会在速度、容量和成本之间付出巨大代价。

| 层次 | 典型位置 | 趋势 |
| --- | --- | --- |
| 寄存器 | CPU 内部 | 最快、最小、最贵 |
| Cache | CPU 附近 | 很快、容量较小 |
| 主存 | DRAM | 容量更大、速度更慢 |
| 外存 | SSD/磁盘等 | 最大、最慢、单位容量便宜 |

2014 年真题曾直接问：分级存储体系主要为了解决什么？核心就是**容量、价格和速度之间的矛盾**。

## 分层为什么真能提速：局部性

- **时间局部性**：刚访问过的数据，很可能很快再次访问。
- **空间局部性**：刚访问某个位置后，很可能继续访问它附近的数据。

循环变量体现时间局部性，顺序遍历数组体现空间局部性。

~~~mermaid
flowchart LR
    A[程序访问集中在局部] --> B[热点数据放高层]
    B --> C[多数访问在快层命中]
    C --> D[平均访问时间下降]
~~~

## 一句话记住

> **存储层次用“少量快存储 + 大量慢存储”折中成本，而局部性保证热点数据真的值得放在上层。**
