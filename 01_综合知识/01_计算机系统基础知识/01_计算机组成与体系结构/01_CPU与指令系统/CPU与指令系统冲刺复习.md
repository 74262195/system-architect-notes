# CPU 与指令系统：冲刺复习

> [!summary] 5 分钟目标
> 把 CPU 理解成一条主线：**取指令 → 译码 → 执行 → 再取下一条；流水线只是让多条指令重叠执行。**

## CPU 里面有什么

- **运算器**：做算术、逻辑运算。
- **控制器**：解释指令并发出控制信号。
- 常见寄存器：
  - PC：下一条要取的指令地址。
  - IR：当前正在执行的指令。
  - MAR：准备访问的存储器地址。
  - MDR：从存储器读出或准备写入的数据。

## 指令怎样执行

记住主线：

**PC 给地址 → 从存储器取指 → 指令进入 IR → 译码 → 执行 → PC 指向后续指令。**

不要把“断点”“PCB”“PC”混为一谈：PC 是寄存器；PCB 是操作系统保存进程状态的数据结构。

## 指令系统

### CISC 与 RISC
- CISC：指令较复杂、种类较多。
- RISC：指令较规整，常采用 Load/Store 思路，更利于流水线。
- 现代处理器会互相借鉴，不要把两者理解成绝对对立。

### 寻址方式
题目本质是在问：**操作数在哪里，CPU 怎样找到它。**
看到立即数、寄存器、存储器地址、间接地址时，先判断“真正的数据在哪一级”。

## 流水线

流水线不是让“一条指令变快很多”，而是让**多条指令的不同阶段重叠**，提高吞吐。

重点记：
- 流水线周期由最慢阶段限制。
- 理想情况下，流水线填满后可以持续完成指令。
- 冒险 = 后一条指令现在继续执行可能会用错资源、数据或控制方向。

三类冒险：
- **结构冒险**：争同一硬件资源。
- **数据冒险**：后一条需要前一条尚未产生的数据。
- **控制冒险**：分支结果未确定，不知道下一条该取哪条。

常见处理：停顿/气泡、转发、增加资源、分支预测等。

## 考前自测

1. PC、IR、MAR、MDR 分别保存什么？
2. 一条指令从取指到执行的大致过程是什么？
3. RISC 为什么通常更利于流水线？
4. 数据冒险为什么不能让后续指令“硬着头皮继续”？
