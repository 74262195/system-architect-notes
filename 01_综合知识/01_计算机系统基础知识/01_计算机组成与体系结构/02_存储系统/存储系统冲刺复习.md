# 存储系统：冲刺复习

> [!summary] 5 分钟目标
> 先抓住矛盾：**CPU 很快，但又快、又大、又便宜的存储器做不到，所以才有 Cache → 主存 → 外存的层次。**

## P1：Cache 命中率与平均访问时间

做题不要先背复杂公式，先分两种情况：
- 命中：只付 Cache 的访问时间。
- 未命中：按题目口径再付主存访问代价。

核心就是：**按命中和未命中的概率加权计算平均时间。**

## P1：Cache 映射方式

本质在问：**主存的一块，可以放到 Cache 的哪些位置。**

- 直接映射：只能放一个固定位置，简单但冲突多。
- 全相联：可以放任意位置，灵活但硬件复杂。
- 组相联：先定组，再在组内任选，是两者折中。

## 存储层次与器件

- SRAM：快、贵、不需要刷新，常用于 Cache。
- DRAM：密度高、便宜、需要刷新，常用于主存。
- ROM/Flash：重点是非易失性以及写入方式区别。
- 局部性是 Cache 有效的基础：最近用过的、附近的数据更可能再次被访问。

## 存储器扩展

题目通常只有两类：
- **位扩展**：CPU 一次要的位数比单颗芯片宽，多片并行拼“宽度”。
- **字扩展/地址扩展**：需要的地址数量比单颗芯片多，多片拼“容量”。

看到 `32K×16`：
- 32K = 有多少个可寻址位置；
- 16 = 每个位置存多少 bit。

## 外存、磁盘与 RAID

磁盘访问时间通常关注：
- 寻道；
- 旋转等待；
- 数据传输。

RAID 先抓能力：
- RAID 0：条带化，性能好，无冗余。
- RAID 1：镜像。
- RAID 5：分布式奇偶校验，允许一块盘故障。
- RAID 10：镜像 + 条带，性能与冗余兼顾。

## 考前自测

1. 为什么需要存储层次？
2. SRAM 和 DRAM 的核心区别是什么？
3. 直接映射、全相联、组相联分别允许数据放哪里？
4. 位扩展和字扩展分别解决什么“不够”？
5. RAID 0 为什么不能提供容错？
