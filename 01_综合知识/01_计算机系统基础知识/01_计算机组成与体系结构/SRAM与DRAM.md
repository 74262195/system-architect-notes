# SRAM 与 DRAM：为什么 Cache 和主存不用同一种芯片

## 先定位：SRAM 和 DRAM 不是两种“存储层次”，而是两种 RAM 实现

前面的 [[存储层次与局部性]] 讲的是**寄存器、Cache、主存、外存为什么要分层**。现在开始往主存硬件里面再看一层：这些存储位置具体用什么半导体技术做出来？

**RAM（Random Access Memory，随机存取存储器）** 是一类可以按地址读写的半导体存储器。在这里要比较的：

- **SRAM（Static Random Access Memory，静态随机存取存储器）**；
- **DRAM（Dynamic Random Access Memory，动态随机存取存储器）**。

两者都属于 RAM，也都属于**易失性存储**：断电后内容会丢失。它们真正的差别在于存储单元怎么实现，因此带来速度、成本、密度和是否需要刷新的差异。

所以本卡是在回答：

> **同样都是 RAM，为什么 Cache 常选 SRAM，而大容量主存常选 DRAM？**


## 如果 SRAM 更快，为什么内存不全用 SRAM

答案不是“做不到”，而是成本和密度不划算。

| 对比 | SRAM | DRAM |
| --- | --- | --- |
| 基本存储方式 | 双稳态电路 | 电容电荷 |
| 速度 | 快 | 相对慢 |
| 密度/成本 | 密度低、贵 | 密度高、便宜 |
| 刷新 | 不需要周期刷新 | 需要刷新 |
| 断电 | 数据丢失 | 数据丢失 |
| 典型用途 | Cache | 主存 |

DRAM 的电容会逐渐漏电，所以必须刷新；SRAM 只要持续供电，稳定状态不需要周期刷新。

## 考试怎么认

- “Cache 通常采用哪种存储器” → SRAM。
- “主存通常采用哪种 RAM” → DRAM。
- “需要刷新” → DRAM。
- “不刷新但掉电仍丢数据” → SRAM。

## 一句话记住

> **SRAM 快贵不刷新做 Cache，DRAM 慢些便宜要刷新做主存；两者都属于易失性 RAM。**

## 自测

1. DRAM 为什么必须刷新？
2. SRAM 不刷新是否意味着它掉电不丢？
3. 为什么大容量主存更倾向 DRAM？
