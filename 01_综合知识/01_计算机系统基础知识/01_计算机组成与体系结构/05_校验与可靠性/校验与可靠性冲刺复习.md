## 一张表先分清三种校验

| 方法 | 优先级 | 主要能力 | 考试看到什么要想到 |
| --- | --- | --- | --- |

## CRC：30 秒复习

记这一条即可：

> **补 0 → 看最高位 → 最高位 1 就 XOR，最高位 0 就跳过 → 拉下一位 → 最后 n-1 位是 CRC。**

### 考试手算卡

生成码有 **n 位**：

1. 原始数据后补 **n-1 个 0**。
2. 当前最高位是 **1**：和生成码做 XOR。
3. 当前最高位是 **0**：不做 XOR，直接丢掉这一位。
4. 从原来补 0 后的数据中**拉下一位**继续。
5. 没有下一位可拉时停止，最后保留 **n-1 位余数**作为 CRC。

例：数据 `1001`，生成码 `1011`

- `1011` 有 4 位 → 补 3 个 0 → `1001000`
- `1001 XOR 1011 = 0010` → 拉下一位得到 `0100`
- `0100` 首位为 0 → 不 XOR，继续拉下一位得到 `1000`
- `1000 XOR 1011 = 0011` → 拉最后一位得到 `0110`
- 没有下一位可拉 → CRC = **`110`**
- 最终发送：**`1001110`**

注意：

- **不是**“首位为 0 就自己补 0”，而是拉原数据里尚未处理的下一位；
- XOR 口诀：**相同得 0，不同得 1**；
- CRC 主要负责检错，不能告诉你具体哪一位错了。

## 海明码：30 秒复习

记住三件事：

1. **能定位并纠正单比特错误。**
2. 校验位放在 **1、2、4、8、16……** 位置。
3. 校验位数量满足：`2^r ≥ m + r + 1`。

常见结论：

- 4 位数据 → 3 个校验位；
- 8 位数据 → 4 个校验位。

如果多个校验结果组合成 `101`，就是十进制 5，表示第 5 位出错，翻转第 5 位即可纠正。

## 奇偶校验：扫一眼即可

奇偶校验当前是 P3，不单独投入大量时间。

只记：

- 奇校验：整个码字中 1 的数量为奇数；
- 偶校验：整个码字中 1 的数量为偶数；
- 能发现奇数个位翻转；
- 偶数个位同时翻转可能漏检；
- 只能检错，不能纠错。

## 最容易混淆的地方

| 容易混淆 | 正确记法 |
| --- | --- |
| CRC 能不能纠错？ | 主要不能，CRC 是强检错 |
| 海明码为什么比 CRC 多一步？ | 它能用多个校验结果定位错误位置 |
| CRC 补几个 0？ | 生成多项式对应二进制位数减 1 |
| 海明码校验位放末尾吗？ | 不，放在 1、2、4、8…… |
| 奇偶校验两位一起错一定能发现吗？ | 不一定，偶数位错误可能漏检 |

## 考前自测

1. `10011` 作为 CRC 除数时，原始数据后补几个 0？
2. CRC 余数非 0 说明什么？能定位错误位吗？
3. 海明码的校验位通常放在哪些位置？
4. 8 位原始数据至少需要几个海明校验位？
5. 奇偶校验为什么可能漏掉两位同时翻转？
