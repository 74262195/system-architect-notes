# 网络类型与广域网技术：局域网、城域网、广域网到底按什么分

> [!summary] 快速复习卡片
> **作用/定位**：先按覆盖范围和接入方式认识网络类型，再对教材中的传统 WAN 技术做最低限度识别。
> **核心结论**：LAN/MAN/WAN 主要按覆盖范围从小到大；WLAN 强调局部无线接入；移动通信网强调蜂窝移动接入。
> **经典题型怎么做 / 题干怎么认**：园区/楼宇 → LAN；城市范围 → MAN；跨城市/国家、运营商远距离 → WAN；Wi-Fi/802.11 → WLAN；蜂窝/4G/5G → 移动通信网。
> **易错点 / 考试重点**：SONET/DDN/帧中继/ATM 当前只做低频历史识别：SONET=同步光网络，DDN=数字数据网，Frame Relay=帧中继，ATM=固定长度信元；不要展开工程细节。

## 网络类型先按两个维度看

| 类型 | 主要判断维度 | 典型场景 |
| --- | --- | --- |
| LAN | 局部范围 | 办公楼、园区 |
| WLAN | 局部 + 无线接入 | Wi-Fi |
| MAN | 城市范围 | 城域汇聚 |
| WAN | 远距离 | 城市/国家/跨国互联 |
| 移动通信网 | 移动蜂窝接入 | 4G、5G |

不要把它们当成按“速度”排序的五种网络。

## 老 WAN 技术只保留识别

| 技术 | 最小识别词 |
| --- | --- |
| SONET | 同步光网络 |
| DDN | 数字数据网、数字专线/半永久连接语境 |
| Frame Relay | 帧中继、数据链路层分组交换 |
| ATM | 固定长度信元、面向连接 |

这些技术具有历史教材价值，但不是当前生产网络的默认方案。按最新减负规则：**能认出即可，不补完整协议结构、帧格式和工程部署。**

## 一句话总结

**LAN/MAN/WAN 看覆盖范围，WLAN/移动网还看接入方式；旧 WAN 技术只识别关键词。**
