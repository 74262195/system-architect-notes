# 复用与多址：都在“多人共享资源”，为什么还要分两个词

## 先定位：一条通信资源往往要服务多路信息、多个用户

共享资源时可以从两个角度问问题。

### 复用

> **一条物理信道里怎样同时承载多路信息？**

常见：

- FDM：按频率分；
- TDM：按时间分；
- CDM：按编码分。

### 多址

> **多个用户怎样获得同一通信资源中的各自使用份额？**

常见：

- FDMA；
- TDMA；
- CDMA。

## 为什么名字这么像

因为多址经常建立在类似的资源划分技术上。

但考试判断时看**主语**：

| 问题 | 落点 |
| --- | --- |
| 多路信号怎样塞进一条信道 | 复用 |
| 多个用户怎样共享接入资源 | 多址 |

所以：

> **复用更偏信号/信道视角，多址更偏用户接入视角。**

## 三种“分法”怎么记

| 技术思想 | 分什么 |
| --- | --- |
| 频分 | 分频率 |
| 时分 | 分时间 |
| 码分 | 分编码 |

## 一句话记住

> **FDM/TDM/CDM 看多路信号；FDMA/TDMA/CDMA 看多用户接入。**
