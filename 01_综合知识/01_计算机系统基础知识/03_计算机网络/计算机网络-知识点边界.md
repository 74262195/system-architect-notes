# 计算机网络知识点边界：不漏主线，也不学成网络工程师

> [!important] 总规则
> **大纲定范围，官方教程定展开深度，近年真题定优先级。** 目录拆得更细，只是为了定位，不代表每个子节点都要学到工程实现深度。

官方第 2 版教程把计算机网络分成五块：**网络基本概念、通信技术、网络技术、组网技术、网络工程**。本仓库在这五块下面做原子化拆分。

## 一、必须讲到：不能缺

### 1. 网络体系结构与分层
- OSI 七层的职责与题眼；
- TCP/IP 四层与 OSI 的对应；
- 帧、MAC、IP、TCP/UDP、端口分别属于哪一层；
- 典型设备与层次：中继器/集线器、交换机、路由器、网关。

### 2. 局域网与交换
- 以太网基本定位；
- 传统共享式以太网 CSMA/CD 与 WLAN CSMA/CA；
- 以太网帧只抓目的/源 MAC、数据、FCS；FCS 使用 CRC 做差错检测；
- 交换机：**学习源 MAC、查询目的 MAC、未知单播泛洪**；
- MAC 地址与 MAC 地址表；
- 冲突域与广播域；
- VLAN 只掌握“逻辑划分广播域”和跨 VLAN 需要三层转发；
- STP/链路聚合只掌握作用，不进入配置细节。

### 3. IP 与子网
- IPv4 地址的网络部分/主机部分；
- 私有地址、回环、组播等稳定特殊地址；
- 子网掩码、CIDR；
- 网络地址、广播地址、可用主机范围；
- 基本子网划分计算；
- IPv4 分片和 IPv6/IPv4 过渡按第二轮深度掌握；
- ARP：IPv4 当前链路 IP → MAC；
- ICMP：差错/控制消息，ping 的基础依赖；
- RARP：MAC → IP，仅作教程历史识别。

### 4. 路由
- 路由表、下一跳、默认路由；
- 最长前缀匹配；
- 静态路由 vs 动态路由；
- IGP 管 AS 内，BGP 管 AS 间。

### 5. 传输层
- TCP 与 UDP 的核心差异；
- 端口用于把数据交给主机上的具体服务/进程；
- 三次握手、四次挥手、拥塞算法不作为当前独立主线卡。

### 6. 应用层协议
- DNS、DHCP、HTTP/HTTPS、FTP、SMTP、POP3/IMAP、SSH/Telnet、SNMP 的**功能识别**；
- 官方教程点名但当前低频的 NFS、NNTP 只保留一句话识别；
- 高频默认端口只记稳定映射；
- 不进入协议报文格式和服务器配置。

### 7. 无线与移动通信
- 802.11/WLAN 基本定位；
- CSMA/CA 与传统共享式以太网 CSMA/CD 的区别；
- 5G 三大业务场景按教材/真题识别；
- 教程点名的 OFDM、灵活子载波间隔、OFDM 加窗、Massive MIMO、毫米波、频谱共享、先进信道编码只做“名称 ↔ 大致作用”识别；
- 网络切片和服务化架构只理解为什么存在，不背网元和实现参数。

### 8. 网络工程
- 网络拓扑；
- 接入/汇聚/核心的层次化思路；
- 网络规划 → 设计 → 实施；
- 冗余、高可用的设计思想。

## 二、只需识别：不扩展

- RARP、NFS、NNTP 等教程保留的低频/历史协议；
- SONET/SDH、DDN、帧中继、ATM 等旧 WAN 技术；
- OFDM/MIMO/毫米波等 5G 关键技术的名称与大致用途；
- 5G 网元和网络切片内部编排；
- STP 根桥/端口选举细节；
- RIP/OSPF/BGP 的报文、状态机和内部算法；
- 802.11 完整标准速率/频段参数表；
- TCP TIME_WAIT、拥塞窗口、慢开始等实现细节。

## 三、明确不进入本章主复习线

- Cisco/Huawei 命令与设备配置；
- OSPF LSA 类型、邻居状态机；
- BGP 路径属性与选路细则；
- VXLAN、EVPN 等数据中心网络工程细节；
- 复杂 QoS 队列算法；
- 无线射频规划、信道复用工程参数；
- NAT 暂不作为本章独立主线：当前第 2 版网络基础章节没有把它作为明确展开项；以后若现行真题形成稳定信号再补；
- 不重复建立“CRC 算法”网络专题：CRC 已在校验码主线学习，本章只在以太网 FCS 中建立联系；
- 把网络安全设备/密码协议重复学一遍——这些回到信息安全章节。

## 四、用这张表判断“该不该继续学”

| 情况 | 处理 |
| --- | --- |
| 现行大纲/教程明确 + 近年真题持续出现 | P0/P1，讲透到会做题 |
| 教程明确，但近年题频低 | P2，理解机制和题眼 |
| 教程点名但属于历史/低频名词 | P3，只保留识别 |
| 老真题出现，但新教程弱化 | P3，做懂旧题所需的最小知识 |
| 只有培训资料/工程资料扩展 | 不进入主线 |

## 一句话边界

**系统架构设计师的网络章要学到“能判断分层、能理解组网、能做基础地址/性能题、能识别常用协议”，不要学成网络工程师配置课。**
