# 计算机网络知识点边界：不漏主线，也不学成网络工程师

> [!important] 总规则
> **大纲定范围，官方教程定展开深度，近年真题定优先级。** 目录拆得更细只是为了定位，不代表每个子节点都要学到工程实现深度。
> 第一次学习的唯一 P0～P2 顺序以 [[计算机网络索引]] 为准；P3 只作为可选旁支，不再另造第二条“理解主线”。

现行大纲在计算机网络中明确列出：**网络基本概念、通信技术、网络技术、组网技术、网络工程**。本仓库在这些范围下面做原子化拆分。

## 一、必须讲到：不能缺

### 1. 网络基本概念、性能与通信底座
- 网络为什么存在：数据通信、资源共享、集中管理、分布式处理和负荷均衡；
- 计算机网络发展的四个阶段，只抓阶段变化，不背网络史细节；
- 速率、带宽、吞吐量、时延、RTT、利用率等基本指标；
- 信道、信号变换、复用、多址的基本定位；
- 香农公式只保留教材要求的信道容量核心计算，不扩展通信理论推导；
- 电路/报文/分组交换只掌握基本差异和分组交换的定位。

### 2. 网络体系结构与分层
- OSI 七层的职责与题眼；
- TCP/IP 四层与 OSI 的对应；
- 帧、MAC、IP、TCP/UDP、端口分别属于哪一层；
- 典型设备与层次：中继器/集线器、交换机、路由器、网关、防火墙基本定位。

### 3. 局域网与交换
- 以太网基本定位；
- 传统共享式以太网 CSMA/CD 与 WLAN CSMA/CA；
- 以太网帧只抓目的/源 MAC、数据、FCS；FCS 使用 CRC 做差错检测；
- 交换机：**学习源 MAC、查询目的 MAC、未知单播泛洪**；
- MAC 地址与 MAC 地址表；
- 冲突域与广播域；
- VLAN 只掌握“逻辑划分广播域”和跨 VLAN 需要三层转发；
- STP/链路聚合只掌握作用，不进入配置细节。

### 4. IP 与子网
- IPv4 地址的网络部分/主机部分；
- 私有地址、回环、组播等稳定特殊地址；
- 子网掩码、CIDR；
- 网络地址、广播地址、可用主机范围；
- 基本子网划分计算；
- ARP：IPv4 当前链路 IP → MAC；
- 路由表、下一跳、默认路由和最长前缀匹配；
- IPv4 分片、TTL、ICMP；
- IPv6 地址特点及双栈/隧道/协议转换三类过渡思路；
- RARP：MAC → IP，仅作历史识别。

### 5. 路由
- 静态路由 vs 动态路由的基本定位；
- 自治系统 AS；
- IGP 管 AS 内，BGP 管 AS 间；
- RIP/OSPF 只作为 IGP 典型名称识别，不进算法和状态机。

### 6. 传输层
- TCP 与 UDP 的核心差异；
- 端口用于把数据交给主机上的具体服务/进程；
- 三次握手、四次挥手只作为 P3 理解旁支，用来补足 `SYN / ACK / Seq / Ack` 和 TCP 双向关闭的最小机制；不进入完整状态机；
- TIME_WAIT、拥塞控制算法不作为当前主线内容。

### 7. 应用层协议
- DNS、DHCP、HTTP/HTTPS、FTP、SMTP、POP3/IMAP、SSH/Telnet、NFS、SNMP 的**功能/所在层次识别**；
- DHCP 先解决“主机怎样获得 IP/掩码/网关/DNS 等配置”，DNS 再解决“域名 → IP”；
- NFS 不要求深学，只记网络文件服务和应用层定位；
- 官方教程点名但当前低信号的 NNTP 只保留一句话识别；
- 常见默认端口只记稳定映射；
- 不进入协议报文格式和服务器配置。

### 8. 无线与移动通信
- 802.11/WLAN 基本定位；
- CSMA/CA 与传统共享式以太网 CSMA/CD 的区别；
- 5G 三大业务场景按教材/已核验题源做识别；
- 网络切片掌握“一网多片、物理共享、逻辑隔离”；
- 教程点名的 OFDM、灵活子载波间隔、OFDM 加窗、Massive MIMO、毫米波、频谱共享、先进信道编码只做“名称 ↔ 大致作用”识别；
- 服务化架构只理解为什么存在，不背网元和实现参数。

### 9. 网络工程
- 五类常见网络拓扑的结构特征与典型单点故障；
- 核心/汇聚/接入的层次化思路；
- MAN 三层与层次化组网统一理解，不重复学两套；
- 冗余、备用路径与负载分担的基本思想；
- 网络规划 → 网络设计 → 网络实施。

## 二、只需识别：不扩展

- [[TCP三次握手]]：只理解三步、SYN 占 1 个序号，以及 `ACK=1` 与具体确认号的区别；不背连接状态机；
- [[TCP四次挥手]]：只理解全双工连接为什么两个方向分别关闭、FIN 占 1 个序号；不背 TIME_WAIT 状态细节；
- RARP、NNTP 等教程保留的低频/历史协议；
- SONET/SDH、DDN、帧中继、ATM 等旧 WAN 技术；
- OFDM/MIMO/毫米波等 5G 关键技术的名称与大致用途；
- 5G 网元和网络切片内部编排；
- STP 根桥/端口选举细节；
- RIP/OSPF/BGP 的报文、状态机和内部算法；
- 802.11 完整标准速率/频段参数表；
- TCP TIME_WAIT、拥塞窗口、慢开始等实现细节。

## 三、明确不进入本章主复习线

- Cisco/Huawei 命令与设备配置；
- OSPF LSA 类型、邻居状态机；
- BGP 路径属性与选路细则；
- VXLAN、EVPN 等数据中心网络工程细节；
- 复杂 QoS 队列算法；
- 无线射频规划、信道复用工程参数；
- NAT 暂不作为本章独立主线：当前第 2 版网络基础章节没有把它作为明确展开项；以后若现行真题形成稳定信号再补；
- 不重复建立“CRC 算法”网络专题：CRC 已在校验码主线学习，本章只在以太网 FCS 中建立联系；
- 把网络安全设备/密码协议重复学一遍——这些回到信息安全章节。

## 四、用这张表判断“该不该继续学”

| 情况 | 处理 |
| --- | --- |
| 现行大纲/教程明确 + 近年题源持续出现 | P0/P1，讲透到会做题 |
| 教程明确或近年题源直接出现，但不是第一轮抓分项 | P2，理解机制和题眼 |
| 教程点名但属于历史/低信号名词 | P3，只保留识别 |
| 老真题出现，但新教程弱化 | P3，做懂旧题所需的最小知识 |
| 只有培训资料/工程资料扩展 | 不进入主线 |

## 一句话边界

**系统架构设计师的网络章要学到“能判断分层、能理解组网、能做基础地址/性能题、能识别常用协议”，不要学成网络工程师配置课。**
