# 网络互联设备：设备到底看信号、MAC 还是 IP

> [!summary] 快速复习卡片
> **作用/定位**：把 OSI 分层落到具体设备，回答“这个设备工作在哪一层、根据什么转发”。
> **核心结论**：中继器/集线器看信号；网桥/二层交换机看 MAC；路由器看 IP 和路由表；网关强调异构协议/数据格式转换。
> **经典题型怎么做 / 题干怎么认**：放大整形 → 中继器；所有端口复制 → 集线器；MAC 表 → 交换机；下一跳/跨网段/IP → 路由器；协议转换 → 网关。
> **易错点 / 考试重点**：2024 直接考过“路由器 = 网络层”；现实有三层交换机等复合设备，基础选择题仍先按主要层次判断。

## 为什么会有不同互联设备

网络扩大后会依次遇到不同问题：信号衰减、共享介质冲突、局域网内定向转发、跨 IP 网络选路、异构协议转换。问题层次不同，设备的判断能力也不同。

| 设备 | 主要层次 | 看什么 | 主要作用 |
| --- | --- | --- | --- |
| 中继器 | 物理层 | 信号/比特 | 整形、放大、延长距离 |
| 集线器 | 物理层 | 信号/比特 | 把信号复制到其他端口 |
| 网桥 | 数据链路层 | MAC | 过滤和转发帧 |
| 二层交换机 | 数据链路层 | MAC 表 | 学习、定向转发、隔离冲突域 |
| 路由器 | 网络层 | IP、路由表 | 连接不同网络、选择下一跳 |
| 网关 | 高层/跨层语境 | 协议、数据格式 | 异构协议转换 |

## 同一份数据经过设备时怎么想

主机访问另一个网段的服务器：

1. 物理层设备只关心信号能不能继续走；
2. 二层交换机根据 MAC 把帧送往默认网关；
3. 路由器取出 IP 分组，根据目的 IP 和路由表选下一跳；
4. 如果两端协议或数据格式本身不兼容，才考虑更高层转换。

> **交换机解决“一跳内送到哪个端口”，路由器解决“跨网络下一步往哪走”。**

## 隔离能力怎么认

- 普通交换机：每个端口通常形成独立冲突域，但同一 VLAN 仍属于同一广播域；
- 路由器：接口之间隔离广播域；
- VLAN：可在交换网络中逻辑划分广播域。

## 一句话总结

**中继看信号，交换看 MAC，路由看 IP，网关做翻译。**
