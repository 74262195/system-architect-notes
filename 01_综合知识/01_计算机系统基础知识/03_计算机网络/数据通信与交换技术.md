# 数据通信与交换技术：专题入口

这组内容属于官方教程“通信技术”范围，但当前整体放在 **P2 第二轮**。第一轮不需要和 OSI、802.11、子网、TCP/UDP 同时抢记忆资源。

建议顺序：

1. **P2 [[数据通信基本模型与信道]]**：信源 → 发信机 → 信道 → 收信机 → 信宿。
2. **P2 [[编码调制与解调译码]]**：编码改表示，调制适配带通信道。
3. **P2 [[香农公式与信道容量]]**：带宽 + 信噪比限制容量；dB 先换线性值。
4. **P2 [[复用与多址]]**：频分、时分、波分、码分；区分“多路信号”和“多用户”。
5. **P2 [[电路报文与分组交换]]**：先占路、整件转、拆小包。
6. **P2 [[网络性能指标]]**：发送时延看数据量，传播时延看距离。

> **减负原则**：通信技术先会“题干在问哪种机制”，再做少量稳定计算；不为了旧题补完整调制算法、复用制式或历史通信产品。
