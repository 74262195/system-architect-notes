# TCP 与 UDP：专题入口

## 本章边界先说清楚

官方网络基础章要求掌握 TCP/IP 协议集，教材在这里重点说明：

- TCP/IP 是四层协议体系；
- 传输层主要有 TCP 和 UDP；
- TCP 与 UDP 提供不同的传输服务。

当前题库趋势也把 **“TCP 与 UDP”整体**列为网络 P1，而没有把三次握手、四次挥手、拥塞算法等拆成独立稳定考点。因此本章只保留两张卡：

1. **P1 [[TCP与UDP对比]]**：连接、可靠性、字节流/数据报等核心区别。
2. **P2 [[端口与进程通信]]**：理解传输层怎样把数据交给主机上的通信端点，并支撑常用协议端口题。

> **减负边界**：三次握手、四次挥手、TIME_WAIT、具体拥塞控制算法属于可进一步理解的 TCP 工程细节，不作为当前系统架构设计师网络基础章的独立复习任务。
