# TCP 与 UDP：专题入口

## 本章边界先说清楚

官方网络基础章要求掌握 TCP/IP 协议集，教材在这里重点说明：

- TCP/IP 是四层协议体系；
- 传输层主要有 TCP 和 UDP；
- TCP 与 UDP 提供不同的传输服务。

当前题库趋势仍把 **“TCP 与 UDP”整体**作为主要复习对象，没有把三次握手、四次挥手、拥塞算法等拆成稳定主线考点。

但如果完全跳过连接建立/释放，就会出现一个理解断层：题目一旦出现 `SYN`、`ACK`、`Seq`、`Ack`，只知道“TCP 面向连接”却不知道连接怎样建立。

因此这里采用 **主线 + P3 理解旁支**：

1. **P1 [[TCP与UDP对比]]**：连接、可靠性、字节流/数据报等核心区别。
2. **P2 [[端口与进程通信]]**：理解传输层怎样把数据交给主机上的通信端点，并支撑常用协议端口题。
3. **P3 [[TCP三次握手]]**：补足 TCP 为什么要建立连接，以及 `SYN / ACK / Seq / Ack` 的最小做题基础。
4. **P3 [[TCP四次挥手]]**：补足 TCP 全双工连接为什么通常要分两个方向关闭。

> **减负边界**：三次握手、四次挥手现在作为理解补充，不提升为当前主线抓分任务；TIME_WAIT、完整状态机和具体拥塞控制算法仍不展开。
