# 端口与进程通信：数据到达主机后怎样交给正确程序

> [!summary] 快速复习卡片
> **作用/定位**：IP 找到主机以后，传输层用端口把数据继续交给主机内的正确通信端点。
> **核心结论**：IP 回答“哪台主机”，TCP/UDP 回答“哪种传输协议”，端口号回答“这个协议里的哪个通信端点”。端口号为 16 位。
> **经典题型怎么做 / 题干怎么认**：问“一条 TCP 连接如何区分” → 协议 + 源 IP + 源端口 + 目的 IP + 目的端口；问熟知端口范围 → 0～1023。
> **易错点 / 考试重点**：端口不是物理插孔；socket 也不是“端口的英文名”；TCP 53 和 UDP 53 可以同时存在。

## IP、协议、端口分别做什么

| 标识 | 回答的问题 |
| --- | --- |
| IP 地址 | 数据送到哪台主机 |
| TCP/UDP | 交给哪种传输协议 |
| 端口 | 交给该协议中的哪个通信端点 |

例如 `203.0.113.10:443/TCP`：先找到这台主机，再由 TCP 把数据交给 443 端口对应的服务。

## Socket 是什么

Socket（套接字）是应用使用网络通信能力的操作系统接口和通信端点抽象。它涉及协议、地址、端口和连接状态等上下文。

所以：

- 端口是一个标识数字；
- socket 是应用实际用来通信的端点/接口抽象。

## 端口范围只记标准分类

- 0～1023：熟知端口；
- 1024～49151：注册端口；
- 49152～65535：动态/私有端口。

具体系统的临时端口范围可以配置，考试按标准分类识别即可。

## 一句话总结

**IP 找主机，TCP/UDP 选传输协议，端口找通信端点。**
