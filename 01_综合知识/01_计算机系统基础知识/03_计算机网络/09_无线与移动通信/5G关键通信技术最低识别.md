# 5G 关键通信技术：教程点了名，但只需要最低识别

> [!summary] 快速复习卡片
> **作用/定位**：补齐官方教程在 5G 通信技术部分明确列出的技术名称。
> **核心结论**：OFDM 解决多载波传输组织；大规模 MIMO 通过多天线提升容量/覆盖；毫米波提供更丰富的高频频谱资源；频谱共享提高频谱使用灵活性；先进信道编码用于提高传输可靠性与效率。
> **经典题型怎么做 / 题干怎么认**：多载波/子载波 → OFDM；大量天线 → Massive MIMO；高频段/宽带宽 → 毫米波；多个系统灵活共用频谱 → 频谱共享。
> **易错点 / 考试重点**：只认“技术名 ↔ 大致作用”，不背参数、公式、帧结构、编码算法细节。

## 最低识别表

| 技术 | 只需要知道 |
| --- | --- |
| OFDM | 把高速数据组织到多个正交子载波上传输，是 5G 重要波形/多址基础 |
| 灵活子载波间隔 | 为不同业务和频段提供更灵活的参数配置 |
| OFDM 加窗 | 用于改善多路传输中的频谱/干扰表现，知道教材点名即可 |
| Massive MIMO | 使用大量天线提升容量、覆盖和空间复用能力 |
| 毫米波 | 利用更高频段获得较丰富带宽资源，但传播特性更苛刻 |
| 频谱共享 | 让频谱资源使用更灵活 |
| 先进信道编码 | 提高数据传输可靠性与效率 |

## 明确不学

- OFDM 数学推导；
- 子载波正交条件公式；
- MIMO 信道矩阵；
- 毫米波链路预算；
- LDPC/Polar 编码实现；
- 5G NR 帧结构和运营商配置参数。

## 一句话总结

**5G 技术这张卡只做“看到名字知道大概干什么”，绝不向通信原理深挖。**
