# 5G 关键通信技术：教程点了名，但只需要最低识别

> [!summary] 快速复习卡片
> **作用/定位**：这是 5G 主线旁边的 P3 补充卡，只用于防止官方教程点名的技术名称完全陌生。
> **核心结论**：OFDM 用多个正交子载波组织多载波传输；Massive MIMO 用大量天线提升空间利用能力；毫米波提供更丰富的高频频谱资源；频谱共享提高资源使用灵活性；先进信道编码提高可靠传输能力。
> **经典题型怎么做 / 题干怎么认**：多载波/子载波 → OFDM；大量天线 → Massive MIMO；高频段/宽带宽 → 毫米波；多个系统灵活共用频谱 → 频谱共享。
> **易错点 / 考试重点**：OFDM 本身重点是多载波波形/传输组织，不要和 OFDMA 这个多址方式混为一个词；只认名称和大致作用。

## 为什么这张卡是 P3

主线 [[5G]] 已经解决考试更重要的“eMBB / uRLLC / mMTC 三大场景”，[[5G网络切片]] 又有 2022 真题直接命中。

相比之下，本卡这些技术虽然在官方教程中被点名，但当前没有足够证据支持你投入通信原理级学习成本。

因此学习目标只有：

> **看到技术名，不至于完全不知道它大致解决什么。**

## 最低识别表

| 技术 | 只需要知道 |
| --- | --- |
| OFDM | 把数据组织到多个彼此正交的子载波上传输，是多载波传输的重要方式 |
| 灵活子载波间隔 | 为不同频段/业务提供更灵活的参数选择 |
| OFDM 加窗 | 改善频谱泄漏等表现，知道教程点名即可 |
| Massive MIMO | 使用大量天线提升容量、覆盖和空间复用能力 |
| 毫米波 | 利用更高频段获取较丰富带宽，但传播条件更苛刻 |
| 频谱共享 | 让有限频谱资源能够更灵活地被共同使用 |
| 先进信道编码 | 提高数据传输的可靠性与效率 |

## 明确不学

- OFDM 数学推导和正交条件公式；
- MIMO 信道矩阵；
- 毫米波链路预算；
- LDPC/Polar 编码实现；
- 5G NR 帧结构和运营商配置参数。

## 一句话总结

**这张卡只做到“看到名字知道大概干什么”；OFDM 是多载波传输技术，不把它和 OFDMA 多址混成一个概念。**
