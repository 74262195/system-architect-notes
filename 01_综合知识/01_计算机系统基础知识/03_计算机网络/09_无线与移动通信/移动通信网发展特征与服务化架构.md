# 移动通信网：从 1G 到 5G，为什么最后走向服务化架构

> [!summary]- 快速复习卡片（学完再看）
> **作用/定位**：承接 WLAN，把局部无线接入扩展到蜂窝移动网络，认识 1G→5G 的能力变化与 5G SBA 服务化思想。
> **核心结论**：1G 从模拟语音起步；2G 进入数字通信；3G 数据能力增强；4G 推动移动互联网；5G 同时面向高速率、低时延、海量连接等差异化需求，并通过 SBA 让核心网功能更容易按需组合。
> **经典题型怎么做 / 题干怎么认**：模拟语音 → 1G；数字语音/短信 → 2G；移动数据增强 → 3G；高速移动互联网 → 4G；多业务、低时延、海量连接、服务化 → 5G。
> **易错点 / 考试重点**：不背各代峰值速率；SBA 只记“网络功能服务化、可组合”，不背 AMF/SMF/NRF 等网元表。

## 先直接回答：移动通信每一代到底在变什么

上一站 [[无线局域网802.11]] 讲的是局部范围的 Wi-Fi 接入。

移动通信网要解决更大的问题：用户会移动，设备要在蜂窝覆盖中持续联网，而且业务从“打电话”逐渐扩展到视频、移动互联网、工业控制和海量物联网。

所以代际演进不要背年份，抓**主要能力变化**：

| 代际 | 最小定位 |
| --- | --- |
| 1G | 模拟移动语音 |
| 2G | 数字移动通信，语音/短信和低速数据 |
| 3G | 数据能力明显增强 |
| 4G | 高速移动宽带，移动互联网普及 |
| 5G | 同时面向高速率、低时延、海量连接等多类需求 |

主线就是：

> **语音 → 数字通信 → 移动数据 → 高速移动互联网 → 面向差异化业务的 5G。**

## 为什么 5G 不只是“更快”

如果所有业务只追求速度，网络只要不断提高带宽就够了。

但 5G 面对的需求差异很大：

- 高清视频需要大带宽；
- 工业控制需要低时延和高可靠；
- 传感器网络需要同时连接海量终端。

因此 5G 的核心变化之一，是同时支持不同类型的业务目标。下一站会用 eMBB、uRLLC、mMTC 三个场景把它们压缩成“快、准、多”。

## 为什么会出现服务化架构 SBA

**直接回答：5G 的 SBA 不是为了让手机信号更快，而是为了让核心网能更灵活地组合、扩展和更新它的管理能力，以适应差异很大的业务。**

先补一个容易漏掉的前提：手机连上基站以后，后面还有一部分叫做**核心网**。它不负责把电波从手机发到基站；它负责“这台设备能不能入网、它是谁、该给它什么连接和策略”等管理工作。

例如，一台手机第一次接入网络时，核心网需要协同完成身份确认、移动性管理、数据连接建立和策略控制等工作。把这些工作合起来，才能让手机真正使用移动数据。

### 原来的困难：能力绑得太死，改一处容易牵连多处

5G 前的核心网并非不能完成这些工作；问题是网络功能之间更多依赖预先约定的、较固定的点对点接口。业务种类少、变化慢时，这种组织方式可以工作。

但 5G 同时要服务普通手机视频、工业控制和海量传感器。若想新增一种能力，或让某类业务使用不同的策略，常常需要同时调整多处功能和接口。**能力越多、组合越多，改动就越不灵活。**

| 组织方式 | 主要特点 | 面对新需求时的困难 |
| --- | --- | --- |
| 固定接口为主 | 功能之间按预先约定的接口直接配合 | 改动一个能力时，关联功能和接口可能也要跟着调整 |
| SBA | 每个网络功能把自己能做的事以“服务”方式提供，其他功能按需要调用 | 更容易发现、调用、替换或扩展某项能力 |

### SBA 到底改变了什么

SBA（Service-Based Architecture，**服务化架构**）把核心网拆成多个各有职责的**网络功能**。每个网络功能不必只和少数固定邻居“硬连着”，而是把可提供的能力作为服务暴露出来，其他网络功能按需要调用。

可以把它理解为：过去像几台机器按固定线路直接配合；SBA 则更像一个“能力目录”。需要身份数据时调用身份相关服务，需要建立数据连接时调用会话相关服务。这里的“服务”指核心网功能对其他网络功能提供的能力，**不是手机里一个个面向用户的 App 服务**。

用“新接入一台工业设备”为例，过程可以这样理解：

1. **触发**：设备请求接入 5G 网络。
2. **判断需要什么**：接入管理功能发现，先要确认设备身份，再决定连接和策略。
3. **调用能力**：它调用提供身份数据的服务、会话管理服务和策略相关服务。
4. **得到结果**：这些服务分别返回所需信息或处理结果，核心网据此为设备建立合适的连接。

关键不在于这四步的网元缩写，而在于：**完成一次接入所需的多项能力可以按服务协同；将来增加、扩容或替换其中一项能力时，不必把整张核心网当成一台不可拆分的大设备来改。**

> **补充理解：** SBA 和常说的“微服务”有相似之处，都是把能力拆开并通过服务调用协作；但 SBA 是 5G 核心网的标准化架构，考试中不要把两者简单画等号。

### 考试只抓这一层

题干出现“5G 核心网、网络功能服务化、服务调用、能力组合、适配差异化业务”，优先想到 **SBA**。它解决的是**核心网组织和演进的灵活性**，不是直接解决无线覆盖、空口速率或基站发射功率。

## 一句话总结

**移动通信从语音走向移动数据，再走向 5G 多业务；SBA 用“网络功能服务化、可组合”适应不同业务需求。**

> [!question]- 自测（展开查看答案）
> 1. SBA 直接解决的是“5G 空口速度不够快”吗？
>    > **答案**：不是。
>    > **解析**：SBA 处理的是核心网功能如何组织、调用和演进，使其更容易适配差异化业务；无线速率属于空口和无线接入侧的问题。
> 2. 为什么业务变多会推动核心网服务化？
>    > **答案**：因为不同业务会需要不同的身份、连接和策略能力组合；把能力按服务提供，比大量固定点对点配合更容易扩展、替换和组合。
