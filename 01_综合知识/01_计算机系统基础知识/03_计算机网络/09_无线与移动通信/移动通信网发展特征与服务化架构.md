# 移动通信网：从 1G 到 5G，为什么最后走向服务化架构

> [!summary] 快速复习卡片
> **作用/定位**：补齐大纲明确要求的“移动通信网发展、特征和服务化架构”，不展开运营商核心网网元细节。
> **核心结论**：1G 从模拟语音起步；2G 进入数字通信；3G 数据能力明显增强；4G 推动移动互联网；5G 面向高速率、低时延、海量连接等多样业务，并在核心网引入 SBA 服务化架构以支持网络功能按需组合。
> **经典题型怎么做 / 题干怎么认**：模拟语音 → 1G；数字语音/短信 → 2G；移动数据增强 → 3G；移动宽带/移动互联网 → 4G；多业务、低时延、海量连接、服务化 → 5G。
> **易错点 / 考试重点**：不要背教材中各代具体峰值速率；SBA 的核心是网络功能服务化、可组合，不要求记 AMF/SMF/NRF 等网元缩写表。

## 发展主线只抓能力变化

| 代际 | 最小定位 |
| --- | --- |
| 1G | 模拟移动语音 |
| 2G | 数字移动通信，语音/短信和低速数据 |
| 3G | 数据速率明显提升，移动数据应用扩展 |
| 4G | 高速移动宽带，移动互联网普及 |
| 5G | 不只追求更快，还面向低时延、海量连接和多业务融合 |

## 5G 的主要业务特征

教材强调的方向可以压成三组：

- **高速率/大带宽**；
- **低时延、高可靠**；
- **海量设备连接、低功耗**。

对应的三大业务场景在 [[5G]] 单独做最小识别。

## 服务化架构 SBA 是什么

传统核心网常把功能固化在特定网元/接口中。5G 为了更快组合不同能力，把核心网功能按“服务”方式组织，使网络功能更容易被调用、组合和迭代。

> **SBA = 把核心网功能服务化，让能力可以按需求组合。**

考试边界到这里为止：知道目的和基本思想，不背具体网络功能缩写、接口名称和部署实现。

## 一句话总结

**移动通信从语音走向移动数据，再走向 5G 多业务；SBA 用“服务化、可组合”适应差异化需求。**
