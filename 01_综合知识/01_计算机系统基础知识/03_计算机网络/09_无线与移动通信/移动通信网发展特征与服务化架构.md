# 移动通信网：从 1G 到 5G，为什么最后走向服务化架构

> [!summary] 快速复习卡片
> **作用/定位**：承接 WLAN，把局部无线接入扩展到蜂窝移动网络，认识 1G→5G 的能力变化与 5G SBA 服务化思想。
> **核心结论**：1G 从模拟语音起步；2G 进入数字通信；3G 数据能力增强；4G 推动移动互联网；5G 同时面向高速率、低时延、海量连接等差异化需求，并通过 SBA 让核心网功能更容易按需组合。
> **经典题型怎么做 / 题干怎么认**：模拟语音 → 1G；数字语音/短信 → 2G；移动数据增强 → 3G；高速移动互联网 → 4G；多业务、低时延、海量连接、服务化 → 5G。
> **易错点 / 考试重点**：不背各代峰值速率；SBA 只记“网络功能服务化、可组合”，不背 AMF/SMF/NRF 等网元表。

## 先直接回答：移动通信每一代到底在变什么

上一站 [[无线局域网802.11]] 讲的是局部范围的 Wi-Fi 接入。

移动通信网要解决更大的问题：用户会移动，设备要在蜂窝覆盖中持续联网，而且业务从“打电话”逐渐扩展到视频、移动互联网、工业控制和海量物联网。

所以代际演进不要背年份，抓**主要能力变化**：

| 代际 | 最小定位 |
| --- | --- |
| 1G | 模拟移动语音 |
| 2G | 数字移动通信，语音/短信和低速数据 |
| 3G | 数据能力明显增强 |
| 4G | 高速移动宽带，移动互联网普及 |
| 5G | 同时面向高速率、低时延、海量连接等多类需求 |

主线就是：

> **语音 → 数字通信 → 移动数据 → 高速移动互联网 → 面向差异化业务的 5G。**

## 为什么 5G 不只是“更快”

如果所有业务只追求速度，网络只要不断提高带宽就够了。

但 5G 面对的需求差异很大：

- 高清视频需要大带宽；
- 工业控制需要低时延和高可靠；
- 传感器网络需要同时连接海量终端。

因此 5G 的核心变化之一，是同时支持不同类型的业务目标。下一站会用 eMBB、uRLLC、mMTC 三个场景把它们压缩成“快、准、多”。

## 为什么会出现服务化架构 SBA

业务类型越来越多后，核心网能力如果完全固化在特定设备和固定接口里，组合、扩展和迭代都会比较僵硬。

SBA（Service-Based Architecture，服务化架构）的基本思想是：

> **把核心网的网络功能按服务方式组织，让不同能力更容易被调用和组合。**

这里学到“服务化、可组合、适应差异化业务”就停，不进入核心网网元缩写和接口实现。

## 为什么下一站是 5G 三大场景

现在已经知道 5G 的需求不只有“更快”，但还没有把差异化需求整理成考试容易识别的三类。

下一站只做这件事：把场景映射成 eMBB、uRLLC、mMTC。

## 一句话总结

**移动通信从语音走向移动数据，再走向 5G 多业务；SBA 用“网络功能服务化、可组合”适应不同业务需求。**
