# IPv4 地址结构与特殊地址：32 位地址里哪些位代表网络，哪些位代表主机

> [!summary] 快速复习卡片
> **作用/定位**：子网掩码和 CIDR 的前置知识，先理解 IPv4 地址为什么需要分成网络部分和主机部分。
> **核心结论**：IPv4 共 32 位；网络部分用于定位目标网络，主机部分用于标识该网络内的接口；两部分边界由掩码/CIDR 决定。
> **经典题型怎么做 / 题干怎么认**：私网地址、回环、组播、网络号/主机号 → IPv4 地址基础。
> **易错点 / 考试重点**：现代题优先按 CIDR 判断，不要把 A/B/C 类当成现代子网划分的主方法。

## 为什么 IP 地址要分两部分

路由器不会给互联网中每台主机都单独保存一条路径，而是先根据地址的“网络部分”把分组送到目标网络，再在目标链路内完成最后交付。

因此 IPv4 地址可以理解为：

> **网络部分 | 主机部分**

具体分界由 [[子网掩码与CIDR]] 决定。

## 稳定特殊地址只记这些

| 地址范围 | 含义 |
| --- | --- |
| `10.0.0.0/8` | 私有地址 |
| `172.16.0.0/12` | 私有地址 |
| `192.168.0.0/16` | 私有地址 |
| `127.0.0.0/8` | 回环地址范围 |
| `224.0.0.0/4` | IPv4 组播地址范围 |

A/B/C 类传统分类只要能识别历史题即可，不作为当前地址规划主线。

## 一句话总结

**IPv4 是 32 位地址；先用前缀分出网络部分和主机部分，再谈子网边界。**
