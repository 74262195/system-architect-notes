# IPv4 地址结构与特殊地址：为什么跨网络通信还要一套 IP 地址

> [!summary] 快速复习卡片
> **作用/定位**：从局域网二层进入网络层，先理解 IPv4 为什么要区分“网络部分”和“主机部分”。
> **核心结论**：IPv4 地址共 32 位；网络部分用于定位目标网络，主机部分用于标识该网络内的接口；两部分边界由掩码/CIDR 前缀决定。
> **经典题型怎么做 / 题干怎么认**：私网地址、回环、组播、网络号/主机号 → IPv4 地址基础；具体网段边界看前缀，不靠 A/B/C 类硬猜。
> **易错点 / 考试重点**：MAC 主要解决当前链路交付，IP 解决跨网络逻辑寻址；现代题优先按 CIDR 判断。

## 先直接回答：已经有 MAC 地址，为什么还要 IP 地址

上一站 [[MAC地址与交换机转发表]] 已经把局域网内部的核心动作讲清：以太网帧依靠 MAC 地址和交换机完成当前二层网络里的交付。

但如果目标在另一个网络，仅凭各个局域网内部的 MAC 地址，路由器很难按“网络范围”组织大规模转发。

因此网络层引入 **IP 地址**：它是一种逻辑地址，可以把地址划成“目标属于哪个网络”和“这个网络里的哪个接口”两部分，让路由器先按网络范围转发。

可以先把两者区分成：

- **MAC**：当前链路这一跳怎样交付；
- **IP**：跨网络最终要去哪个网络/主机。

VLAN、STP、链路聚合是局域网规模扩大后出现的二层扩展问题，可以从上一阶段旁支学习，但不是进入 IP 主线的必要前置。

## IPv4 的 32 位为什么要分成两部分

IPv4 地址一共 32 位，通常写成四个十进制数，例如：`192.168.10.70`。

真正做路由和子网计算时，不是简单固定成“前三段网络、最后一段主机”，而是要看前缀边界：

> **网络部分 | 主机部分**

- 网络部分：帮助判断地址属于哪个网络；
- 主机部分：在这个网络内部标识具体接口。

例如 `192.168.10.70/24` 中，`/24` 的意思是**前 24 位属于网络部分**。为什么 `/24` 能这样表示、它和子网掩码是什么关系，下一站再系统讲。

## 稳定特殊地址只记这些

| 地址范围 | 最小定位 |
| --- | --- |
| `10.0.0.0/8` | 私有地址 |
| `172.16.0.0/12` | 私有地址 |
| `192.168.0.0/16` | 私有地址 |
| `127.0.0.0/8` | 回环地址范围 |
| `224.0.0.0/4` | IPv4 组播地址范围 |

私有地址主要用于内部网络，不在这里展开 NAT；回环地址用于本机内部测试/通信语境；组播表示“一份数据面向一组接收者”。

A/B/C 类传统分类只做历史题识别，不作为当前地址规划主线。

## 为什么下一站是子网掩码和 CIDR

现在只知道 IPv4 要分“网络部分”和“主机部分”，但还缺一个关键信息：

> **这 32 位到底从哪一位开始由网络部分切换成主机部分？**

这个边界就是子网掩码和 CIDR 前缀要表达的东西。

## 一句话总结

**MAC 管当前链路的一跳交付，IP 管跨网络的逻辑寻址；IPv4 共 32 位，具体网络/主机边界由前缀决定。**
