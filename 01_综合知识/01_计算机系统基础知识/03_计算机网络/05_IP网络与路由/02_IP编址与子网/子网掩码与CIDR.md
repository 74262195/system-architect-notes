# 子网掩码与 CIDR：`192.168.10.70/27` 里的 `/27` 到底是在说什么

> [!summary] 快速复习卡片
> **先记一句**：CIDR 的 `/n` 表示 IPv4 的前 `n` 位属于网络前缀，剩下的位用于区分该网络里的地址。
> **掩码怎么对应**：网络位写 1，主机位写 0；所以 `/27` 对应 `255.255.255.224`。
> **做题起手式**：看到 `/27`，先想“前 27 位网络，剩 5 位变化”；5 位共有 32 种组合，所以这一段地址 **32 个一块**。
> **易错点**：`/27` 不是 27 台主机，也不是“最后 27 位”；不要只看 IP 的小数点猜网络边界。

## 继续上一站：为什么只给 `192.168.10.70` 还不够

上一站 [[IPv4地址结构与特殊地址]] 已经知道，IPv4 地址里需要区分：

- 哪一部分代表网络；
- 哪一部分在这个网络里继续区分地址。

现在给你两个地址：

- `192.168.10.70`
- `192.168.10.90`

你光看这两个十进制地址，不能严谨判断它们是不是同一个网络。

为什么？

因为还不知道**网络边界切在哪里**。

所以 IPv4 地址旁边还要带一个“切割说明”。最常见的两种写法是：

- CIDR 前缀：`/27`；
- 子网掩码：`255.255.255.224`。

它们表达的是同一件事：

> **这 32 位里，哪些位用来识别网络范围。**

## `/27` 先不要算，直接翻译成人话

IPv4 总共 32 位。

`/27` 就表示：

> **从最左边开始，前 27 位固定为网络前缀；剩下 5 位可以在这个地址块里变化。**

同理：

| 前缀 | 人话 |
| --- | --- |
| `/24` | 前 24 位是网络前缀，剩 8 位变化 |
| `/27` | 前 27 位是网络前缀，剩 5 位变化 |
| `/30` | 前 30 位是网络前缀，剩 2 位变化 |

先把这个意思吃透，再谈十进制掩码。

## 子网掩码为什么一串 1 后面是一串 0

子网掩码只是把同一条分界线换一种写法：

- 网络前缀对应的位置写 **1**；
- 后面可变化的位置写 **0**。

因此 `/27` 是：

- 前 24 位已经占满前三个字节；
- 第四个字节还需要 3 个网络位；
- 第四个字节于是是 `11100000`；
- `11100000` 转成十进制是 224。

所以：

> `/27` = `255.255.255.224`

这不是两个不同规则，而是同一个边界的两种表示。

## 为什么 `/27` 会变成“32 个地址一块”

`/27` 后面剩 5 位可以变化。

5 个二进制位从全 0 到全 1，一共有 32 种不同组合。

因此在前三个字节固定的例子里，第四个字节不是任意乱分，而是每 **32 个地址**形成一个块：

| 地址块 | 第四段范围 |
| --- | --- |
| 第 1 块 | 0～31 |
| 第 2 块 | 32～63 |
| 第 3 块 | 64～95 |
| 第 4 块 | 96～127 |
| 第 5 块 | 128～159 |
| 第 6 块 | 160～191 |
| 第 7 块 | 192～223 |
| 第 8 块 | 224～255 |

所以 `192.168.10.70/27` 里的 70 落在哪？

它在 **64～95** 这一块。

到这里先不要急着背网络地址和广播地址。

你现在只需要形成这个动作：

> **看到前缀 → 知道剩几位 → 知道每块有多大 → 找具体 IP 落在哪一块。**

下一篇再解释为什么块头和块尾有特殊意义。

## 为什么前缀越长，单个网络反而越小

这个地方很容易凭直觉搞反。

例如：

- `/24` 剩 8 位变化；
- `/27` 只剩 5 位变化。

前缀越长，意味着更多位已经被固定成“网络前缀”，留给一个地址块内部变化的位反而越少。

所以：

> **前缀越长 → 单个地址块越小。**

这也是做子网划分时“借走更多主机位，就能切出更多、更小子网”的根本原因。

## CIDR 为什么比老式 A/B/C 类更适合现在的题

早期分类地址会把网络边界固定在若干默认位置。

CIDR 直接用 `/n` 写出边界，可以是 `/20`、`/27`、`/30` 等，更灵活。

因此现在做题时：

> **题目给了 `/n` 或子网掩码，就以它为准。**

不要看到地址首段就先套 A/B/C 类默认边界。

## 这一篇解决了什么，还剩什么没解决

现在你已经可以看到 `192.168.10.70/27`，知道：

- `/27` 是网络/主机分界；
- 对应掩码 `255.255.255.224`；
- 每块 32 个地址；
- 70 落在 64～95 这一块。

但新的问题是：

> **64～95 这 32 个地址里，为什么 64 不能普通主机随便用？为什么 95 也特殊？真正能分给主机的是哪些？**

下一站 [[子网划分与地址范围计算]] 就只解决这个问题。

## 一句话总结

**`/n` 就是 IPv4 的网络边界：前 n 位固定为网络前缀，剩余位决定地址块大小；先找“这一块”，再谈网络地址、广播地址和主机范围。**
