# 路由表与最长前缀匹配：目标 IP 同时匹配多条路由时走哪一条

> [!summary] 快速复习卡片
> **作用/定位**：承接 ARP 把分组送到网关之后，解释路由器如何根据目的 IP 选择出口和下一跳。
> **核心结论**：一条路由通常包含目标网络/前缀、下一跳或出口；多条路由同时匹配目的 IP 时，优先选择**前缀最长**、范围最具体的一条。
> **经典题型怎么做 / 题干怎么认**：给 `/8、/16、/24、/0` 多条路由 → 先判断哪些能匹配目的 IP → 再选前缀最长者。
> **易错点 / 考试重点**：默认路由 `/0` 能匹配所有地址，但只有没有更具体路由时才兜底使用。

## 先直接回答：路由器收到分组以后在做什么

上一站 [[ARP地址解析]] 已经说明：如果目标不在本地子网，主机会先把帧交给默认网关。

网关通常就是承担路由功能的设备。它收到帧后取出里面的 IP 分组，查看**目的 IP**，再查询自己的**路由表**：

> **哪些目的网络应该从哪个出口/下一跳继续走？**

路由表最小可以理解成一张“**目标网络范围 → 下一步往哪里走**”的表。

## 一条路由至少看什么

| 字段 | 含义 |
| --- | --- |
| 目标网络/前缀 | 这条路由负责哪些目的地址 |
| 下一跳 | 接下来交给哪个路由器 |
| 出口接口 | 从本机哪个接口发出去 |

有些路由是接口直接连接产生的，有些由管理员配置，还有些是路由协议动态学习来的。

## 为什么会同时匹配多条路由

假设路由表有：

- `10.0.0.0/8 → A`
- `10.1.0.0/16 → B`
- `0.0.0.0/0 → C`

目标 IP 是 `10.1.2.3`。

它确实同时属于：

- 整个 `10.0.0.0/8` 大范围；
- 更具体的 `10.1.0.0/16`；
- `/0` 这个“所有地址都能匹配”的兜底范围。

如果直接随便选一条，路由就不确定。所以规定：

> **选择前缀最长的匹配项，也就是范围最小、描述目标最具体的那一条。**

这里 `/16` 比 `/8` 更具体，因此走 B。

## 三种常见路由来源

- **直连路由**：某个网络直接连接在本路由器接口上；
- **静态路由**：管理员手工告诉设备“这个目标往哪走”；
- **动态路由**：设备通过路由协议自动交换和学习路径信息。

[[自治系统与IGP-BGP]] 会继续解释动态路由为什么区分“组织内部”和“组织之间”，但它属于路由专题支线，不再挡住主线。

## 为什么主下一站进入传输层

到这里，网络层的主问题已经闭环：

**IP 标识跨网络目标 → ARP 解决当前一跳的二层交付 → 路由器按目的 IP 选下一跳。**

这样数据最终可以到达目标主机。但“到达主机”还不等于“完成通信”：目标主机上可能同时运行很多程序，而且不同应用对可靠性、顺序和开销要求不同。

所以下一步进入传输层，先看 TCP 和 UDP 为什么提供两种不同的端到端服务风格。

## 一句话总结

**路由器按目的 IP 查路由表；多条都匹配时选最长前缀，`/0` 只负责最后兜底。网络层把数据送到主机，下一步还要解决主机上的端到端传输。**
