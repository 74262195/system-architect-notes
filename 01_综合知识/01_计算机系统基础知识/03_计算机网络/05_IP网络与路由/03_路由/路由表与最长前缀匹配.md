# 路由表与最长前缀匹配：目标 IP 同时匹配多条路由时走哪一条

> [!summary] 快速复习卡片
> **作用/定位**：解释路由器收到 IP 分组后如何查表选择出口和下一跳。
> **核心结论**：一条路由通常包含目标网络、前缀、下一跳/出口；多条路由同时匹配目的 IP 时，优先选择**前缀最长**、也就是目标范围最具体的一条。
> **经典题型怎么做 / 题干怎么认**：给 `/8、/16、/24、/0` 多条路由 → 先判断哪些能匹配目的 IP，再选前缀最长者。
> **易错点 / 考试重点**：默认路由 `/0` 能匹配所有地址，但只有没有更具体路由时才使用。

## 路由表记录什么

最小理解即可：

| 字段 | 含义 |
| --- | --- |
| 目标网络/前缀 | 这条路由负责哪些目的地址 |
| 下一跳 | 接下来交给哪个路由器 |
| 出口接口 | 从哪个接口发出去 |

## 最长前缀匹配

路由表：

- `10.0.0.0/8 → A`
- `10.1.0.0/16 → B`
- `0.0.0.0/0 → C`

目标 IP：`10.1.2.3`

它同时匹配 `/8`、`/16`、`/0`，其中 `/16` 最具体，所以走 B。

> **最长前缀 = 网络位更多 = 匹配范围更小、更精确。**

## 三种常见路由来源

- 直连路由：接口直接连接；
- 静态路由：管理员手工指定；
- 动态路由：路由协议学习。

协议类别见 [[自治系统与IGP-BGP]]。

## 一句话总结

**先找所有能匹配目的 IP 的路由，再选前缀最长的一条；`/0` 是最后兜底。**
