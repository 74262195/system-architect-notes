# 自治系统与 IGP/BGP：为什么路由协议要分“内部”和“外部”

> [!summary] 快速复习卡片
> **作用/定位**：把互联网按管理范围分开后，区分“一个范围内部怎么走”和“不同范围之间怎么走”。
>
> **核心结论**：AS 是统一管理路由的一片网络；AS 内部主要用 IGP，不同 AS 之间主要用 BGP。
>
> **题干怎么认**：“自治系统内部”选 IGP；“自治系统之间”选 BGP；RIP、OSPF、IS-IS 都属于 IGP。
>
> **易错点**：IGP 是协议类别，不是某一个具体协议；AS 也不等于一家公司或一个局域网。

## 先看一份数据要走哪两段路

假设你在公司 A 的电脑上访问公司 C 的服务器，数据要走两段路：

1. 先穿过公司 A 的内部网络，找到公司出口。
2. 再经过外部网络，最终到达公司 C。

这两段路不是由同一个人管理：

- 公司内部怎么走，由公司自己决定；
- 从一个组织走到另一个组织，需要不同组织互相通报路线。

因此，路由协议才会分成“内部使用”和“外部使用”两类。

## AS：先说明哪片网络归谁管

互联网上的网络分别归运营商、企业、学校等组织管理。

由同一管理体系控制、执行协调路由策略的一组网络，称为 **自治系统（Autonomous System，AS）**。

大白话说：

> **AS 就是一片“由自己统一管路”的网络区域。**

“自治”不是说它与互联网隔离，而是说这片网络内部采用什么路由策略，主要由管理者自己决定。

需要注意：

- 一个 AS 可以包含很多路由器和网段；
- 一个组织也可能管理多个 AS；
- 所以 AS 不等于“一家公司”，也不等于“一个局域网”。

## IGP：在自己管理的范围内找路

现在先解决公司 A 内部的问题：

> 数据怎样经过公司内部的路由器，到达公司出口？

在一个 AS 内部使用的路由协议，统称为 **内部网关协议（Interior Gateway Protocol，IGP）**。

一句话记忆：

> **IGP 管 AS 内部怎么走。**

IGP 是一类协议的总称，常见成员有 RIP、OSPF 和 IS-IS。

它们都在帮助内部路由器学习路线，只是方法不同：

- **RIP**：主要向邻居打听“经过你还要走多远”，属于距离向量协议；
- **OSPF、IS-IS**：先了解网络的连接情况，再计算路线，属于链路状态协议。

复习到这里就够了，不继续展开算法和报文细节。

## BGP：不同管理范围之间互相报路

公司 A 内部的路解决了，数据离开公司后，还要经过其他 AS。

这时要解决的问题变成：

> 哪个 AS 可以到达哪些网络？

不同 AS 之间交换路由信息的代表性协议是 **边界网关协议（Border Gateway Protocol，BGP）**。

一句话记忆：

> **BGP 管 AS 之间怎么走。**

例如，公司 C 所在的 AS 可以通过 BGP 告诉其他 AS：“这段目标网络可以经过我到达。”其他 AS 收到信息后，才知道访问公司 C 时可以把数据交给谁。

当前阶段只掌握 BGP 的位置和作用，不展开路径属性、复杂选路规则和具体配置。

## 把一份数据完整走一遍

公司 A 的电脑访问公司 C，大致经历下面四步：

1. 公司 C 所在的 AS 通过 BGP，让其他 AS 知道它可以到达哪些网络。
2. 这些外部路由信息传到公司 A 的出口路由器。
3. 公司 A 内部的 IGP，让内部路由器知道怎样到达这个出口。
4. 数据包按照路由器已经掌握的路线，逐跳转发到公司 C。

现在三者的关系就清楚了：

> **AS 划定管理范围，IGP 负责范围内部，BGP 负责不同范围之间。**

## 它们和路由表是什么关系

上一站 [[路由表与最长前缀匹配]] 讲的是：数据包来到路由器后，怎样从已有路由表中选择路线。

这一站补上了前一个问题：路由表里的动态路线可以怎样学来。

- IGP、BGP：帮助路由器学习和维护路由；
- 路由表：保存路由器可以使用的路线；
- 最长前缀匹配：数据包到来后，从路由表中选择最具体的匹配路线。

所以不要混淆：

> **IGP、BGP 负责“学路”，最长前缀匹配负责“用已经学到的路”。**

## 考试怎么判断

- 看到“自治系统内部使用” → IGP；
- 看到“自治系统之间交换路由信息” → BGP；
- 看到“距离向量协议” → RIP；
- 看到“链路状态协议” → OSPF、IS-IS；
- 看到“统一管理、执行协调路由策略的一组网络” → AS。

最后只背这一句也可以：

> **一个 AS 内部主要用 IGP，不同 AS 之间主要用 BGP。**
