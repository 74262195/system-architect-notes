# IPv4 报文与分片：大报文遇到更小 MTU 怎么办

> [!summary] 快速复习卡片
> **作用/定位**：网络层为不同链路 MTU 适配报文大小的经典机制与计算题。
> **核心结论**：同一原始报文的分片标识相同；DF=1 禁止分片；MF=1 表示后面还有分片；片偏移以 **8 字节**为单位。
> **经典题型怎么做 / 题干怎么认**：先看“总长度是否超过 MTU、DF 是否允许” → 每片可装的数据先从 MTU 扣 IP 首部 → 非末片数据按 8B 对齐 → 片偏移用“本片数据在原数据中的起始位置 ÷ 8”。
> **易错点 / 考试重点**：MTU 包含 IP 首部；总长度也包含首部；片偏移不是“第几片”。P2，先会动作链，不背冷门首部字段。

## 先定位：MTU 是链路能承载的最大 IP 报文大小约束

IPv4 数据报经过不同链路时，可能遇到更小的 MTU。如果数据报太大且允许分片，就拆成多个较小分片，到目的主机再重组。

## 分片只抓四个字段

| 字段 | 人话 |
| --- | --- |
| Identification | 哪些分片属于同一原始报文 |
| DF | 能不能分片；1 表示禁止 |
| MF | 后面还有没有分片；末片为 0 |
| 片偏移 | 当前片数据在原数据里的位置，单位 8B |

TTL 另一个稳定识别点：每经过路由器通常减少，到 0 时丢弃，用来防止报文在环路中无限转发。

## 计算例子：4000B 报文过 1500B MTU

假设 IPv4 首部 20B：

- 原数据区：4000 - 20 = 3980B；
- 每片最多放数据：1500 - 20 = 1480B；
- 前两片各 1480B，最后剩 1020B；
- 三片数据起点分别是 0、1480、2960；
- 片偏移分别是 0、185、370，因为偏移单位是 8B；
- 前两片 MF=1，最后一片 MF=0。

| 分片 | 数据长度 | 总长度 | 片偏移 | MF |
| --- | ---: | ---: | ---: | ---: |
| 1 | 1480B | 1500B | 0 | 1 |
| 2 | 1480B | 1500B | 185 | 1 |
| 3 | 1020B | 1040B | 370 | 0 |

> **先算“每片能装多少数据”，再算“这一片从原数据哪里开始”。**

## 一句话总结

**算容量先扣首部，算偏移再除 8；DF 决定能不能切，MF 决定后面还有没有。**
