# IP 编址与子网划分：专题入口

这一专题位于“已经知道数据怎样在链路上传输”与“数据怎样跨网络到达远方”之间，先回答三个连续问题：

1. **目的 IP 属于哪个网络？**
2. **当前这一跳应该直接交给目标，还是先交给网关？**
3. **进入路由器以后，下一步应该从哪个出口继续走？**

## 先看懂本专题的主线

| 学习位置 | 当前要解决的问题 | 一句大白话 | 解决后为什么继续 |
| --- | --- | --- | --- |
| [[IPv4地址结构与特殊地址]] | IP 地址由什么组成 | 先知道“网络”和“网络里的某个地址”是两层含义 | 还不知道两部分从哪里分开 |
| [[子网掩码与CIDR]] | `/27` 这样的前缀表示什么 | 用前缀画出网络边界，并算出每块有多大 | 还不知道某个 IP 落在哪块、哪些地址能用 |
| [[子网划分与地址范围计算]] | 给定 IP/前缀怎样求地址范围 | 找到它所在的小区，以及小区的头、尾和普通门牌 | 判断完本地或异地，还缺当前一跳的 MAC |
| [[ARP地址解析]] | 已知当前一跳 IP，怎样得到 MAC | 同网段找目标 MAC，跨网段先找网关 MAC | 分组到了网关，网关还要选择出口 |
| [[路由表与最长前缀匹配]] | 多条路由应该选择哪一条 | 在所有能走的路里，选匹配最具体的一条 | 还要知道这些路由信息从哪里来 |
| [[自治系统与IGP-BGP]] | 路由信息怎样在不同范围传播 | 一个组织内部和不同组织之间使用不同定位的路由协议 | 至此完成“往哪里走”的主线 |

> [!tip] 主线记忆
> **地址说明“我要去哪” → 前缀说明“哪里算同一个网络” → 子网计算决定“直接送还是交网关” → ARP 找当前一跳 MAC → 路由表决定下一跳。**

## 本阶段重点与减负边界

### 需要真正掌握

- 看懂 IPv4 地址、前缀长度和子网掩码分别在表达什么；
- 根据 `IP/前缀` 求网络地址、广播地址和常规主机范围；
- 根据地址范围判断目标在本地还是其他子网；
- 理解这个判断怎样自然引出 ARP 和默认网关；
- 理解路由表的最长前缀匹配动作。

### 暂时不打断主线

- “根据子网数量选择前缀”和 VLSM 地址规划属于子网设计旁支，后续单独整理，不再塞进地址范围计算卡；
- A/B/C 类只做历史识别；
- OSPF、BGP 不进入报文、状态机和完整路径属性；
- `/31`、`/32` 等特殊工程语境只标明边界，不在基础计算卡展开。

## 第一步：先会判断地址属于哪个网络

1. **P2 [[IPv4地址结构与特殊地址]]**：先知道 32 位地址、网络部分/主机部分，以及稳定特殊地址。
2. **P1 [[子网掩码与CIDR]]**：理解 `/n` 怎样划分网络位与主机位。
3. **P1 [[子网划分与地址范围计算]]**：求网络地址、广播地址和常规主机范围，并据此判断本地或跨网段通信。

## 第二步：把 IP 落到当前链路，再跨网络转发

4. **P2 [[ARP地址解析]]**：同网段找目标主机 MAC；跨网段先找默认网关/下一跳 MAC。
5. **P2 [[路由表与最长前缀匹配]]**：路由器根据目的 IP 选择出口和下一跳。
6. **P2 [[自治系统与IGP-BGP]]**：动态路由只掌握 AS 内 IGP、AS 间 BGP 的定位。

## 第三步：补齐 IPv4 报文、反馈和 IPv6 过渡

7. **P2 [[IPv4报文与分片]]**：MTU、分片、片偏移和 TTL。
8. **P2 [[ICMP与Ping]]**：网络层控制/差错反馈和基本可达性。
9. **P2 [[IPv6与IPv4过渡]]**：128 位地址与双栈、隧道、协议转换。

P3 可选旁支：[[RARP反向地址解析]]。

## 推荐学习顺序

**IPv4 地址 → CIDR → 子网范围与本地判断 → ARP → 路由表 → AS/IGP/BGP → IPv4 分片/TTL → ICMP → IPv6 → TCP/UDP。**
