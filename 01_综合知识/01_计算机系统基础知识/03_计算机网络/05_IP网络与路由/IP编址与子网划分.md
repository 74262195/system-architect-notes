# IP 编址与子网划分：专题入口

这部分原来把“IPv4 地址结构、CIDR、子网计算、特殊地址、VLSM”全部塞在一张卡里，已经超过单一主问题。现在按做题链拆开：

1. **P2 [[IPv4地址结构与特殊地址]]**：先知道 32 位地址、网络部分/主机部分，以及稳定特殊地址。
2. **P1 [[子网掩码与CIDR]]**：理解 `/n` 怎样划分网络位与主机位。
3. **P1 [[子网划分与地址范围计算]]**：真正做网络地址、广播地址、可用主机范围和基本子网数计算。

相关但不是同一个问题：

- **P2 [[ARP地址解析]]**：当前 IPv4 链路中 IP → MAC；
- **P2 [[ICMP与Ping]]**：网络层控制/差错信息；
- **P2 [[IPv4报文与分片]]**：MTU 与分片；
- **P2 [[IPv6与IPv4过渡]]**：IPv6 与融合过渡；
- **P2 [[路由协议与路由选择]]**：跨网段后怎样选择下一跳。

> **减负边界**：A/B/C 类只做历史识别；VLSM 只理解“按需求使用不同前缀、通常先分最大子网”，不扩展复杂地址规划题。

## 推荐学习顺序

`IPv4 地址结构 → 子网掩码/CIDR → 子网边界计算 → ARP/ICMP → 路由`
