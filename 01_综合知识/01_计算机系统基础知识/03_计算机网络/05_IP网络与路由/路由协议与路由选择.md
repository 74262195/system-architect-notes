# 路由协议与路由选择：目标不在本地网段时下一跳给谁

> [!summary] 快速复习卡片
> **作用/定位**：子网边界确定以后，解决跨网络分组应该从哪个出口、交给哪个下一跳。
> **核心结论**：路由协议负责“学路”，路由表负责“记路”，转发负责“按表走”；多条路由都匹配时优先**最长前缀匹配**；IGP 管 AS 内，BGP 重点管 AS 之间。
> **经典题型怎么做 / 题干怎么认**：给 `/8、/16、/0` 多条匹配 → 选前缀最长者；AS 内 → IGP；AS 之间/Internet 域间/边界网关 → BGP；管理员手工写路径 → 静态路由。
> **易错点 / 考试重点**：路由选择属于网络层，不是数据链路层；IGP 是一类协议的统称，不是单一协议名；P2，不展开 RIP/OSPF/BGP 报文和算法细节。

## 路由器实际做什么

收到 IP 分组后：

1. 查看目的 IP；
2. 在路由表中找能匹配的目标网络；
3. 如果多条都匹配，选最具体的前缀；
4. 得到出口接口和下一跳；
5. 为下一条链路重新封装二层帧并发出。

例如：

- `10.0.0.0/8 → A`
- `10.1.0.0/16 → B`
- `0.0.0.0/0 → C`

目标 `10.1.2.3` 同时匹配 `/8` 和 `/16`，但 `/16` 更具体，所以走 B。

## 路由从哪里来

- 直连路由：接口直接连接的网络；
- 静态路由：管理员手工配置；
- 动态路由：通过路由协议学习。

互联网由多个自治系统 AS 组成，所以动态协议常分：

- AS 内部：IGP 类；
- AS 之间：BGP 是核心域间路由协议。

## MAC 和 IP 在跨路由时怎么变

IP 目的地址始终指向最终目标主机；每经过一台路由器，当前链路的二层 MAC 封装会重新生成，因此“下一跳 MAC”会变化。

## 一句话总结

**协议学路、表里记路、收到包以后按最长前缀走；IGP 管内部，BGP 管 AS 之间。**
