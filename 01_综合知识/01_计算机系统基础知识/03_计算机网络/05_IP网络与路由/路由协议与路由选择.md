# 路由协议与路由选择：专题入口

原文件同时回答了“路由器怎样查表”和“动态协议怎样分类”两个问题，现在拆开：

1. **P2 [[路由表与最长前缀匹配]]**：路由表、下一跳、默认路由、最长前缀匹配。
2. **P2 [[自治系统与IGP-BGP]]**：AS 内/AS 间的协议定位。

相关前置：

- [[子网掩码与CIDR]]：路由表中的目标网络为什么带前缀；
- [[子网划分与地址范围计算]]：先知道目的 IP 属于哪个网段；
- [[ARP地址解析]]：选出下一跳以后，当前链路还要知道下一跳 MAC。

> **减负边界**：RIP、OSPF 只识别其属于 IGP 类；BGP 只识别域间定位。当前不进入协议报文、状态机、LSA、路径属性和厂商配置。

## 固定理解链

`目的 IP → 查路由表 → 最长前缀 → 得到下一跳/出口 → 当前链路解析下一跳 MAC`
