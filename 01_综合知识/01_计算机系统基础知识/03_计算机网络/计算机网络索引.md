# 一、先看整个网络是怎么串起来的

```text
应用协议
  ↓
TCP / UDP + 端口
  ↓
IP 地址 + 路由
  ↓
当前链路 ARP 找 MAC
  ↓
交换机按 MAC 转发帧
  ↓
以太网 / WLAN 把比特真正送出去
```

这条链比背文件目录更重要。

## 8. IP 控制与当前链路：有 IP 以后为什么还要 MAC

目录：`05_IP网络与路由/01_IP控制与邻居发现`

- P2 [[ARP地址解析]]：当前 IPv4 链路 IP → MAC
- P2 [[ICMP与Ping]]：网络层控制/差错信息

关键区别：

- DNS：名字 → IP；
- ARP：当前链路 IP → MAC；
- ICMP：网络层状态/差错反馈。

# 五、明确不重复/不扩展

- CRC：本章只在 [[以太网技术]] 的 FCS 建立联系；CRC 算法本身回到校验码主线，不再复制一套。

- TCP 内核机制：不进入拥塞窗口、TIME_WAIT、状态机实现细节。
- OSPF/BGP：不进入网络工程师级协议内部细节。
