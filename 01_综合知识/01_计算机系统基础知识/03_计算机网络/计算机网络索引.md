## 本章最重要的易混点

| 容易混 | 一句话区分 |
| --- | --- |
| OSI vs TCP/IP | 七层职责参考模型 vs Internet 四层协议体系 |
| 数据链路层 vs 网络层 | 帧/MAC vs IP/路由 |
| CSMA/CD vs CSMA/CA | 有线传统共享“检测” vs 无线“避免” |
| 交换机 vs 路由器 | MAC 二层转发 vs IP 三层转发 |
| TCP vs UDP | 可靠有序连接字节流 vs 无连接数据报 |
| 发送 vs 传播时延 | 数据量/速率 vs 距离/传播速度 |
| STP vs 链路聚合 | 防二层环路 vs 多链路合成逻辑链路 |
| 双栈 vs 隧道 vs 转换 | 两种都会 vs 套壳穿过 vs 中间翻译 |
