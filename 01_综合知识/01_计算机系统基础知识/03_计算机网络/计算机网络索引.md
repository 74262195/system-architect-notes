# 一、先抓住本章真正的主线

学习计算机网络时，不把几十个考点平铺成一串。主线只回答一个问题：

> **网络从“几台机器想通信”，是怎样一步步发展成今天能够跨网络、跨主机、跨应用通信的互联网的？**

主干可以压成：

**为什么需要联网 → 网络规模扩大 → 需要统一协议 → 协议复杂后需要分层 → OSI/TCP-IP 建立职责体系 → 局域网用帧、MAC、交换机通信 → IP 解决跨网络寻址 → 路由解决下一跳 → TCP/UDP 和端口把数据交给进程 → 应用层协议完成具体业务 → 无线、移动通信、5G 等继续扩展网络形态 → 最后进入现实网络的组网与工程建设。**

这条主线解决的是**理解顺序**。P0/P1/P2/P3 解决的是**复习投入多少时间**，两者不能混在一起。

# 七、明确不重复/不扩展

- CRC：本章只在 [[以太网技术]] 的 FCS 建立联系；算法本身回校验码主线。
- NAT：当前不建立独立主线卡；官方第 2 版网络基础章节未明确展开，除非后续现行真题形成稳定信号。
- TCP：不进入 TIME_WAIT、拥塞窗口、慢开始等实现细节。
- OSPF/BGP：不进入 LSA、状态机、路径属性和厂商配置。
- 5G：网络切片因 2022 真题保留 P2；OFDM/MIMO/毫米波等实现技术仍只 P3 识别。
