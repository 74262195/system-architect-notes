建议顺序：

1. [[计算机网络基本概念与功能]]
2. [[网络性能指标]]
3. [[非性能性指标]]

## 二、通信技术：先把“信息怎么穿过线路”讲明白

核心入口：

1. [[数据通信与交换技术]]

重点掌握：

- 信源 → 发信机 → 信道 → 收信机 → 信宿；
- 编码负责重新表示信息；基带传输可由线路编码直接形成信号，带通信道通常还要调制；
- 接收端根据发送方式完成对应的信号恢复、解调和译码；
- 香农公式；
- FDM/TDM/WDM/CDM 与 FDMA/TDMA/CDMA；
- 电路交换、报文交换、分组交换，以及数据报与虚电路；
- 发送时延与传播时延。

这块是后面所有协议和网络类型的“物理通信底座”。

## 四、组网技术：设备和协议怎样把多张网络真正连起来

这一块内容最多，按“分层 → 二层 → 三层 → 传输 → 应用”走。

### 1. 先看协议分层

[[网络协议与OSI七层]]

掌握：

- OSI 七层；
- TCP/IP 模型；
- 封装与解封装；
- 每层典型协议和设备。

### 2. 网络设备与局域网二层转发

先看：

1. [[网络互联设备]]
2. [[交换机]]
3. [[STP与链路聚合]]

核心：

- MAC 地址学习、泛洪、过滤；
- 冲突域与广播域；
- VLAN；
- STP 防二层环路；
- 链路聚合增加带宽和冗余。

按层次识别：

> **中继/集线看信号，交换看 MAC，路由看 IP，网关做协议转换。**

再把二层机制说清：

> **交换机先学源 MAC，再查目的 MAC；STP 把冗余拓扑逻辑剪成无环树，链路聚合把多条物理链路组成一个逻辑接口。**

### 3. IP 地址和网络层

依次看：

1. [[IP编址与子网划分]]
2. [[IPv4报文与分片]]
3. [[IPv6与IPv4过渡]]
4. [[路由协议与路由选择]]

核心：

- CIDR / VLSM；
- 网络地址、广播地址、可用主机数；
- MTU 与 IPv4 分片；
- IPv6 单播/组播/任播；
- 双协议栈、隧道、NAT-PT；
- 路由表、下一跳、IGP、BGP。

### 4. 端到端传输与应用服务

先用 [[TCP与UDP协议]] 建立总览，再按机制学习：

1. [[TCP与UDP对比]]
2. [[端口与进程通信]]
3. [[TCP三次握手]]
4. [[TCP可靠传输机制]]
5. [[TCP流量控制与拥塞控制]]
6. [[TCP四次挥手]]
7. [[应用层常用协议]]

核心：

- TCP 的序号、累计确认、窗口与重传怎样形成可靠闭环；
- rwnd 保护接收端，cwnd 保护网络；
- 四次挥手为什么按方向关闭，TIME_WAIT 为什么仍要等待；
- DNS / DHCP / HTTP(S) / FTP / 邮件 / SNMP 等。

## 重点易混总表

| 容易混 | 一句话区分 |
| --- | --- |
| 发送时延 vs 传播时延 | 一个看数据量/速率，一个看距离/传播速度 |
| FDM vs FDMA | 一个偏多路复用，一个偏多用户接入 |
| CSMA/CD vs CSMA/CA | 有线传统共享介质“检测”，无线“避免” |
| 交换机 vs 路由器 | MAC 二层转发 vs IP 三层转发 |
| 冲突域 vs 广播域 | 碰撞范围 vs 广播传播范围 |
| STP vs 链路聚合 | 防环 vs 多链路合并 |
| CIDR vs VLSM | 聚合/无类别前缀 vs 按需不同子网大小 |
| IPv4 vs IPv6 | 32 位 vs 128 位 |
| IGP vs BGP | AS 内部 vs AS 之间 |
| TCP 流量控制 vs 拥塞控制 | 防接收端撑爆 vs 防网络拥塞 |
