# IPv6 与 IPv4 过渡：新旧网络怎样共存

> [!summary] 快速复习卡片
> **作用/定位**：IPv4 地址空间不足后的网络层地址体系，以及 IPv4/IPv6 共存阶段的互通方法。
> **核心结论**：IPv6 地址 128 位；常见目的地址有单播、组播、任播；过渡重点认 **双协议栈、隧道、协议转换**。
> **经典题型怎么做 / 题干怎么认**：设备自己同时懂 IPv4/IPv6 → 双栈；两端懂 IPv6、中间只有 IPv4 → 隧道；一端只懂 IPv4、一端只懂 IPv6 → 协议转换。
> **易错点 / 考试重点**：任播不是发给全部成员，而是由路由送往其中一个合适成员；NAT-PT 按教材识别，不把它当现代唯一方案。

## IPv6 先抓住什么

IPv4 地址 32 位，IPv6 扩展为 128 位。IPv6 常写成 8 组十六进制数，连续全 0 可以用 `::` 压缩，但一个地址里 `::` 只能用一次，否则无法确定省略了多少组。

目的地址类型：

| 类型 | 人话 |
| --- | --- |
| 单播 | 发给一个接口 |
| 组播 | 发给一组接口 |
| 任播 | 发给一组接口中的一个合适成员 |

IPv6 不沿用 IPv4 的广播机制，很多场景改用组播。

## 三种过渡方法用场景判断

### 双协议栈
设备同时运行 IPv4 和 IPv6，按对端和网络条件选择协议。

### 隧道
中间网络不懂内层协议，就先套一个中间网络能转发的外壳，穿过去后再解封装。

### 协议转换
通信两端只支持不同版本，由中间设备完成地址/协议表示的转换。

> **双栈 = 自己两种都会；隧道 = 套壳穿过去；转换 = 中间翻译。**

## 第一轮不要背什么

不需要记大量 IPv6 首部字段、扩展首部细节或所有过渡技术名称。当前先做到：看到场景能选对“双栈/隧道/转换”，能区分单播/组播/任播。

## 一句话总结

**IPv6 记 128 位；过渡题先看谁懂 IPv4、谁懂 IPv6，再选双栈、隧道或转换。**
