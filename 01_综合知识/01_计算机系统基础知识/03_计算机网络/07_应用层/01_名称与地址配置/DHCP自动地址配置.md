# DHCP 自动地址配置：新主机刚接入网络时 IP 从哪里来

> [!summary] 快速复习卡片
> **作用/定位**：应用层协议中的“网络接入第一步”，自动给主机提供 IP、子网掩码、默认网关、DNS 等网络配置。
> **核心结论**：DHCP 属于应用层；常见客户端/服务器端口 68/67；基础流程可记 DORA：Discover → Offer → Request → ACK。
> **经典题型怎么做 / 题干怎么认**：自动获取 IP、租约、67/68、Discover/Offer → DHCP。
> **易错点 / 考试重点**：DHCP 是“发配置”，DNS 是“查域名”；两者都是应用层但解决不同问题。

## 先直接回答：为什么不能让每台电脑都手工写 IP

上一站 [[应用层协议功能与端口识别]] 已经知道 DHCP 负责自动网络配置。

小网络当然可以手工填 IP、掩码、网关和 DNS，但主机一多就很麻烦：

- 容易给两台机器配置重复 IP；
- 人工修改成本高；
- 设备临时接入/离开时地址难管理；
- 网关、DNS 等公共参数变化时要逐台改。

DHCP 让客户端刚接入网络时，自动向服务器申请一组可用配置，并按租约使用。

## DORA 四步到底在做什么

1. **Discover**：客户端说“网络里有没有 DHCP 服务器？”；
2. **Offer**：服务器说“我可以给你这套地址配置”；
3. **Request**：客户端说“我要使用这套配置”；
4. **ACK**：服务器确认“可以，租约生效”。

当前只需要理解动作含义，不进入 DHCP Relay、Option 字段和服务器配置。

## DHCP 通常会给什么

考试里最常见的是：

- IP 地址；
- 子网掩码；
- 默认网关；
- DNS 服务器地址。

这也自然引出下一步：拿到 DNS 服务器地址后，用户输入一个域名时，怎样找到真正的服务器 IP？

## 一句话总结

**DHCP 解决“刚接入网络，我的 IP、掩码、网关、DNS 等配置从哪里来”；DORA 是发现、提供、请求、确认。**
