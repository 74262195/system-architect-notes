# 应用层协议功能与端口识别：看到业务动作先想到哪个协议

> [!summary] 快速复习卡片
> **作用/定位**：把域名、地址配置、网页、文件、邮件、远程管理等业务动作映射到应用层协议。
> **核心结论**：DNS 查域名；DHCP 发网络配置；HTTP/HTTPS 访问 Web；FTP 传文件；SMTP 发邮件；POP3/IMAP 收邮件；Telnet/SSH 远程登录；NFS 提供网络文件服务；SNMP 做网络管理。
> **经典题型怎么做 / 题干怎么认**：先按“功能/所在层次”选协议，再用默认端口校验；2024 分层题要求能认出 NFS、Telnet、FTP、SMTP 都属于应用层。
> **易错点 / 考试重点**：SMTP 是发，POP3/IMAP 是收；DNS 常见端口 53；IP/ICMP 属于网络层，TCP/UDP 属于传输层。

## 第一轮：必须会认

| 功能 | 协议 | 常见端口/备注 |
| --- | --- | --- |
| 域名解析 | DNS | 53 |
| 自动网络配置 | DHCP | 67/68 |
| Web | HTTP | 80 |
| 加密 Web | HTTPS | 443 |
| 文件传输 | FTP | 21（控制） |
| 网络文件服务 | NFS | **记功能和应用层即可，不背端口** |
| 安全远程登录 | SSH | 22 |
| 明文远程终端 | Telnet | 23 |
| 发邮件 | SMTP | 25 |
| 收邮件 | POP3 | 110 |
| 收邮件/服务器同步 | IMAP | 143 |
| 网络管理 | SNMP | 161/162 |

> 第一轮重点不是把端口表全部默写，而是 **协议功能 + 所在层次**。端口只记稳定高频映射。

## 教程明确但当前低频：最低识别

| 协议 | 最小识别 |
| --- | --- |
| NNTP | 网络新闻传输协议，应用层 |

NNTP 不单独建学习任务，也不背端口和报文流程。以后若近年真题重新出现，再按证据升级。

## 一句话总结

**功能先认协议，层次先拿分：NFS/Telnet/FTP/SMTP 都是应用层；DNS 找 IP，HTTP 谈 Web，SMTP 发信，POP3/IMAP 收信。**
