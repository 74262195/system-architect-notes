# 应用层协议功能与端口识别：看到业务动作先想到哪个协议

> [!summary] 快速复习卡片
> **作用/定位**：把域名、地址配置、网页、文件、邮件、远程管理等业务动作映射到协议。
> **核心结论**：DNS 查域名；DHCP 发网络配置；HTTP/HTTPS 访问 Web；FTP 传文件；SMTP 发邮件；POP3/IMAP 收邮件；SSH 安全远程登录；SNMP 做网络管理。
> **经典题型怎么做 / 题干怎么认**：先按“功能”选协议，再用默认端口校验，不要先背数字再猜功能。
> **易错点 / 考试重点**：SMTP 是发，POP3/IMAP 是收；DNS 常见端口 53；ICMP/ARP 不属于应用层。

## 高频映射

| 功能 | 协议 | 常见端口 |
| --- | --- | ---: |
| 域名解析 | DNS | 53 |
| 自动网络配置 | DHCP | 67/68 |
| Web | HTTP | 80 |
| 加密 Web | HTTPS | 443 |
| 文件传输 | FTP | 21（控制） |
| 安全远程登录 | SSH | 22 |
| 明文远程终端 | Telnet | 23 |
| 发邮件 | SMTP | 25 |
| 收邮件 | POP3 | 110 |
| 网络管理 | SNMP | 161/162 |

第一轮只要求稳定映射。协议内部流程见专题卡，时间紧可以不展开。

## 一句话总结

**功能先认协议，端口只做校验：DNS 找 IP，HTTP 谈 Web，SMTP 发信，POP3/IMAP 收信。**
