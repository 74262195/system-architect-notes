# 电子邮件协议：SMTP 为什么是发信，而 POP3/IMAP 是收信

> [!summary] 快速复习卡片
> **作用/定位**：区分电子邮件发送与接收使用的应用层协议。
> **核心结论**：SMTP 负责发送/转发邮件；POP3 与 IMAP 用于接收邮件；三者都属于应用层。
> **经典题型怎么做 / 题干怎么认**：发邮件/邮件服务器转发 → SMTP；下载式收信 → POP3；服务器端同步管理 → IMAP。
> **易错点 / 考试重点**：SMTP 不是收信协议；第一轮优先记 SMTP 25、POP3 110，IMAP 主要记功能即可。

## 最小关系

发送邮件：

`客户端 → SMTP → 邮件服务器 → SMTP → 对方邮件服务器`

用户读取邮件时，再使用 POP3 或 IMAP 类协议访问邮箱。

## POP3 与 IMAP 只需这样区分

- POP3：传统上更强调把邮件取到本地；
- IMAP：更强调服务器端保留、同步和管理。

当前不需要学习邮件头字段、MIME 编码和服务器配置。

## 一句话总结

**SMTP 管发，POP3/IMAP 管收；看到邮件题先判断题目问的是“发送”还是“接收”。**
