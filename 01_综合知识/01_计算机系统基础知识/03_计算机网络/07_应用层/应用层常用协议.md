# 应用层常用协议：专题入口

应用层先用一张总识别卡解决“**看到业务动作应该想到哪个协议**”，再沿一次真实联网过程理解几个 P2 协议。

## 第一轮只学这一张

- **P1 [[应用层协议功能与端口识别]]**：先按功能认协议，再用常见默认端口校验。

## 第二轮按真实使用顺序

### 先让主机具备联网参数
- **P2 [[DHCP自动地址配置]]**：自动下发 IP、掩码、网关、DNS；基础流程识别 DORA。

### 再把名字变成可以路由的地址
- **P2 [[DNS域名解析]]**：域名 → IP。

### 找到服务器后进入具体业务
- **P2 [[HTTP与HTTPS]]**：Web 请求/响应与安全 Web。
- **P2 [[FTP文件传输]]**：文件上传下载协议识别。
- **P2 [[电子邮件协议]]**：SMTP 发，POP3/IMAP 收。

### 只在总识别卡保留，不再单独扩展
- SSH / Telnet：安全远程登录 vs 明文远程终端；
- NFS：网络文件服务；
- SNMP：网络管理；
- NNTP 等低信号协议：最低识别。

> **减负边界**：不学习 HTTP 报文头全集、TLS 握手细节、FTP 主动/被动模式、DNS 服务器部署、邮件服务器配置。

## 推荐顺序

**应用层总识别 → DHCP → DNS → HTTP/HTTPS → FTP → 邮件协议 → WLAN。**
