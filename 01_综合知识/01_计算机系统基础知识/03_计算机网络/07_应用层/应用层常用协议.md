# 应用层常用协议：专题入口

原文件把 DNS、DHCP、HTTP、FTP、邮件、SSH、SNMP 全部放进一张考点卡，不利于定位。现在改成“**一张 P1 总识别卡 + P2 原子理解卡**”。

## 第一轮只学这一张

- **P1 [[应用层协议功能与端口识别]]**：按功能认协议，再用常见端口校验。

## 第二轮按业务拆开

### 名称与地址配置
- **P2 [[DNS域名解析]]**：域名 → IP。
- **P2 [[DHCP自动地址配置]]**：自动下发 IP、掩码、网关、DNS；DORA。

### Web 与文件
- **P2 [[HTTP与HTTPS]]**：Web 请求/响应与安全 Web。
- **P2 [[FTP文件传输]]**：文件上传下载协议识别。

### 邮件
- **P2 [[电子邮件协议]]**：SMTP 发，POP3/IMAP 收。

### 只在总识别卡保留，不再单独扩展
- SSH / Telnet：安全远程登录 vs 明文远程终端；
- SNMP：网络管理；
- TFTP 等低频协议：仅在真题出现时按最小知识补充。

> **减负边界**：不学习 HTTP 报文头全集、TLS 握手细节、FTP 主动/被动模式、DNS 服务器部署、邮件服务器配置。

## 推荐顺序

`DNS → DHCP → HTTP/HTTPS → FTP → 邮件协议`
