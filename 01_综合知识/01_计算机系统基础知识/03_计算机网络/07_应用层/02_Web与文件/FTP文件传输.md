# FTP 文件传输：专门用于文件上传下载的应用层协议

> [!summary] 快速复习卡片
> **作用/定位**：在客户端和服务器之间传输文件。
> **核心结论**：FTP 属于应用层；常见控制连接端口 21；题目看到“文件上传/下载、FTP”先定位到应用层。
> **经典题型怎么做 / 题干怎么认**：文件传输、上传下载、21 → FTP。
> **易错点 / 考试重点**：不要把 FTP 和 HTTP 下载混成同一个协议；考试只要求识别，不需要背主动/被动模式端口细节。

## 学到哪里就够

当前只保留：

- FTP 的用途；
- 应用层定位；
- 常见控制端口 21。

不进入：主动/被动模式握手、数据连接端口分配和服务器配置。

## 一句话总结

**FTP = 应用层文件传输协议；识别“上传/下载 + 21”即可。**
