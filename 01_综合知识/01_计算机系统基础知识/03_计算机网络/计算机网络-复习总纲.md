# 计算机网络：减负复习总纲

本页只负责复习顺序，不替代原子考点卡。

> **当前原则：大纲定范围，教材定深度，近年真题定优先级。第一轮先拿能直接决定选项的分，第二轮再补机制和计算，P3 时间紧可以跳。**

## 第一轮：P0 当前直接命中

### [[网络协议与OSI七层]]

必须做到：
- 帧/MAC/交换机 → 数据链路层；
- IP/路由器/路由选择 → 网络层；
- TCP/UDP/端口 → 传输层；
- HTTP/DNS/SMTP → 应用层。

近年题眼：2024 直接问路由器所在层；2025H2 已核验回忆题继续考数据链路层职责。

### [[无线局域网802.11]]

必须做到：
- 无线 802.11 → CSMA/CA；
- 和有线传统 CSMA/CD 区分；
- 2026H1 已核验回忆题直接命中：**802.11b 的 5.5 Mb/s、11 Mb/s**。

不要因此背完整 Wi-Fi 速率参数表。

## 第一轮：P1 主线拿分

1. [[IP编址与子网划分]]：前缀 → 地址块 → 网络/广播/主机范围。
2. [[TCP与UDP对比]]：可靠有序字节流 vs 无连接数据报。
3. [[交换机]]：先学源 MAC，再查目的；已知定向、未知泛洪。
4. [[网络互联设备]]：中继看信号、交换看 MAC、路由看 IP、网关做转换。
5. [[应用层常用协议]]：按功能认 DNS/DHCP/HTTP(S)/FTP/SMTP/POP3/SSH，再核对默认端口。

第一轮完成标准：看到题干能在数秒内决定“这是哪层、哪种设备、哪种协议、哪类地址题”。

## P3：时间紧可以暂跳

- [[5G]]：只识别 eMBB/uRLLC/mMTC = 快/准/多。
- [[5G网络切片]]：只识别“一张物理网、多张逻辑网、按需 QoS”。
- [[非性能性指标]]：网络章只识别费用/可靠/扩展/维护；MTBF/MTTR 等放后续质量与可靠性主线统一学。

## 三条历史内容减负规则

1. `SONET / DDN / Frame Relay / ATM`：只记识别词，不展开完整协议。
2. TCP 慢开始/快恢复等：只分清控制对象与阶段，不背不同 TCP 版本的窗口数值变化。
3. 一道旧题出现某技术，不自动把整个技术家族补成 P1。
