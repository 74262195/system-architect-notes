# 计算机网络：减负复习总纲

> **规则：大纲定范围，教材定深度，真题定优先级。大纲点不能因为低频就删；教材里没有支撑、题库也没有稳定信号的工程细节不进入主复习线。**

## 第一轮：P0 当前直接命中

### [[网络协议与OSI七层]]

必须做到：
- 帧/MAC/交换机 → 数据链路层；
- IP/路由器/路由选择 → 网络层；
- TCP/UDP/端口 → 传输层；
- HTTP/DNS/SMTP → 应用层。

### [[无线局域网802.11]]

必须做到：
- 三类 WLAN 拓扑：点对点、HUB 型、完全分布型；
- 无线 802.11 → CSMA/CA；
- 与传统共享式以太网 CSMA/CD 区分；
- 2026H1 已核验回忆题：802.11b 的 **5.5/11 Mb/s**。

## 第一轮：P1 主线

1. [[OSI与TCP-IP协议体系对比]]：七层 ↔ 四层映射。
2. [[IP编址与子网划分]]：前缀 → 地址块 → 网络/广播/主机范围。
3. [[TCP与UDP对比]]：连接可靠字节流 vs 无连接数据报。
4. [[交换机]]：先学源 MAC，再查目的 MAC。
5. [[网络互联设备]]：中继看信号、交换看 MAC、路由看 IP。
6. [[应用层常用协议]]：按功能匹配常用协议与默认端口。

## 已退出本章主复习线

以下内容不再保留独立原子卡：

- TCP 三次握手；
- TCP 四次挥手 / TIME_WAIT；
- TCP 可靠传输内部机制专题；
- TCP 慢开始、拥塞窗口等具体拥塞控制专题；
- 802.1Q 带标签帧最大长度等工程参数；
- 5G SDN/NFV、切片编排生命周期、网元缩写表。

原因不是“这些知识错误”，而是当前**大纲要求 + 网络基础章教材深度 + 题库映射**不足以支持把它们作为独立复习任务。
