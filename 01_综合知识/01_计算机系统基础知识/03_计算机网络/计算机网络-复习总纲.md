# 计算机网络：减负复习总纲

> **先看 [[计算机网络-知识点边界]]。规则：大纲定范围，教材定深度，真题定优先级。大纲/教程点不能因为低频就消失，但低频点也不能因为“存在”就全部升成重点。**

# 第一轮：先拿下 P0 + P1

## P0：当前优先命中

### [[网络协议与OSI七层]]

必须做到：
- 帧/MAC/交换机 → 数据链路层；
- IP/ICMP/路由器 → 网络层；
- TCP/UDP/端口 → 传输层；
- HTTP/DNS/SMTP → 应用层。

### [[无线局域网802.11]]

必须做到：
- WLAN/802.11 的基本定位；
- 无线 802.11 → CSMA/CA；
- 与传统共享式以太网 CSMA/CD 区分；
- 近年回忆题直接出现过 802.11b 的 5.5/11 Mb/s，当前只保留这一高信号数字，不背完整 Wi-Fi 参数表。

## P1：稳定主线

1. [[OSI与TCP-IP协议体系对比]]：七层 ↔ 四层映射。
2. [[网络互联设备]]：不同设备看什么信息、工作在哪层。
3. [[交换机]]：二层交换机的定位。
4. [[MAC地址与交换机转发表]]：**学源 MAC → 查目的 MAC → 定向转发/泛洪**。
5. [[子网掩码与CIDR]]：`/n` → 网络位/主机位 → 地址块大小。
6. [[子网划分与地址范围计算]]：地址块 → 网络/广播/主机范围。
7. [[TCP与UDP对比]]：连接可靠字节流 vs 无连接数据报。
8. [[应用层协议功能与端口识别]]：按业务功能认协议，端口做校验。

> `IP编址与子网划分`、`应用层常用协议`、`路由协议与路由选择` 现在都是专题导航，不算额外的学习卡。

# 第三轮 / 时间紧可跳：P3 最低识别

- [[非性能性指标]]：费用、质量、标准化、可靠、扩展/升级、管理/维护。
- [[RARP反向地址解析]]：只记 ARP 的反方向，MAC → IP。
- NFS：只记网络文件服务/远程文件访问。
- NNTP：只记网络新闻传输协议。
- [[5G关键通信技术最低识别]]：OFDM、Massive MIMO、毫米波等只认名称与大致作用。
- [[5G网络切片]]：只认“一张物理网、多张逻辑网、按业务隔离”。
- SONET/SDH、DDN、帧中继、ATM：只在 [[网络类型与广域网技术]] 识别。

# 已明确退出本章主复习线

以下不是“永远不存在”，而是**当前不值得形成独立网络复习任务**：

- OSPF LSA、邻居状态机；
- BGP 路径属性和工程选路；
- 交换机/路由器厂商 CLI；
- 复杂 VLSM 地址规划；
- 802.1Q、QinQ 等工程字段与配置；
- TCP TIME_WAIT、拥塞窗口、慢开始等实现细节；
- 5G NR 帧结构、核心网网元、切片编排生命周期；
- NAT 独立专题：当前官方第 2 版网络基础章节未明确展开，暂不因网络常识自行扩展。

CRC 不重复学：CRC 算法回到校验码主线；网络这里只需知道 [[以太网技术]] 的 FCS 用 CRC 做差错检测。

# 闭卷自检：做不到再回正文

- [ ] 看到 MAC / IP / TCP / HTTP，能立刻判断所在层。
- [ ] 能解释交换机为什么“学源 MAC、查目的 MAC”，未知目的为什么泛洪。
- [ ] 能区分交换机、路由器以及冲突域/广播域的基本作用。
- [ ] 给 `/27` 之类前缀，能找网络地址、广播地址、可用主机范围。
- [ ] 能说清 DNS 与 ARP：DNS 是域名 → IP，ARP 是当前链路 IP → MAC。
- [ ] 能说清 ICMP/ping 的定位，知道 ping 通不代表应用服务正常。
- [ ] 给多条路由前缀，知道先匹配再选最长前缀；`/0` 是兜底。
- [ ] 能区分 TCP 与 UDP，并知道端口为什么存在。
- [ ] 能按功能认 DNS、DHCP、HTTP/HTTPS、FTP、SMTP、POP3/IMAP、SSH、SNMP。
- [ ] 能区分 CSMA/CD 与 CSMA/CA。
- [ ] 能说出 5G 三大业务方向和 SBA“服务化、可组合”的核心，不必背网元。
- [ ] 能说出网络规划 → 设计 → 实施各自负责什么。
