# TCP 与 UDP：专题入口

这一专题现在明确分两轮，不再把六张卡全部视为 P1。

## 第一轮：先拿服务差异的分

1. **P1 [[TCP与UDP对比]]**：面向连接/无连接、可靠有序字节流/数据报。

第一轮只要求看到题干能判断“业务需要哪种传输服务”。

## 第二轮：再理解 TCP 为什么能做到

1. **P2 [[端口与进程通信]]**：数据到主机后怎样交给通信端点。
2. **P2 [[TCP三次握手]]**：为什么建立连接需要三次确认。
3. **P2 [[TCP可靠传输机制]]**：序号、ACK、重传、窗口怎样形成可靠闭环。
4. **P2 [[TCP流量控制与拥塞控制]]**：rwnd 保护接收端，cwnd 保护网络。
5. **P2 [[TCP四次挥手]]**：全双工为什么通常分方向关闭。

> **减负原则**：第一轮先会“TCP 与 UDP 怎么选”；后面的 TCP 内部机制统一第二轮，不背不同实现版本的工程细节。
