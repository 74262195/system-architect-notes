# 计算机网络基本概念与功能：为什么要把独立计算机连起来

> [!summary] 快速复习卡片
> **作用/定位**：计算机网络整章的起点，先回答“为什么要联网、联网后获得什么能力”。
> **核心结论**：一台独立计算机只能使用自己能直接访问的数据和资源；把多台计算机通过通信网络连接后，它们才能远程交换数据、共享资源，并进一步协同处理任务和统一管理。
> **经典题型怎么做 / 题干怎么认**：数据通信、资源共享、管理集中化、分布式处理、负荷均衡 → 网络基本功能。
> **易错点 / 考试重点**：把设备连接起来只是建立通信条件；真正交换数据还必须遵守共同的通信协议。

## 先直接回答这张卡的两个问题

### 1. 为什么要把计算机连起来？

因为**独立工作的计算机彼此不能直接使用对方的数据、硬件和计算能力**。

例如有两台彼此独立的计算机：

- A 上有一份文件，B 想使用；
- B 连接着一台打印机，A 想打印；
- A 和 B 想共同处理一个大任务。

如果没有网络，就只能靠移动存储设备人工复制文件、分别配置资源，或者把任务集中到一台机器上处理。

把它们连接成网络，最直接的目的就是：**让原本彼此独立的计算机能够交换信息、共享资源和协同工作。**

### 2. 连起来之后想获得什么能力？

教材把这些能力概括成五类：

| 能力 | 实际在解决什么 |
| --- | --- |
| 数据通信 | A 能把数据直接发送给 B |
| 资源共享 | A 能使用 B 提供的文件、打印机、服务等资源 |
| 管理集中化 | 多台设备和业务可以通过网络统一管理 |
| 分布式处理 | 一个任务可以拆给多台计算机共同完成 |
| 负荷均衡 | 工作量可以分配给更空闲或更合适的计算机 |

所以这五个名词不是孤立定义，它们都在回答同一个问题：

> **联网以后，多台原本独立的计算机能一起做哪些以前做不到或很麻烦的事情？**

## 有了连接以后，为什么还需要“协议”

要让 A 和 B 通信，首先当然要有一条能够传递信号的通路。这个通路可以是网线、光纤，也可以是无线电波。

但是“有通路”只解决了**信号能不能到达**，还没有规定双方怎样合作。例如仍然需要约定：

- 怎样表示发送方和接收方；
- 数据按什么格式组织；
- 一次发多少、怎样判断边界；
- 数据出错或丢失时怎么办；
- 目的地不在本地网络时往哪里转发。

这些共同遵守的通信规则，就是后面会反复遇到的**网络协议**。

因此可以把网络先理解成两部分：

> **通信通路负责“能传过去”，协议负责“双方知道该怎么传、怎么理解”。**

## 这张卡在整章哪里

现在只建立了网络的最上层定位：

**独立计算机存在协作需求 → 把它们连接起来 → 获得通信、共享和协同能力 → 要真正通信还需要共同协议。**

后面不再按“目录里下一篇是什么”机械前进，而按网络发展过程中不断出现的新问题继续：

1. 网络最初是怎样一步步扩大成互联网的；
2. 网络规模扩大后，不同系统怎样靠统一协议互联；
3. 协议越来越复杂后为什么必须分层；
4. 局域网内怎样用帧、MAC 和交换机通信；
5. 不同局域网之间怎样用 IP 和路由形成互联网；
6. 数据到达主机后怎样交给正确程序和应用。

主学习链先记成：

**网络为什么存在 → 网络怎样发展 → 协议与分层 → 局域网通信 → IP 跨网 → 路由 → 传输层 → 应用层。**

性能、通信理论、无线和网络工程会在相应阶段作为专题或扩展学习，不再抢主下一站。

## 一句话总结

**计算机联网，是为了让原本独立的计算机能够通信、共享资源和协同工作；通信通路让信号能到达，协议让双方知道怎样正确交换数据。**
