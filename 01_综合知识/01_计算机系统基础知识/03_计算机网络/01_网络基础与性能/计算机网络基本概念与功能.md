# 计算机网络基本概念与功能：为什么要把独立计算机连起来

> [!summary] 快速复习卡片
> **作用/定位**：计算机网络整章的起点，先回答“网络是什么、为什么要联网”。
> **核心结论**：计算机网络把地理上分散、能够独立工作的计算机和通信设备连接起来，并依靠网络软件及通信协议实现信息传递和资源共享。
> **经典题型怎么做 / 题干怎么认**：数据通信、资源共享、管理集中化、分布式处理、负荷均衡 → 网络基本功能。
> **易错点 / 考试重点**：物理线路接通不等于一定能通信，还需要协议规则。

## 这张卡在整章哪里

这一步先不要急着学 IP、TCP 或交换机。

当前只解决两个最基础的问题：

1. **为什么要把计算机连起来？**
2. **连起来之后想获得什么能力？**

知道网络“为什么存在”以后，下一步才有意义去看：**网络最早是什么样，后来为什么逐渐变成今天这种标准化互联网。**

因此主学习链是：

**网络是什么 → 网络怎样发展 → 怎样评价一张网络 → 网络有哪些类型 → 数据到底怎样在网络里传。**

## 为什么“插上线”还不够

物理连接只让信号有路可走，还没有解决：

- 双方怎样标识自己和目标；
- 数据按什么格式传；
- 跨网络怎么找路；
- 到达主机后交给哪个服务。

因此后面才会出现分层协议、MAC、IP、TCP/UDP、应用协议等知识。

> **线路提供通道，协议规定合作规则。**

## 五类基本功能

| 功能 | 人话 |
| --- | --- |
| 数据通信 | 在网络节点之间传递信息 |
| 资源共享 | 共享硬件、软件和数据资源 |
| 管理集中化 | 依托网络统一组织和管理业务 |
| 分布式处理 | 把任务分给多台计算机协同完成 |
| 负荷均衡 | 把工作量分散到负载更合适的系统 |

## 官方五块主线

官方教程把本章分成：

1. 网络基本概念；
2. 通信技术；
3. 网络技术；
4. 组网技术；
5. 网络工程。

可以理解为：**为什么联网 → 信息怎样传 → 有哪些网络 → 协议和设备怎样互联 → 一张网络怎样建设。**

## 一句话总结

**网络 = 独立计算机/通信设备 + 通信线路 + 协议规则，目标是通信、共享和协同。**
