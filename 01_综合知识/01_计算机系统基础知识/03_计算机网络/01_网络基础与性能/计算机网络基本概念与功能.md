# 计算机网络基本概念与功能：为什么要把独立计算机连起来

> [!summary] 快速复习卡片
> **作用/定位**：计算机网络整章父概念，先回答“网络为什么存在”，再进入通信、协议、组网和工程。
> **核心结论**：计算机网络把地理上分散、能够独立工作的计算机通过通信线路和协议连接起来，实现数据通信、资源共享和协同处理。
> **经典题型怎么做 / 题干怎么认**：数据通信、资源共享、分布式处理、负载分担 → 网络功能；带宽/吞吐/时延 → 性能指标；可靠、可扩展、易维护 → 非性能/质量指标。
> **易错点 / 考试重点**：物理线路接通不等于一定能通信，还需要寻址、封装、路由、传输等协议规则；P2，不背空泛定义长句。

## 为什么“插上线”还不够

物理连接只让信号有路可走，还没有解决：

- 双方怎样标识自己和目标；
- 数据按什么格式传；
- 跨网络怎么找路；
- 丢包、乱序怎么办；
- 到达主机后交给哪个应用。

因此后面才会自然出现 OSI、MAC、IP、TCP/UDP、DNS 等知识。

> **线路提供通道，协议规定合作规则。**

## 网络主要提供什么价值

- 数据通信；
- 资源共享；
- 集中管理；
- 分布式处理；
- 负载分担。

其中最值得带走的是：网络不只是“能发数据”，还让不同计算机共享资源、协同工作。

## 后面五块为什么这样排

官方教程将网络分成：

1. 网络基本概念；
2. 通信技术；
3. 网络技术；
4. 组网技术；
5. 网络工程。

可以理解为：**为什么联网 → 数据怎么传 → 有哪些网络 → 协议/设备怎么连 → 真正怎么设计建设。**

## 一句话总结

**网络 = 独立计算机 + 通信通道 + 协议规则，目标是通信、共享和协同。**
