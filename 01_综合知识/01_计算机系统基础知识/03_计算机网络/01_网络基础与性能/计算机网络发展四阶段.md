# 计算机网络发展四阶段：网络从“远程连主机”怎样走到互联网

> [!summary] 快速复习卡片
> **作用/定位**：属于“网络基本概念”的范围确认项，用来认识网络体系为什么逐步走向多主机互联、标准化和互联网。
> **核心结论**：教材把发展概括为 **诞生 → 形成 → 互联互通 → 高速发展** 四阶段。
> **经典题型怎么做 / 题干怎么认**：远程终端围绕单主机 → 诞生；多个主机经通信子网互联 → 形成；统一体系结构/国际标准 → 互联互通；Internet、高速网络普及 → 高速发展。
> **易错点 / 考试重点**：只要求识别阶段特征，不背年代、机构和长篇历史。

## 四阶段只抓“发生了什么变化”

| 阶段 | 核心变化 | 最小题眼 |
| --- | --- | --- |
| 诞生 | 以单台主机为中心，远程终端接入 | 主机 + 终端 |
| 形成 | 多台独立主机通过通信子网互联 | 多主机、资源共享 |
| 互联互通 | 出现统一体系结构和标准 | TCP/IP、OSI、标准化 |
| 高速发展 | 高速局域网、光纤和 Internet 普及 | Internet、高速网络 |

## 为什么要学到这里就停

这个知识点在大纲中明确存在，但它的考试价值主要是“能认出发展阶段”，不是计算机网络史。ARPANET、具体年份、厂商体系结构等不单独扩展成记忆负担。

## 一句话总结

**单主机远程接入 → 多主机联网 → 标准化互联 → 高速互联网。**
