# 计算机网络发展四阶段：网络从“远程连主机”怎样走到互联网

> [!summary] 快速复习卡片
> **作用/定位**：承接“网络为什么存在”，继续回答“网络为什么会变成今天这种多主机、标准化、互联的形态”。
> **核心结论**：教材把发展概括为 **诞生 → 形成 → 互联互通 → 高速发展** 四阶段。
> **经典题型怎么做 / 题干怎么认**：远程终端围绕单主机 → 诞生；多个主机经通信子网互联 → 形成；统一体系结构/国际标准 → 互联互通；Internet、高速网络普及 → 高速发展。
> **易错点 / 考试重点**：只要求识别阶段特征，不背年代、机构和长篇历史。

## 为什么这张卡紧跟“基本概念”

上一站 [[计算机网络基本概念与功能]] 解决的是：**为什么要联网。**

这张卡解决的是：**联网这件事是怎样一步步发展成熟的。**

最重要的不是背历史，而是看出一条变化：

**单台主机为中心 → 多台主机互联 → 不同网络需要统一规则 → Internet 大规模普及。**

这也解释了后面为什么一定会学协议、标准、分层和互联设备：网络规模越大，越不能靠“各自约定”。

## 四阶段只抓“发生了什么变化”

| 阶段 | 核心变化 | 最小题眼 |
| --- | --- | --- |
| 诞生 | 以单台主机为中心，远程终端接入 | 主机 + 终端 |
| 形成 | 多台独立主机通过通信子网互联 | 多主机、资源共享 |
| 互联互通 | 出现统一体系结构和标准 | TCP/IP、OSI、标准化 |
| 高速发展 | 高速局域网、光纤和 Internet 普及 | Internet、高速网络 |

## 为什么学完历史要转到“性能指标”

网络发展到大规模、高速互联以后，问题就从“能不能连起来”变成了：

- 到底有多快？
- 实际能传多少？
- 延迟有多大？
- 链路是不是已经很忙？

这些问题不能再用“感觉快”来描述，而要用统一指标衡量，所以自然进入 [[网络性能指标]]。

## 为什么要学到这里就停

这个知识点在大纲中明确存在，但考试价值主要是“能认出发展阶段”，不是计算机网络史。ARPANET、具体年份、厂商体系结构等不单独扩展成记忆负担。

## 一句话总结

**单主机远程接入 → 多主机联网 → 标准化互联 → 高速互联网。**
