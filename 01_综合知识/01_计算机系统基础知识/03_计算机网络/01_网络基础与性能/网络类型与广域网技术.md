# 网络类型与广域网技术：LAN、MAN、WAN 到底按什么分

> [!summary] 快速复习卡片
> **作用/定位**：先按覆盖范围和接入特征认识主要网络类型，再对教材中的传统 WAN 技术做最低限度识别。
> **核心结论**：LAN/MAN/WAN 主要按覆盖范围从小到大；WLAN 强调局部无线接入；移动通信网强调蜂窝移动接入，详细发展和服务化架构见独立卡。
> **经典题型怎么做 / 题干怎么认**：园区/楼宇 → LAN；城市范围 → MAN；跨城市/国家、运营商远距离 → WAN；Wi-Fi/802.11 → WLAN；蜂窝/1G～5G → 移动通信网。
> **易错点 / 考试重点**：这些类型不是按“速度”排序；SONET/DDN/帧中继/ATM 只做教材历史识别，不扩展工程配置。

## 网络类型

| 类型 | 主要判断维度 | 典型场景 |
| --- | --- | --- |
| LAN | 局部范围 | 办公楼、园区 |
| WLAN | 局部 + 无线 | Wi-Fi |
| MAN | 城市范围 | 城市级网络 |
| WAN | 广区域、远距离 | 跨城市、跨国家互联 |
| 移动通信网 | 蜂窝移动接入 | 1G～5G |

## 广域网教材旧技术只保留识别

| 技术 | 最小识别词 |
| --- | --- |
| SONET/SDH | 同步光传输网络 |
| DDN | 数字数据网、数字专线语境 |
| Frame Relay | 帧中继、虚电路、链路层分组交换 |
| ATM | 固定长度 53B 信元、面向连接 |

此外教材把 WAN 概括为覆盖范围广、通信距离远，常由电信部门/运营商建设管理；可分公共传输网络、专用传输网络、无线传输网络。掌握分类即可。

## 一句话总结

**LAN/MAN/WAN 先看范围；WLAN 看无线局域接入；移动网另看蜂窝移动能力；旧 WAN 技术只识别。**
