# 网络互联设备：设备到底看信号、MAC 还是 IP

> [!summary] 快速复习卡片
> **作用/定位**：把 OSI 分层落到具体设备，回答“设备主要工作在哪一层、根据什么信息处理数据”。
> **核心结论**：中继器/集线器看信号；网桥/二层交换机看 MAC；路由器看 IP 和路由表；网关强调异构协议/数据格式转换；防火墙主要按安全策略控制网络访问。
> **经典题型怎么做 / 题干怎么认**：放大整形 → 中继器；所有端口复制 → 集线器；MAC 表 → 交换机；下一跳/跨网段/IP → 路由器；协议转换 → 网关；安全边界/访问控制 → 防火墙。
> **易错点 / 考试重点**：基础分层题先按设备主要功能判断；真实设备可能跨多层，防火墙不能机械钉死在单一 OSI 层。

## 为什么不同层会出现不同设备

上一站 [[OSI与TCP-IP协议体系对比]] 已经把通信职责分层。职责不同，设备需要“看懂”的信息也不同：

- 只想让衰减的信号继续走，不需要理解地址；
- 想在一个局域网里定向送帧，需要看 MAC；
- 想把数据送往另一个 IP 网络，需要看 IP 和路由；
- 想控制网络边界能不能通过，还要看安全策略。

所以不是先发明很多设备再硬塞进 OSI，而是**不同层要解决的问题不同，自然需要不同处理能力的设备**。

| 设备 | 基础题主要定位 | 看什么 | 主要作用 |
| --- | --- | --- | --- |
| 中继器 | 物理层 | 信号/比特 | 整形、再生、延长距离 |
| 集线器 | 物理层 | 信号/比特 | 把收到的信号复制到其他端口 |
| 网桥 | 数据链路层 | MAC | 过滤和转发帧 |
| 二层交换机 | 数据链路层 | MAC 表 | 学习、定向转发、隔离冲突域 |
| 路由器 | 网络层 | IP、路由表 | 连接不同网络、选择下一跳 |
| 网关 | 高层/跨层语境 | 协议、数据格式 | 异构协议转换 |
| 防火墙 | 安全边界设备 | 规则、连接/报文等 | 按安全策略允许或阻止访问 |

> 防火墙的包过滤、状态检测、应用代理等细节统一放到信息安全技术，本章只建立“安全边界与访问控制”的定位。

## 同一份数据经过网络时怎么想

主机访问另一个网段的服务器：

1. 物理层设备只关心信号能不能继续传；
2. 二层交换机根据 MAC 把当前链路的帧送向正确端口；
3. 路由器根据目的 IP 和路由表决定跨网络的下一步；
4. 网络边界上的防火墙可能再判断这次访问是否允许；
5. 如果两端协议或数据格式本身不兼容，才考虑更高层的网关转换。

> **交换机解决“一跳内往哪个端口送”，路由器解决“跨网络下一步往哪走”，防火墙解决“允不允许过”。**

## 为什么下一站先看“以太网”

设备定位已经清楚了，但如果马上钻交换机内部动作，会缺一个场景：**交换机最典型地工作在局域网的数据链路层，而以太网正是最常见的有线局域网技术。**

所以下一步先建立以太网的帧、MAC 和传统共享介质背景，再回来理解交换机为什么比集线器更聪明。

## 一句话总结

**中继看信号，交换看 MAC，路由看 IP，网关做翻译，防火墙管放行。**
