# OSI 与 TCP/IP：七层参考模型和互联网四层协议体系怎样对应

> [!summary] 快速复习卡片
> **作用/定位**：补上“会背 OSI 七层”之后最容易漏掉的大纲要求：TCP/IP 四层怎样对应，以及两套体系的定位差异。
> **核心结论**：OSI 常作为七层职责参考模型；TCP/IP 是互联网实际广泛使用的协议体系，通常画成 **网络接口层、网际层、传输层、应用层** 四层。
> **经典题型怎么做 / 题干怎么认**：TCP/UDP → 传输层；IP/ICMP → 网际层；HTTP/FTP/SMTP/DNS 等 → 应用层；以太网等 → 网络接口层。
> **易错点 / 考试重点**：OSI 的会话层、表示层在 TCP/IP 四层模型中通常并入应用层；OSI 是模型，TCP/IP 同时有模型和具体协议族，不要把二者当两套同等流行的现实协议栈。

## 对应关系

| OSI 七层 | TCP/IP 四层 | 常见协议/技术 |
| --- | --- | --- |
| 应用层 | 应用层 | HTTP、FTP、SMTP、DNS、SNMP 等 |
| 表示层 | 应用层 | 表示功能通常由应用自己处理 |
| 会话层 | 应用层 | 会话功能通常由应用/协议实现 |
| 传输层 | 传输层 | TCP、UDP |
| 网络层 | 网际层 | IP、ICMP 等 |
| 数据链路层 | 网络接口层 | Ethernet、PPP 等 |
| 物理层 | 网络接口层/具体网络硬件 | 介质、接口、比特传输 |

## 两者最重要的区别

- **OSI**：更像“职责应该怎样分层”的标准参考框架；
- **TCP/IP**：围绕 Internet 形成并实际广泛部署的一组协议及其分层模型。

考试常借 OSI 问层次职责，再借 TCP/IP 问“协议属于哪一层”。掌握对应关系比背 OSI 协议集中大量冷门协议名更有价值。

## 协议集要背到什么程度

大纲写了“OSI 协议集、TCP/IP 协议集”，但教材表格中的大量旧 OSI 协议名不值得全部背。当前边界：

- 能说明 OSI 每层都有相应协议/服务标准；
- 能识别 TCP/IP 的核心层次和常见协议；
- 能完成 OSI ↔ TCP/IP 的层次映射。

不把 `TP0～TP4`、CLNP 等旧协议表扩成独立记忆任务。

## 一句话总结

**OSI 用七层讲职责，TCP/IP 用四层跑互联网；会把协议放回层次、会把七层映射到四层就够。**
