# 以太网技术：传统共享网络为什么要先听再发

> [!summary] 快速复习卡片
> **作用/定位**：有线局域网的数据链路层基础，理解以太网帧和传统共享介质的 CSMA/CD。
> **核心结论**：CSMA/CD = 发送前监听、空闲再发、发送中检测碰撞、碰撞后随机退避重传；现代交换式全双工以太网通常不再靠它处理碰撞。
> **经典题型怎么做 / 题干怎么认**：共享式有线、边发边听、碰撞检测、退避 → CSMA/CD；帧、MAC、FCS → 以太网数据链路层。
> **易错点 / 考试重点**：无线 802.11 用 CSMA/CA，不套 CD；教材经典以太网最小帧长为 64B，数据字段通常最多 1500B。

## CSMA/CD 怎么动作

1. 有数据先监听；
2. 信道忙就等待；
3. 空闲后开始发送；
4. 发送过程中继续检测；
5. 若碰撞，停止发送并随机退避；
6. 等待后重新监听并尝试。

> **CD 是 Collision Detection，检测碰撞；CA 是 Collision Avoidance，尽量避免碰撞。**

## 以太网帧只记高价值字段

| 字段 | 作用 |
| --- | --- |
| 目的 MAC | 帧发给谁 |
| 源 MAC | 帧从谁来 |
| 类型/长度 | 标识上层协议或数据长度 |
| 数据 | 承载 IP 分组等 |
| FCS | CRC 差错检测 |

FCS 能检测传输差错，但不等于以太网会自动把错误帧可靠重传。

## 为什么最小帧长和碰撞有关

共享式以太网中，如果帧太短，发送端可能已经发送完，远端碰撞才传播回来，发送端就无法在发送期间发现碰撞。因此经典以太网规定最小帧长 64B。

当前理解这个因果即可，不展开时隙和距离推导。

## 一句话总结

**有线共享式以太网用 CD：先听、再发、边发边检测；无线 802.11 主要用 CA。**
