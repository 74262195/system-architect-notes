# 端口：IP 已经找到服务器，操作系统怎么知道数据该交给哪个程序

## 先定位：IP 地址只把数据送到“这台主机”

一台服务器上可能同时运行：

- Web 服务；
- DNS 服务；
- 数据库；
- SSH；
- 其他应用。

如果网络分组只带目标 IP：

> **到达这台机器以后，还不知道该交给哪个网络服务。**

传输层用**端口号（port）**继续区分通信端点。

## 地址层次怎么理解

> **IP 找主机，端口找主机里的通信端点/服务。**

例如：

- 目标 IP：203.0.113.10
- 目标端口：443

表示数据先到这台主机，再交给监听 443 端口的对应服务。

## 为什么同一个端口号能在不同主机重复使用

端口不是互联网全局唯一编号。

A 主机可以有 443，B 主机也可以有 443。

真正定位连接时，需要结合：

- IP 地址；
- 传输协议；
- 源/目标端口等信息。

因此不能把端口理解成“全网唯一房间号”。

## 常见端口只是默认约定

HTTP 常见 80，HTTPS 常见 443，DNS 常见 53。

但服务可以配置其他端口。

> **考试题没有额外条件时按常见约定识别；现实部署不能把端口号当成协议身份的绝对证明。**
