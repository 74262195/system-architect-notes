# 编码、调制、解调、译码：信息怎样变成信道能传的信号

> [!summary] 快速复习卡片
> **作用/定位**：处在“发信机/收信机”这一段，解释信息怎样变成适合信道的信号，以及接收端怎样恢复。
> **核心结论**：编码改变信息的表示方式；调制让信息控制载波参数；解调从接收信号中取回承载的信息；译码按编码规则恢复数据。
> **经典题型怎么做 / 题干怎么认**：问“数字信息如何适配带通信道” → 调制；问“按规则重新表示/加入冗余/线路码型” → 编码；接收侧对应解调、译码。
> **易错点 / 考试重点**：编码 ≠ 加密，调制 ≠ 编码；基带线路可经线路编码直接传，带通信道通常还需要调制。

## 四个动作先分清

| 动作 | 人话 |
| --- | --- |
| 编码 | 按规则重新表示信息 |
| 调制 | 让信息控制载波的幅度、频率、相位等 |
| 解调 | 从收到的已调信号中取回信息 |
| 译码 | 按编码规则恢复数据 |

编码还可能按目的分成信源编码、信道编码、线路编码。当前只需要知道它们解决的问题不同，不背算法家族。

## 为什么不是所有通信都必须调制

关键看信道能不能直接承载基带信号：

- 基带传输：线路编码后可直接形成线路信号；
- 带通/频带传输：通常需要把信息调制到载波上，例如无线传输。

> **不要机械背“信息一定先编码再调制”；要先看信道类型。**

## 一句话总结

**编码决定“怎么表示”，调制决定“怎么搭载信道”；接收端再解调、译码恢复。**
