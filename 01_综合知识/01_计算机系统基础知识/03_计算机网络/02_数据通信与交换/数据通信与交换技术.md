# 数据通信与交换技术：专题入口

大纲把通信技术边界写得很明确：**信道、信号变换、复用/多址、5G 通信网**。题库历史上还存在数据通信/交换方式题，因此保留交换方式做第二轮识别。

建议顺序：

1. **P2 [[数据通信基本模型与信道]]**：信源 → 发信机 → 信道 → 收信机 → 信宿。
2. **P2 [[信号变换处理链]]**：信源编码 → 信道编码 → 交织 → 脉冲成形 → 调制。
3. **P2 [[编码调制与解调译码]]**：分清编码、调制、解调、译码。
4. **P2 [[香农公式与信道容量]]**：带宽 + 信噪比限制容量。
5. **P2 [[复用与多址]]**：按频率、时间、码等共享通信资源。
6. **P2 [[电路报文与分组交换]]**：历史真题支持的交换方式辨析，不扩展旧网络实现。
7. 5G 移动通信另见 **P2 [[5G]]**。

> **减负边界**：不补具体调制算法、信道编码算法、滤波器设计、OFDM 参数或通信制式工程参数。
