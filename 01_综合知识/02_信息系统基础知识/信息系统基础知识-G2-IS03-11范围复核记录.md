# G2-IS03-11：IS-A028～IS-A030 范围与反向复核

## 本批执行计划与边界

- **批次与目标**：G2-IS03-11，第一轮“范围与遗漏”审查；只核验 IS-A028、IS-A029、IS-A030。
- **目标文件**：[[企业信息化方法]] 承担 A028，[[电子商务]] 承担 A029，[[企业信息系统战略规划方法]] 承担 A030；[[企业信息化的概念]]、[[企业应用集成EAI]] 与 [[信息系统基础知识复习主线]] 只作相邻边界检查。
- **选择原因**：这是矩阵中最后一组尚未完成第一轮反向复核的 Atom。三项容易混为“企业信息化的一堆做法”，须分别确认：落地方法、交易标准和规划方法各有唯一主事实源。
- **范围与证据**：大纲 PDF 第38页列出企业信息化的规划和方法、电子商务的概念和标准；第63页列出 CSF、SST、BSP。教材 PDF 第160页列出六种企业信息化方法，PDF 第454页说明三种规划方法。2017 年下半年综合知识第18、19题直接辨析 CSF 和 BSP；2009 年下半年综合知识第20题涉及 EDI，但库内解析标为“来源待核验”，故只用作电子商务标准化方向的低强度旁证，不调整 A029 优先级或扩充正文。
- **唯一主问题**：企业的落地路径、交易参与方的商务信息标准、企业信息系统的规划方法，是否都有真实、唯一且不混层的正文承接？
- **预计修改内容**：逐项核验正文、反向映射和相邻边界；新增本记录，并同步矩阵与索引的批次进度。正文仅在发现真实缺口时修改。
- **不会修改的范围**：不进入第二轮概念/机制审查，不扩写 ERP/SCM、EDI 实现、XML 规范细节或 CSF/SST/BSP 以外的规划方法，不转入其他模块。
- **验收标准**：每项均有大纲→主教材→正文具体落点；不以目录、索引或快速复习卡充当唯一覆盖；无重复主事实源、正文孤岛或胖卡；矩阵、索引和本记录一致。

## 反向检查与唯一主事实源

- [[企业信息化方法]] 只承接六种推进路径；[[企业信息化的概念]] 只承接企业信息化目标、推进方向和三个规划对象，[[企业应用集成EAI]] 只承接已有应用的协同，不复制六种方法。
- [[电子商务]] 独立承接市场交易主体、商务信息标准与三项代表定位；[[电子政务分类]] 仅以政府服务作最小分流，没有第二套电子商务标准正文。
- [[企业信息系统战略规划方法]] 独立承接 CSF/SST/BSP；[[企业信息化的概念]] 的“战略—业务运作—管理运作”是规划对象，不是方法，二者边界清楚。
- 从三张主事实源反查，实质段落均能映射至 A028～A030；没有正文孤岛、重复主事实源或为矩阵拼接的胖卡。
