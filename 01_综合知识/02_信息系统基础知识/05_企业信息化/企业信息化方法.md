# 📘 企业信息化方法（精简版）

## 一、五大方法速览

| 方法              | 一句话大白话         | 考场秒杀词          |
| --------------- | -------------- | -------------- |
| **BPR 业务流程重组**  | 推倒重来，流程再造      | 根本性重构、打破部门墙    |
| **ERP 企业资源计划 ** | 人财物产供销一套系统管    | 三流合一、财务业务一体化   |
| **SCM 供应链管理**   | 管好上下游供应链       | 供应商协同、牛鞭效应     |
| **CRM 客户关系管理**  | 用数据管好客户全生命周期   | 客户360°视图、销售自动化 |
| **EAI 企业应用集成**  | 把新老系统拉通，让它们能对话 | 异构系统互联、中间件、ESB |


## 二、逻辑关系

```
BPR（先理流程）→ ERP/SCM/CRM（核心应用）→ EAI（系统整合）
```

- **BPR 是前提**：流程不对，上系统就是“用电脑跑老路”
- **ERP/SCM/CRM 是三大支柱**：分别管内部、上游、客户
- **EAI 是粘合剂**：避免信息孤岛


## 三、考场陷阱

| 误区 | 正解 |
|------|------|
| 企业信息化 = 买软件 | ❌ 先BPR理流程，再选系统 |
| ERP = SCM | ❌ ERP管内部，SCM管上下游 |
| CRM = 客服软件 | ❌ CRM核心是**客户关系管理**（数据+策略） |


> **口诀**：**BPR理流程，ERP管内部，SCM控上游，CRM抓客户，EAI通系统。**

## 四、BPR vs BPM对比（高频易混淆）

**BPR**（业务流程重组）是企业信息化五大方法之一，是 **“前提”**——流程不对，上系统就是“用电脑跑老路”。**BPM**（业务流程管理）不属于五大方法，但它与BPR常放在一起考辨析，需要区分清楚。[^1]

### 核心区别

| 对比项  | BPR（业务流程重组）     | BPM（业务流程管理）      |
| :--- | :-------------- | :--------------- |
| 核心理念 | 推倒重来，根本性重构 [^1] | 持续优化，渐进式改进       |
| 变革程度 | 剧烈（质变）          | 温和（量变）           |
| 风险   | 高               | 低                |
| 周期   | 短而剧烈（一次性项目）     | 长而持续（常态化管理）      |
| 适用场景 | 流程严重落后、需要脱胎换骨   | 流程基本合理、只需微调      |
| 典型产出 | 全新流程图、组织架构调整    | 流程改进清单、KPI提升报告   |
| 考场秒杀 | “根本性”“推倒重来”“再造” | “持续改进”“PDCA”“精益” |

### 两者在企业信息化中的关系

- **先BPR后BPM**：流程太烂时先推倒重来，重建后再持续优化
- **只用BPM**：流程基本合理，只需微调
- **只用BPR不动BPM**：重建后没有持续改进机制，流程会再次变乱

### 考场关键词

- 出现 **“根本性”“推倒重来”“彻底重构”** → **BPR**
- 出现 **“持续改进”“渐进式”“PDCA”** → **BPM**

### 一个口诀

> **BPR 拆了重建，BPM 精装修。看到“根本性”选 BPR，看到“持续”选 BPM。**


### 四、CRM 和 SCM 必考场景详解

#### 1️⃣ CRM（客户关系管理）

**考试怎么考**：选择题给你一个场景，问用了哪种系统；或者问你CRM的核心目标是什么。

**核心功能**：

| 功能模块 | 说明 | 考场秒杀 |
|:---|:---|:---|
| **客户360°视图** | 把客户在所有渠道（电话、线上、门店）的交互记录汇总 | “全渠道客户数据整合” |
| **销售漏斗** | 跟踪潜在客户从“了解”到“成交”的全过程 | “线索→商机→合同” |
| **客户细分** | 按消费习惯、价值高低给客户分类 | “高价值客户”“客户分层” |
| **忠诚度管理** | 积分、会员、复购率分析 | “留存率”“复购率” |

**考场陷阱**：
- 题干说“接听客户投诉电话的系统”→ 那是**客服系统**，不是CRM（CRM比客服大得多，包含营销、销售、服务全流程）

**一个口诀**：
> CRM三件事：**管客户、看全貌、推策略**

---

#### 2️⃣ SCM（供应链管理）

**考试怎么考**：选择题考“牛鞭效应”的定义，或案例题考供应链优化手段。

**核心功能**：

| 功能模块 | 说明 | 考场秒杀 |
|:---|:---|:---|
| **供应商协同** | 与供应商共享库存和需求数据 | “VMI供应商管理库存” |
| **需求预测** | 用历史数据预测未来销量 | “产销协同” |
| **物流优化** | 规划最优配送路径和仓储布局 | “仓储选址”“路径规划” |
| **牛鞭效应** | 需求信息从下游往上传时逐级放大 | **（必考！）** |

**牛鞭效应详解（必考点）**：

| 维度 | 内容 |
|:---|:---|
| **定义** | 消费者真实需求的小波动，经过零售商→批发商→制造商逐级传递后，被层层放大，导致上游库存剧烈波动 |
| **产生原因** | 信息不对称、批量订货、价格波动、短缺博弈 |
| **消除手段** | 信息共享（SCM系统）、缩短订货周期、VMI（供应商管理库存） |
| **考场秒杀** | “需求放大”“库存波动”“啤酒游戏” |

**一个口诀**：
> SCM核心防御牛鞭，信息共享是解药

---

#### 3️⃣ ERP vs SCM vs CRM 对比（考场最爱混着考）

| 对比项 | ERP | SCM | CRM |
|:---|:---|:---|:---|
| **管什么** | 企业内部资源 | 上游供应商 | 下游客户 |
| **核心问题** | 人财物产供销怎么协同 | 货什么时候到、库存怎么压 | 客户怎么来、怎么留 |
| **典型功能** | 财务、生产、采购、库存 | 供应商协同、物流、需求预测 | 销售管理、客户服务、营销 |
| **考场秒杀** | “财务业务一体化” | “牛鞭效应”“供应商” | “客户360°”“销售漏斗” |
