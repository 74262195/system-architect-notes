# MIS（管理信息系统）

> **定位**：企业信息化的 **“中层”**，服务于部门经理。
> **层级**：管理层（中层管理者）

---

## 一、一句话定义

MIS 在 TPS 的基础上，对原始数据进行 **汇总、统计、制表**，生成各种 **定期报表**，供中层管理者使用。

> **大白话**：**“出统计报表的面包机”**。把“张三买了可乐、李四买了雪碧”变成“本月可乐销量100瓶，雪碧80瓶”。

---

## 二、核心特征

| 特征 | 大白话 |
| :--- | :--- |
| **数据来源** | 高度依赖 **TPS**（没有TPS，MIS就是无源之水） |
| **核心处理** | 汇总、分组、求平均、生成报表 |
| **解决的问题** | **结构化问题**（有固定公式，如“上个月工资总额”） |
| **输出形式** | **定期报表**（日/周/月/季报） |
| **追求目标** | **效率**（报表出得快、算得准） |

---

## 三、典型场景

| 场景 | 说明 |
| :--- | :--- |
| 月度销售统计 | “上个月销售额是多少？比上上个月增长了多少？” |
| 库存预警清单 | “当前有哪些物料低于安全库存？” |
| 员工考勤汇总 | “本月每人出勤天数、迟到次数” |
| 财务报表 | “本季度利润表、资产负债表” |

---

## 四、MIS vs DSS（必考！）

| 对比维度 | **MIS** | **DSS** |
| :--- | :--- | :--- |
| 处理的问题 | **结构化**（有标准答案） | **半结构化/非结构化**（无标准答案） |
| 追求目标 | **效率**（算得快） | **有效性**（决策正确） |
| 分析能力 | 事后统计——“上个月发生了什么” | 事前预测——“如果降价，会怎样” |
| 决策角色 | **替代**人力（机器出报表） | **支援**人（参谋，不拍板） |
