# 电子政务：群众少跑腿以后，政府系统到底改了什么

> [!summary] 快速复习卡片
> **定位**：利用信息技术整合政府管理与公共服务，让部门内部、部门之间以及政府与社会能够在线协同。
> **五类互动**：政府与政府、政府对企事业、政府对居民、企业对政府、居民对政府。
> **建设过程模式**：以用户为中心、引入客户关系管理思想、建设政府门户。
> **技术模式**：网络管理、信息资源管理、应用开发、安全体系、标准化。
> **易错点**：过程模式回答“服务和业务怎样组织”，技术模式回答“系统靠哪些技术管理方式支撑”。

过去群众办一件事，可能要先去 A 部门拿证明，再到 B 部门填表，再到 C 部门缴费。电子政务真正改变的，不是把三张纸扫描成三个网页，而是让信息、流程和服务能够跨部门衔接，尽量形成一个面向用户的办事入口和处理闭环。

## 五类互动怎样判断

| 互动 | 典型业务 |
| --- | --- |
| 政府与政府 | 部门间公文、信息共享、跨层级业务协同 |
| 政府对企事业 | 发布政策，颁发执照、许可证和认证 |
| 政府对居民 | 公共信息服务，户籍、证件和公共服务办理 |
| 企业对政府 | 纳税、报送统计信息、投标、提出建议或申请援助 |
| 居民对政府 | 缴费、提交信息、参政议政、报警和求助 |

网络资料常把这些方向压缩成 G2G、G2B、G2C、B2G、C2G。缩写可以帮助识别，但教材正文采用的是上述五类互动口径，作答时先看题干使用哪套表述。

## 四个发展阶段

1. 起步阶段：政府在网上发布静态信息。
2. 政府与用户单向互动：除发布信息外，开始提供单向服务。
3. 政府与用户双向互动：用户可以在线提交信息并收到反馈。
4. 网上事务处理：一项业务能够在线完成闭环处理。

复习重点是**互动程度逐步增加**，不需要背全部历史事件。

## 中国政府信息化的策略与历程怎么抓

教材大纲要求了解“中国政府信息化的策略和历程”，考试重点不是背政策年份，而是认出演进方向：

- 早期先做政府内部办公电子化和网络化；
- 随后建设跨部门的网络与共享信息资源，经典框架可用“**三网一库**”帮助识别：内部办公业务网、部门间办公业务资源网、面向社会的公众信息网，以及共建共享的信息资源库；
- 再向政府上网、信息公开、跨部门协同和网上办事发展；
- 最终关注点从“有没有网站”转向“能不能围绕用户把业务真正办完”。

因此看到“三网一库”时，第一反应应是我国政府信息化建设的经典框架，而不是电子商务网络分类。

## 建设过程模式：先改变服务组织方式

建设过程模式回答的是：**政府业务怎样围绕用户重新组织？**

1. **以用户为中心**：不是让群众理解每个部门内部怎么分工，而是从群众/企业要办成什么事出发组织服务。
2. **引入客户关系管理思想**：借鉴 CRM 对服务对象、需求和服务过程进行持续管理，但政府服务对象不是商业意义上的“客户买卖关系”。
3. **政府门户**：把分散部门的信息和服务组织到统一入口，降低用户寻找部门和系统的成本。

~~~mermaid
flowchart LR
    A[群众或企业要办一件事] --> B[统一门户进入]
    B --> C[围绕用户组织服务]
    C --> D[跨部门流程与信息协同]
    D --> E[在线完成或持续跟踪服务]
~~~

## 技术模式：再看系统靠什么支撑

| 技术模式 | 先记住什么 |
| --- | --- |
| 网络管理模式 | 组织政务内网、专网/业务网、外网等网络连接与隔离关系 |
| 信息资源管理模式 | 对分散政务数据和信息资源进行组织、共享和管理 |
| 应用开发模式 | 建设真正承载政务业务的应用，是从“有网络”走向“能办事”的关键环节 |
| 电子政务安全体系 | 从物理、网络、信息和管理等方面保障政务系统安全 |
| 电子政务标准化 | 用统一规范减少部门系统之间无法交换、无法协同的问题 |

### 过程模式和技术模式为什么容易混

- **过程模式**关注服务对象和办事流程：用户中心、CRM 思想、政府门户。
- **技术模式**关注基础支撑和系统治理：网络、信息资源、应用、安全、标准化。

题目如果问“政府门户”在建设思路中的位置，优先看过程模式；如果问“网络管理/信息资源/安全/标准化”，优先看技术模式。

## 三个组成部分

- 政府部门内部的电子化和网络化办公。
- 政府部门之间的信息共享和实时通信。
- 政府部门通过网络与居民进行双向信息交流。

## 考试怎么做

- **题干信号**：政府上网、三网一库、用户中心、政府门户、网络管理、信息资源管理、安全体系、标准化。
- **第一反应**：先分清题目在问互动主体、发展阶段、建设过程模式，还是技术模式，再归类选项。
- **排除动作**：出现 B2B/B2C 等市场交易主体时不要选电子政务；把“网络管理、信息资源、安全、标准化”说成过程模式也应排除。
