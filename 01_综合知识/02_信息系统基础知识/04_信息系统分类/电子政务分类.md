# 电子政务：先看谁和谁互动，再判断业务方向

> [!summary] 快速复习卡片
> **三个主体**：政府、企事业单位、居民。
> **五类互动**：政府与政府、政府对企事业、政府对居民、企业对政府、居民对政府。
> **题干怎么认**：政府采购服务看政府对企业；企业纳税和报表看企业对政府；居民办证看政府对居民。
> **易错点**：方向按谁发起、谁接受当前业务判断，不能只看场景里同时出现了哪些主体。

电子政务不是把政府网站做成信息公告栏，而是利用信息技术整合政府管理与服务职能，优化组织结构和工作流程，让政府内部以及政府与社会之间能够在线协同。

## 五类互动怎样判断

| 互动 | 典型业务 |
| --- | --- |
| 政府与政府 | 部门间公文、信息共享、跨层级业务协同 |
| 政府对企事业 | 发布政策，颁发执照、许可证和认证 |
| 政府对居民 | 公共信息服务，户籍、证件和公共服务办理 |
| 企业对政府 | 纳税、报送统计信息、投标、提出建议或申请援助 |
| 居民对政府 | 缴费、提交信息、参政议政、报警和求助 |

网络资料常把这些方向压缩成 G2G、G2B、G2C、B2G、C2G。缩写可以帮助识别，但教材正文采用的是上述五类互动口径，作答时先看题干使用哪套表述。

## 四个发展阶段

1. 起步阶段：政府在网上发布静态信息。
2. 政府与用户单向互动：除发布信息外，开始提供单向服务。
3. 政府与用户双向互动：用户可以在线提交信息并收到反馈。
4. 网上事务处理：一项业务能够在线完成闭环处理。

复习重点是**互动程度逐步增加**，不需要背教材中的全部应用领域清单。

## 三个组成部分

- 政府部门内部的电子化和网络化办公。
- 政府部门之间的信息共享和实时通信。
- 政府部门通过网络与居民进行双向信息交流。
