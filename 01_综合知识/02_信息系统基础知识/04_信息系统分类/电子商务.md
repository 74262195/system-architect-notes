# 电子商务（E-Commerce）

> [!important] 核心理解
> 用网络完成**商务活动**（交易、支付、物流、服务）。核心考点就一个：**按交易主体分模式**——B2B、B2C、C2C、O2O。跟 [[电子政务分类|电子政务]] 是"官方大纲双胞胎"，常放在一起考。

---

## 一、一句话定义

**电子商务** = 利用**电子手段（网络）**进行的**商务活动**，包括网上交易、在线支付、供应链协同、售后服务等。

> 大白话：**"把线下买卖搬到网上，从看货、下单、付款到收货全流程电子化。"**

---

## 二、四大交易模式（⭐必背）

| 模式 | 含义 | 典型例子 | 考场秒杀词 |
| :--- | :--- | :--- | :--- |
| **B2B** | **企业 → 企业** | 阿里巴巴（1688）、企业采购平台 | "企业间批发""供应链协同""采购平台" |
| **B2C** | **企业 → 消费者** | 京东自营、天猫旗舰店 | "网上商城""企业对个人" |
| **C2C** | **消费者 → 消费者** | 闲鱼、淘宝个人店 | "个人对个人""二手交易""跳蚤市场" |
| **O2O** | **线上 → 线下**融合 | 美团外卖、滴滴、到店团购 | "线上下单线下消费""到店/到家""本地生活" |

> **拓展记忆**（防止超纲干扰项）：
> - **B2G**：企业 → 政府（电子采购投标）——与电子政务联动
> - **C2B**：消费者 → 企业（定制化，如"反向团购"）
> - **C2G**：个人 → 政府（缴罚单等）

---

## 三、电子商务的四大支撑技术（多选题考点）

| 支撑 | 作用 | 大白话 |
| :--- | :--- | :--- |
| **电子支付** | 在线资金结算 | 支付宝、微信支付、网银 |
| **物流配送** | 实体商品送达 | 快递、同城配送、仓储系统 |
| **安全认证** | 身份与交易可信 | 数字证书（CA）、SSL/TLS、电子签名 |
| **数据共享/信息流** | 订单、库存、支付数据打通 | 前后台系统集成、供应链协同 |

---

## 四、电子商务 vs 电子政务（必考对比）

| 对比维度 | **电子商务** | **电子政务** |
| :--- | :--- | :--- |
| 主体 | **企业/个人**（商业主体） | **政府**（行政主体） |
| 目的 | 赚钱（商务交易） | 服务（政务便民） |
| 典型模式 | B2B / B2C / C2C / O2O | G2G / G2B / G2C / G2E |
| 考场陷阱 | "网上购物""在线支付" → 电子商务 | "网上办事""一网通办" → 电子政务 |

---

## 五、考场秒杀表

| 题干关键词 | 秒选 |
| :--- | :--- |
| "企业间大宗交易""采购平台" | **B2B** |
| "个人在商城购物" | **B2C** |
| "个人之间二手交易" | **C2C** |
| "线上下单、线下到店消费""本地生活" | **O2O** |
| "网上报税、在线办证" | **电子政务**（不是电子商务！） |
| "电子支付、数字证书、物流" | **电子商务支撑技术** |

---

## 六、一句话总结

> **B 是商家、C 是顾客，两个字母讲清谁卖给谁；O2O 把线上流量引到线下。** 看到"买卖"是电商，看到"办事"是政务。
