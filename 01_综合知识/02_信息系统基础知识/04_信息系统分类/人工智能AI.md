# 人工智能：为什么下一步会讲专家系统

> [!summary] 快速复习卡片
> **定位**：人工智能（AI）研究怎样让机器表现出一部分类似人类的智能行为。
> **智能行为题眼**：能从经验学习、信息不完整时求解、处理符号和图像、表现想象/创造、使用启发式方法。
> **主要分支**：专家系统、机器人技术、视觉系统、自然语言处理、学习系统、神经网络。
> **与 ES 的关系**：ES 不是 AI 的同义词，而是 AI 中经典的知识型分支。

一个系统只会按固定步骤做加减乘除，我们通常不会因为它“算得快”就说它有智能。AI 关注的是：机器能不能在复杂环境中表现出学习、理解、推理、识别和求解问题等智能行为。

## 什么叫“智能行为”

教材把 AI 的重点放在具有智能行为的计算机系统上。考试不需要讨论哲学上的“机器是否真的会思考”，先抓住这些可观察能力：

1. **从经验中学习并迁移**：过去遇到的情况能帮助处理新的场景。
2. **信息不完整时仍能求解**：不是所有条件都齐全才会工作。
3. **处理符号和图像**：不只做数值计算，也能操作符号、理解形象化信息。
4. **表现想象力和创造性**：能产生不只是机械重复的候选结果。
5. **善于启发**：面对搜索空间很大的问题，可以用经验性线索缩小求解范围。

这些是“智能行为的典型表现”，不是判断一个现代 AI 产品能力强弱的完整指标表。

## AI 有哪些主要分支

| 分支 | 先记住什么 |
| --- | --- |
| 专家系统 | 把领域专家知识放入知识库，再由推理机求解问题 |
| 机器人技术 | 让机器在物理环境中感知、规划和行动 |
| 视觉系统 | 从图像等视觉信息中识别和理解对象 |
| 自然语言处理 | 处理和理解人类语言 |
| 学习系统 | 从经验或数据中改进能力 |
| 神经网络 | 用网络化计算结构学习复杂模式 |

这些分支会互相组合，考试此处主要要求**识别分类和定位**，不需要在本章展开机器学习或神经网络算法。

## 为什么下一篇是专家系统

~~~mermaid
flowchart LR
    A[人工智能 AI] --> B[多种实现智能能力的方向]
    B --> C[专家系统 ES]
    B --> D[机器人技术]
    B --> E[视觉系统]
    B --> F[自然语言处理]
    B --> G[学习系统 / 神经网络]
    C --> H[知识库 + 推理机]
~~~

专家系统之所以放在这里，是因为它代表一种很经典的 AI 思路：**不要求程序员把所有问题都写成固定算法，而是把某个领域的专家知识保存下来，再利用推理机制求解问题。**

## 易混淆点

- **AI vs ES**：AI 是更大的上位领域；ES 只是其中一个分支。
- **ES vs 普通程序**：普通程序常把处理步骤直接写进算法；ES 更强调领域知识与推理控制分离。
- **AI vs DSS**：AI 是技术/研究领域概念；DSS 是面向管理决策支持的信息系统类型，二者不是同一级分类。

## 考试怎么做

- **题干信号**：模仿人类智能、从经验学习、信息不完整时求解、自然语言、视觉、专家系统。
- **第一反应**：先判断题目问的是 AI 上位概念/分支，还是某个具体信息系统；出现“ES 属于什么”时回答 AI 的重要分支。
- **排除动作**：不能把“专家系统”当成人工智能的全部，也不能因为系统使用数据库和模型就直接判成 AI。
