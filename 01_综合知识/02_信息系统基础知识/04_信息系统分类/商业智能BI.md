# 商业智能 BI：分散数据怎样变成经营洞察

> [!summary] 快速复习卡片
> **定位**：BI 把分散业务数据整合、分析并展示，帮助组织发现规律和支持经营决策。
> **处理链**：数据准备，数据仓库或分析存储，OLAP/数据挖掘，报表与可视化。
> **题干怎么认**：多源数据、数据仓库、联机分析处理、数据挖掘、经营分析。
> **易错点**：所谓“四层”是常见理解框架，不是所有 BI 系统都必须采用的唯一固定技术栈。

业务系统最适合保证每笔交易正确完成，却不适合直接回答“哪些客户正在流失、哪些商品组合更有利润”。BI 会先整理多源数据，再用分析工具从历史与当前数据中寻找趋势和模式。

| 环节 | 解决的问题 |
| --- | --- |
| 数据准备 | 从多个系统抽取、清洗并统一口径 |
| 分析存储 | 让面向分析的数据与日常交易处理适当分离 |
| 分析计算 | 用 OLAP、统计或数据挖掘比较维度、发现模式 |
| 信息呈现 | 通过报表、指标和可视化交给使用者 |

上表四步是本卡为零基础读者整理的学习框架，不表示主教材规定所有 BI 必须采用固定四层技术栈。主教材分别涉及 OLAP/数据挖掘、数据仓库与管理分析、商业智能结果可视化。

BI 是一组从数据到洞察的能力集合；DSS 更强调围绕具体决策问题，通过数据、模型和人机交互比较方案。现实中二者可以重叠。
