# OAS：办公自动化不只是把纸质文件搬到电脑里

> [!summary] 快速复习卡片
> **定位**：OAS 综合处理文字、数据、声音、图形和图像等办公信息，提高办公效率与质量。
> **三类功能**：事务处理、信息管理、辅助决策。
> **组成**：计算机设备、办公设备和软件系统。
> **题干怎么认**：公文、档案、日程、沟通、会议和办公信息的一体化处理。

办公室的工作不只有填表，还包括起草和审批文件、归档、沟通、开会与辅助决策。OAS 用信息技术把这些活动连接起来，重点是**办公信息的一体化处理**，不是单纯“无纸化”。

| 功能层次 | 解决的问题 |
| --- | --- |
| 事务处理 | 文字处理、日程、收发文等日常办公事务 |
| 信息管理 | 分类、存储、查询和共享办公信息 |
| 辅助决策 | 为主管人员提供分析、判断和决策支持 |

OAS 可以服务不同层级的办公人员，不能固定说成“只服务全体员工而没有管理层次”。现实中的协同办公平台也可能同时具有流程、知识管理和决策支持能力。
