# 诺兰模型：组织的信息化为什么会从扩张走向治理

> [!summary] 快速复习卡片
> **顺序**：初始、传播、控制、集成、数据管理、成熟。
> **主线**：少量试用，快速扩张，统一控制，系统集成，数据治理，战略成熟。
> **关键分界**：前三阶段偏计算机应用扩张，后三阶段偏信息资源管理。
> **易错点**：诺兰模型描述组织的信息化成熟过程，不是单个系统的生命周期。

组织刚开始使用计算机时，往往只解决少量局部问题。应用增多后，重复建设、数据不一致和信息孤岛随之出现，于是管理重点会从“多上系统”转向“统一治理和利用信息资源”。

**诺兰模型回答的是一个组织的信息化怎样成熟，不是在给单个系统划开发、运行或退役阶段。** 所以题干若讲的是企业内系统从分散扩张走向集成、数据治理和支撑决策，先按诺兰六阶段判断；若讲的是某个系统从提出到退出，转到 [[4大阶段]]。

| 阶段 | 主要状态 |
| --- | --- |
| 初始 | 少数人、少量应用，常从财务等部门开始 |
| 传播 | 应用和投入迅速增加，同时出现冗余、不一致和共享困难 |
| 控制 | 开始从整体上控制建设，建立组织协调和数据库管理 |
| 集成 | 重新规划并整合分散系统，建立共享基础 |
| 数据管理 | 统一数据平台和管理体系，把信息当作组织资源 |
| 成熟 | 信息技术与管理过程结合，支持各层业务、管理和决策 |

教材把信息资源规划视为由前三阶段进入后三阶段的重要转折。复习时理解这条变化即可，不需要背每一阶段的全部描述。
