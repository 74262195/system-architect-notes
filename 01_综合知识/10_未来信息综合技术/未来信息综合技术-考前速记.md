# 未来信息综合技术-考前速记

> [!tip] 使用方式
> 先闭卷说出“CPS → AI → 机器人 → 边缘 → 数字孪生 → 云与大数据”各自解决什么，再看下面的题干信号。想不起机制时点回对应 Atom，不在本页重新学一遍正文。

## 一眼看全章

1. **CPS**：让计算、通信、控制进入物理过程闭环。→ [[01_CPS是什么：为什么不是设备联网的别名]]
2. **AI**：提供学习、识别、推理、决策等智能能力。→ [[04_AI概念与发展：最低要识别什么]]
3. **机器人**：把感知和智能判断转成实体世界的规划、控制与执行。→ [[06_机器人闭环：智能如何变成现实动作]]
4. **边缘计算**：把对实时性、局部性敏感的处理放到数据源附近，并与云协同。→ [[08_边缘计算：为什么不能所有数据都送云端]]
5. **数字孪生**：让现实对象与数字对应体持续关联，用数据、模型和仿真帮助监测、预测与优化。→ [[10_数字孪生：为什么不是普通数字模型]]
6. **云计算 + 大数据**：前者提供按需资源/服务能力，后者解决复杂数据获取、治理、分析与价值提取。→ [[12_云计算：未来系统为什么需要弹性资源池]]、[[13_大数据：为什么需要与云协同支撑全局智能]]

## 题干信号 → 第一反应

| 题干信号 | 先想到 | 第一动作 |
|---|---|---|
| 感知现实、计算判断、控制设备、反馈回来 | CPS | 先找是否形成“感知→计算→控制→反馈”闭环 |
| 学习、识别、推理、知识处理、智能决策 | AI | 先判断题目要的是智能能力，不要直接等同机器人 |
| 传感、规划、控制、执行器、实体动作 | 机器人 | 看智能判断是否真正转成物理动作 |
| 低时延、海量现场数据、带宽压力、断网自治 | 边缘计算 | 先问哪些任务必须在数据源附近完成 |
| 现实对象对应数字体、持续同步、仿真预测、反馈优化 | 数字孪生 | 先找“现实 ↔ 数字”的持续数据关联 |
| 按需资源、弹性、资源池、服务化供给 | 云计算 | 先定位资源如何被组织和提供 |
| Volume / Velocity / Variety / Value、清洗、集成、分析 | 大数据 | 先定位问题落在数据特征还是处理链 |

## 五组必须切开的边界

| 易混 | 最小区分 |
|---|---|
| CPS vs IoT | IoT 更强调连接、感知、数据交换；CPS 更强调计算—通信—控制进入物理闭环 |
| AI vs 机器人 | AI 是智能能力；机器人还要在实体世界感知、规划、控制、执行 |
| 边缘 vs 云 | 边缘偏现场实时和局部自治，云偏全局资源；通常是协同，不是互相替代 |
| 普通数字模型 vs 数字孪生 | 只有模型不够；孪生强调与现实对象持续数据关联及分析/反馈价值 |
| 云计算 vs 大数据 | 云解决资源/服务供给，大数据解决复杂数据处理与价值提取 |

## 易错陷阱

- 有传感器、网络、设备联网，不自动等于 CPS；继续找控制现实对象的闭环。
- AI 软件有智能能力，不自动等于机器人；机器人还需要实体感知和执行。
- 边缘计算不是“不要云”，而是重新分配计算位置。
- 建了 3D/CAD 模型，不自动等于数字孪生；继续找持续虚实关联。
- 大数据不只是“文件很大”；还要结合速度、多样性和价值等特征判断。
- 云计算与大数据经常一起出现，但不是同义词。

5. 普通数字模型与数字孪生之间，最关键还差什么？
6. 云计算和大数据分别解决什么问题？
7. 大数据处理为什么通常不能跳过清洗和集成直接分析？
