# 信息安全技术 · 学习路线

> [!tip] 学习方法
> 不要把安全知识背成 26 个孤立名词。始终问三个问题：**保护什么、威胁是什么、靠什么机制保护。**

## 第 1 关 · 密码学：数据怎么保密、验真、验完整

1. [[对称加密]]：先理解“大量数据为什么用对称密钥”。
2. [[非对称加密]]：再解决密钥分发与公私钥方向。
3. [[哈希算法]]：理解摘要、完整性和口令存储。
4. [[数字签名]]：把哈希与公私钥连接起来。
5. [[数字证书与PKI]]：最后回答“公钥到底是不是他的”。

通关标准：能说清**保密、完整性、真实性、不可抵赖**分别依赖什么机制。

## 第 2 关 · 身份与权限：你是谁、你能做什么

认证线：[[身份认证]] → [[Kerberos认证]] → [[单点登录SSO]]

授权线：[[DAC自主访问控制]] → [[MAC强制访问控制]] → [[RBAC基于角色访问控制]]

通关标准：看到“属主、标签、角色、KDC、TGT、一次登录”能立即定位。

## 第 3 关 · 网络安全：流量从边界到通道怎么保护

1. [[防火墙]]：先学边界过滤。
2. [[IDS与IPS]]：再区分发现与阻断。
3. [[VPN]]：理解公网之上的安全隧道。
4. [[TLS与HTTPS]]：把证书、密钥协商、会话加密串起来。
5. [[无线网络安全]]：补齐无线接入。

通关标准：能画出“**边界过滤 → 检测阻断 → 安全通信 → 接入控制**”的网络防护链。

## 第 4 关 · 攻击与应用安全：先认攻击目标，再匹配防御

先读 [[常见网络攻击]] 建立攻击词典，再集中攻克：

- [[SQL注入]]：数据库/SQL 语义 → 参数化查询。
- [[XSS跨站脚本]]：浏览器脚本执行 → 输出编码/CSP。
- [[CSRF跨站请求伪造]]：借登录态发请求 → Token/SameSite。

通关标准：题干一出现“拖库、脚本、冒充登录用户”就能立即区分三者。

## 第 5 关 · 安全架构与治理：从单点技术走向系统方案

合规线：[[等级保护2.0]] → [[ISO27001信息安全管理]]

架构线：[[安全架构设计]] → [[纵深防御]] → [[零信任架构]] → [[可信计算]]

通关标准：案例题能按**威胁/风险 → 身份权限 → 网络 → 主机/应用 → 数据 → 监控审计 → 合规**分层回答，而不是只堆安全产品。
