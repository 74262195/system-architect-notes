# 常见网络攻击

> [!important] 软考定位
> ⭐⭐ 考"攻击原理+防御"配对，运维同学大多见过，主要是把术语对齐。


## 零基础先抓住

> [!question] 为什么要学这个
> 安全题经常先描述现象而不说攻击名字，必须先从机制判断攻击类型，再选防御。

> [!tip] 讲人话
> 像医生先看症状再诊断：流量耗尽、中间转发、重复请求、口令穷举，各有不同病因。

> [!important] 考试怎么认
> 先抓题眼：DDoS=资源耗尽，MITM=插入双方之间，重放=重复合法报文，暴力破解=穷举凭据。

---

## 一、攻击速查表（⭐）

| 攻击 | 原理 | 防御 |
| :--- | :--- | :--- |
| **DDoS** | 海量请求耗尽资源 | 流量清洗、CDN、限流、扩容 |
| **中间人（MITM）** | 冒充双方窃听/篡改 | TLS证书校验、双向认证 |
| **ARP欺骗** | 伪造 MAC 映射劫持流量 | 静态ARP、端口安全、DHCP Snooping |
| **端口扫描** | 探测开放端口找漏洞 | 防火墙最小暴露、隐藏端口 |
| **暴力破解** | 穷举口令 | 锁定、限速、强口令、MFA |
| **钓鱼** | 伪装身份诱导 | 安全意识培训、邮件网关 |
| **重放攻击** | 截获合法请求再次发送 | 时间戳、随机数nonce、序号 |
| **SYN Flood** | 半连接耗尽资源 | SYN Cookie、连接超时 |

---

## 二、重点深挖三个

### DDoS（分布式拒绝服务）
- 僵尸网络（Botnet）控制大量机器同时发起攻击
- 类型：流量型（带宽耗尽）、连接型（连接耗尽）、应用型（资源耗尽）
- 防御思路：**检测 + 清洗 + 扩容 + 降级**

### 中间人 MITM
- 攻击者插入通信双方之间，转发并篡改
- 防御核心：**TLS + 证书校验**（让伪造无处遁形）

### ARP 欺骗
- 局域网内伪造"IP→MAC"映射，让流量发往攻击者
- 防御：静态 ARP 表、交换机端口安全

---

## 三、考场避坑

1. "重放"的特征词：**时间戳/nonce** 防御
2. DDoS 是"资源耗尽"，不是"数据泄露"
3. 防御中间人 = 证书验证（没有证书验证的"裸加密"照样被中间人）

---

## 四、一句话总结

> **DDoS耗资源、MITM搞转发、ARP骗路由——防攻击先认原理，再配对策。**
