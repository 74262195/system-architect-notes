# 信息安全技术知识库

> [!summary] 先抓住两条线
> **问题线：资产 → 威胁 → 脆弱性 → 攻击 → 风险 → 安全目标 → 安全机制 → 剩余风险。**
>
> **技术线：保护数据 → 管住身份与权限 → 保护通信路径 → 防应用攻击 → 用架构与治理持续控制风险。**

## 零基础从哪里开始

第一次进入这一章，先读 [[00_信息安全技术开篇：系统建好了，为什么还不够]]。它会从你已经学过的“系统怎样提供业务”继续往下讲：为什么**能运行不等于能安全运行**，以及资产、威胁、脆弱性、攻击、风险、目标和控制之间为什么会一环接一环。

然后按下面顺序走，不要一上来背 AES、RSA、防火墙等名词：

1. [[信息安全基本目标]]：先定义“什么叫安全”；
2. [[信息安全范围与存储安全]]：把安全目标落到设备、数据、内容和行为等保护对象；
3. [[安全风险评估]]：把资产、威胁、脆弱性、可能性和影响连成可排序的风险；
4. [[学习路线]]：再进入密码学、身份权限、网络通信、应用攻击和安全架构五站。

[[信息系统安全为什么需要治理]] 不再挡在风险评估之前。等你已经理解“风险 + 技术控制”以后，再在第 5 站用它回答：**为什么一堆安全技术仍然不等于完整安全体系。**

## 这些技术各自处在什么位置

安全技术不是一套互相替代的“产品清单”。它们接住的是不同风险，并要一起组成保护链：

| 先问什么 | 主要技术线 | 它主要交付什么 | 它单独不保证什么 |
| --- | --- | --- | --- |
| 数据会不会被偷看或被改？ | [[对称加密]]、[[非对称加密]]、[[哈希算法]]、[[数字签名]]、[[数字证书与PKI]] | 保密、完整性、来源可信与密钥信任 | 不自动决定一个用户有没有操作权限 |
| 来的人是谁，他能做什么？ | [[身份认证]]、[[访问控制基础]]、DAC/MAC/RBAC | 身份确认与授权限制 | 不自动让传输内容保密 |
| 网络和应用会不会遭到攻击？ | [[防火墙]]、[[IDS与IPS]]、[[VPN]]、[[TLS与HTTPS]]、[[常见网络攻击]] | 边界控制、检测阻断、安全通信与漏洞防护 | 不自动替代账号权限和整体风险治理 |
| 这些控制是否覆盖风险、能否持续运行？ | [[安全风险评估]]、[[安全架构设计]]、[[纵深防御]]、[[ISO27001信息安全管理]] | 选择、组织、审计和持续改进控制措施 | 不替代某个具体加密或认证机制 |

阅读每篇技术笔记时都先问：**它在保护链中接住了哪一种风险，又把什么问题留给下一种技术？**

## 01 · 密码学与 PKI

[[对称加密]] → [[非对称加密]] → [[哈希算法]] → [[数字签名]] → [[数字证书与PKI]] → [[密钥管理]]

- 对称加密：高效保护大量数据，但共享密钥必须安全管理。
- 非对称加密：用公私钥解决特定的保密、签名和密钥协商问题。
- 哈希与签名：前者生成摘要，后者证明来源并发现篡改。
- 证书与密钥管理：回答“公钥是否可信”和“密钥怎样贯穿生命周期”。

## 02 · 身份认证与访问控制

[[身份认证]] → [[访问控制基础]] → [[DAC自主访问控制]] / [[MAC强制访问控制]] / [[RBAC基于角色访问控制]]

协议例子：[[Kerberos认证]]。工程扩展：[[单点登录SSO]]。

先分清两问：**认证回答“你是谁”，访问控制回答“这次操作能不能做”。**

## 03 · 网络与通信安全

[[网络安全-从漏洞威胁到安全措施]] → [[防火墙]] → [[IDS与IPS]] → [[VPN]] → [[TLS与HTTPS]] → [[无线网络安全]]

这些机制分别负责策略控制、检测/阻断、安全隧道、应用通信保护和无线接入，不能互相替代。

## 04 · 应用安全与攻击防护

先用 [[常见网络攻击]] 学会“看现象认机制”，再用 [[网络欺骗-ARP、DNS与IP欺骗]] 区分三种被伪造的网络信息、用 [[端口扫描-怎样用响应判断服务暴露]] 识别攻击者怎样收集入口信息、用 [[TCPIP协议攻击-SYN、ICMP与SNMP]] 区分三类协议攻击，最后区分三类 Web 问题：

| 考点 | 攻击落点 | 第一防线 |
| --- | --- | --- |
| [[SQL注入]] | 输入改变 SQL 结构 | 参数化查询 |
| [[XSS跨站脚本]] | 不可信内容进入浏览器执行上下文 | 按上下文输出编码 / 安全 DOM API |
| [[CSRF跨站请求伪造]] | 借浏览器已有身份提交请求 | 抗 CSRF Token / SameSite / 来源校验 |

## 05 · 安全架构治理与可信

基础：[[信息安全基本目标]] → [[安全风险评估]] → [[安全模型]] → [[OSI安全体系结构]]

设计：[[安全架构设计]] → [[纵深防御]] → [[数据库安全与完整性设计]] → [[软件脆弱性分析]]

治理与扩展：[[信息系统安全为什么需要治理]]、[[等级保护2.0]]、[[ISO27001信息安全管理]]、[[可信计算]]、[[零信任架构]]

这里的主问题是：怎样把零散控制组织为覆盖预防、检测、响应和恢复的整体方案。

## 复习减负

- **P1 重点**：基本目标、密码学主链、身份与访问控制基础、防火墙、VPN、HTTPS、常见攻击、安全架构与 OSI 体系结构。
- **P2 补齐边界**：访问控制模型、IDS/IPS、无线安全、Web 漏洞、安全模型、风险评估、数据库安全、软件脆弱性、纵深防御、可信计算、等保。
- **P3 拓展认识**：SSO、零信任、ISO/IEC 27001。先掌握它们解决什么问题，不必在第一遍记工程细节。
