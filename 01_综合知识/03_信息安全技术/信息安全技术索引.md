## 01 · 密码学与 PKI

[[对称加密]] → [[非对称加密]] → [[哈希算法]] → [[数字签名]] → [[数字证书与PKI]]

重点关系：对称加密适合大量数据；公钥密码解决密钥与身份问题；哈希提供摘要；数字签名验证签名者和完整性；PKI 解决公钥与身份的可信绑定。

## 02 · 身份认证与访问控制

认证主线：[[身份认证]] → [[Kerberos认证]] → [[单点登录SSO]]

授权主线：[[DAC自主访问控制]] → [[MAC强制访问控制]] → [[RBAC基于角色访问控制]]

题目先分清：**认证回答“你是谁”，授权回答“你能做什么”。**

## 03 · 网络与通信安全

[[防火墙]] → [[IDS与IPS]] → [[VPN]] → [[TLS与HTTPS]] → [[无线网络安全]]

重点关系：策略控制、攻击检测/阻断、安全隧道、传输保护、无线接入分别解决不同层次的问题，不要把任一设备写成“单独解决全部安全”。

## 04 · 应用安全与攻击防护

[[常见网络攻击]] → [[SQL注入]] → [[XSS跨站脚本]] → [[CSRF跨站请求伪造]]

| 攻击 | 本质 | 主防线 |
| --- | --- | --- |
| SQL 注入 | 数据被解释为 SQL 结构 | 参数化查询 |
| XSS | 不可信内容进入浏览器可执行上下文 | 上下文输出编码/安全 DOM API |
| CSRF | 借浏览器已有身份提交请求 | Token + SameSite + 来源校验 |
