## 01 · 密码学与 PKI

[[对称加密]] → [[非对称加密]] → [[哈希算法]] → [[数字签名]] → [[数字证书与PKI]]

重点关系：**对称负责高效保密；非对称解决密钥交换/身份问题；哈希负责摘要；签名负责验真与防抵赖；PKI 解决公钥可信来源。**

## 02 · 身份认证与访问控制

认证主线：[[身份认证]] → [[Kerberos认证]] → [[单点登录SSO]]

授权主线：[[DAC自主访问控制]] → [[MAC强制访问控制]] → [[RBAC基于角色访问控制]]

重点关系：**认证回答“你是谁”，授权回答“你能做什么”。**

## 03 · 网络与通信安全

[[防火墙]] → [[IDS与IPS]] → [[VPN]] → [[TLS与HTTPS]] → [[无线网络安全]]

重点关系：边界过滤、异常检测/阻断、安全隧道、传输保护、无线接入形成网络侧防线。

## 04 · 应用安全与攻击防护

[[常见网络攻击]]

Web 三兄弟：[[SQL注入]] → [[XSS跨站脚本]] → [[CSRF跨站请求伪造]]

| 攻击 | 主要目标/本质 | 核心防御 |
| --- | --- | --- |
| SQL 注入 | 输入被当成 SQL 代码执行 | 参数化查询 |
| XSS | 恶意脚本进入用户浏览器执行 | 上下文相关输出编码 + CSP |
| CSRF | 借已登录用户身份发起请求 | CSRF Token + SameSite |
