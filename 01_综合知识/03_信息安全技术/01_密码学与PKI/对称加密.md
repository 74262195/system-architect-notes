# 对称加密：同一共享密钥怎样高效保护大量数据

> [!summary]- 快速复习卡片（学完再看）
> **作用/定位**：用共享密钥高效保护大量数据。
> **核心结论**：速度快，但通信双方必须安全共享并管理密钥；现代使用还应考虑完整性认证。
> **经典题型怎么做**：先看算法名与用途：AES/DES → 对称；N 个用户两两独立配钥 → 数用户对。
> **易错点**：加密模式决定分组怎样处理；ECB 会泄露重复模式，Nonce/IV 要满足具体模式要求。

## 先从信息安全的总问题出发

信息安全不是“装上一种加密算法”就结束了。系统需要分别防住：信息被不该看的人看到、内容被偷偷改掉、身份被冒用、合法用户需要时无法使用等风险。[[信息安全基本目标]] 用机密性、完整性、可用性等目标把这些问题分开。

**对称加密只重点解决其中一个问题：让传输或存储的数据不被旁观者读懂，也就是保护机密性。** 它不自动证明“消息是谁发的”，也不自动保证内容没有被篡改；这些问题会在 [[哈希算法]]、[[数字签名]] 等后续笔记中分别处理。

| 定位 | 对称加密在这里的答案 |
| --- | --- |
| 要防的风险 | 数据在传输或存储中被未授权者看到 |
| 主要交付 | 机密性：没有共享密钥的人不能读懂密文 |
| 为什么先学它 | 它高效，适合持续保护大量业务数据 |
| 依赖/边界 | 双方必须先安全获得并管理同一把密钥；它不单独提供身份认证、完整性或可用性 |
| 在主线中的位置 | 它负责“把数据藏起来”；下一步的非对称加密回答“双方怎样更方便地建立密钥关系” |

## 当别人能看见传输内容时，怎样高效保密

设员工 A 要把一份工资表发送给公司服务器 B。若直接发送明文，途中能够截获数据的人也可能读到工资表。对称加密的做法是让 A 和 B 预先持有同一把共享密钥：A 用它把工资表变成密文，B 用同一把密钥还原明文。

**对称加密**使用同一把共享密钥，或可由一把密钥直接推导的密钥，完成加密和解密。它适合保护大量数据；难点是密钥生成、分发、轮换和泄露后的影响控制。

## 完整工作过程

~~~mermaid
flowchart LR
    A[准备共享密钥与必要参数] --> B[按算法和模式加密]
    B --> C[发送密文及公开参数]
    C --> D[接收方验证并解密]
    D --> E[得到明文]
~~~

现代应用通常采用带认证的加密模式，同时提供机密性和完整性。密钥必须保密；IV/Nonce 通常不必保密，但必须满足所用模式规定的唯一性或随机性要求。

## 算法与模式分开记

| 类别 | 代表 | 考试结论 |
| --- | --- | --- |
| 分组算法 | DES、3DES、AES、IDEA | DES 密钥过短；AES 是现代常用标准 |
| 流密码 | RC4 等 | RC4 已不推荐 |
| 工作模式 | ECB、CBC、CTR、GCM 等 | 模式决定怎样处理多个分组及是否带认证 |

| 模式 | 关键特点 | 主要风险/要求 |
| --- | --- | --- |
| ECB | 各块独立，可并行 | 相同明文块产生相同密文块，泄露模式 |
| CBC | 当前明文块与前一密文块关联 | 需要不可预测 IV；单独加密不自动提供完整性 |
| CTR | 用计数器生成密钥流，可并行 | 同一密钥下 Nonce/计数器不可复用 |
| GCM | 计数器加密 + 认证标签 | 同时保护机密性与完整性；Nonce 不可重复 |

CFB/OFB 在部分教材中作为反馈模式出现；做题按教材给出的模式特征判断。

## 密钥规模问题

若 $N$ 个用户两两独立共享密钥，理论上需要：

$$
\frac{N(N-1)}{2}
$$

把不同的两两关系分别配钥。因此系统规模越大，密钥管理越困难。实际系统常用密钥分发中心，或利用公钥机制协商临时对称会话密钥。

## 考试怎么认

- 大量数据、高性能、共享密钥、AES → 对称加密。
- 同一明文块暴露相同模式 → ECB。
- 对称加密不天然解决大规模密钥分发，也不等于自动具有完整性保护。

> [!question] 自测
> 1. 为什么“共享密钥、传输大量数据”通常首先想到对称加密？
>
> > [!answer]- 第 1 题答案与解析
> > **答案**：因为通信双方使用同一把共享密钥完成加解密，对称加密适合高效处理大量数据。
> > **解析**：题干若强调“先安全分发同一把密钥”，也同时提示了它的主要难点是密钥管理。
>
> 2. 有 4 个用户，两两独立共享密钥，需要多少把密钥？
>
> > [!answer]- 第 2 题答案与解析
> > **答案**：6 把。
> > **解析**：不同用户对的数量是 $N(N-1)/2$，代入 $N=4$ 得 $4×3/2=6$。
>
> 3. 为什么 ECB 模式容易泄露信息？
>
> > [!answer]- 第 3 题答案与解析
> > **答案**：相同的明文分组会产生相同的密文分组。
> > **解析**：攻击者即使看不懂明文，也可能从密文中的重复模式推断结构。
