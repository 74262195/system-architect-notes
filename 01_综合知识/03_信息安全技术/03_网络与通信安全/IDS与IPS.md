# IDS 与 IPS

> [!important] 软考定位
> ⭐ 经典对比题：**旁路 vs 串联、检测 vs 阻断**，两个词记住就拿分。


## 零基础先抓住

> [!question] 为什么要学这个
> 光靠静态规则拦截不够，还需要发现异常行为；有些场景还要实时阻断。

> [!tip] 讲人话
> IDS 像摄像头和报警器，IPS 像站在通道上的保安，发现问题还能当场拦下。

> [!important] 考试怎么认
> “旁路/告警”对应 IDS，“串联/阻断”对应 IPS。

---

## 一、一句话定义

- **IDS（入侵检测系统）**：**旁路**观察流量，发现攻击**只告警**，不拦
- **IPS（入侵防御系统）**：**串联**在线，发现攻击**直接阻断**

---

## 二、对比表（⭐）

| | IDS | IPS |
| :--- | :--- | :--- |
| 部署 | **旁路**（镜像端口） | **串联**（在线） |
| 行为 | 检测 + 告警 | 检测 + **阻断** |
| 影响业务 | 不影响 | 可能误伤业务 |
| 定位 | 事后发现 | 实时防御 |

> 🧠 **记忆**：IDS=摄像头（只拍）；IPS=保安（当场制止）。

---

## 三、与防火墙的关系（⭐）

| 设备 | 角色 |
| :--- | :--- |
| [[防火墙]] | 门卫，按规则**拦已知** |
| IDS | 摄像头，**发现异常** |
| IPS | 保安，**发现并制止** |

- 三者常组合成**纵深防御**（见 [[纵深防御]]）

---

## 四、考场避坑

1. "旁路/只检测/告警"→ IDS；"串联/阻断/在线"→ IPS
2. IDS 不影响业务、IPS 可能影响业务（这是选型权衡点）
3. 填空题：IPS 是 IDS 的"加装制动器"

---

## 五、一句话总结

> **IDS 看不说，IPS 看就说、说就做。**
