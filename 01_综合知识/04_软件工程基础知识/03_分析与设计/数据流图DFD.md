# 数据流图DFD

> [!summary] 快速复习卡片
> - **核心结论**：DFD 用外部项、加工、数据流和存储描述数据怎样变换；分解前后边界输入输出保持一致。
> - **做题入口**：先定边界，再查每条数据流至少一端是加工，最后检查父子图平衡。

**DFD（数据流图）**是需求分析中的功能模型。它回答数据从哪里来、经历什么处理、保存或送到哪里，不描述 CPU 按什么先后执行语句。

| 元素 | 告警系统中的例子 |
| --- | --- |
| 外部项 | 提交告警的设备、接收结果的值班人员 |
| 加工 | 校验告警、分级处理、生成通知 |
| 数据流 | 原始告警、分级结果、通知内容 |
| 数据存储 | 告警记录库 |

建模先把整个系统作为一个加工，明确输入输出；再按功能分解，直至每个加工容易说明。分解不能偷偷新增对外输入或丢失输出，这就是父子图平衡。

教学检查：若“设备”直接连“告警记录库”，按教材建模规则，中间缺少处理；若“生成通知”完全没有输入，也无法说明通知内容来自哪里。除了有无箭头，还要检查输入信息是否足以产生输出。

数据流名称说明传递的数据，不用“执行下一步”这类控制含义。图形符号有不同记法，应按题目图例识别。本卡用元素映射表解释规则，不冒充教材原图。

## 自测

> [!question]- 将一个加工拆成三个后，可以删去原来的对外输出吗？
> 不能无依据删去，子图需要保持父图的边界输入输出语义。
