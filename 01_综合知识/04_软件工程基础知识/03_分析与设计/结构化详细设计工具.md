# 结构化详细设计工具

> [!summary] 快速复习卡片
> - **核心结论**：详细设计说明模块内部算法；流程图、NS、PAD、判定表和 PDL 是不同表达工具。
> - **做题入口**：模块调用层次看 SC；模块内部控制过程看详细设计工具；数据流向看 DFD。

概要设计确定模块和接口后，开发者仍要知道每个模块内部怎样运行。**详细设计工具**用图、表或语言表达这些逻辑。

| 工具 | 主要特点 |
| --- | --- |
| 程序流程图 | 用处理、判断和控制流描述执行过程 |
| NS 图 | 盒状嵌套，结构化表达，不能任意跳转 |
| PAD 图 | 表达逐步细化的结构，可描述逻辑及数据结构 |
| 判定表 | 列条件组合及对应动作 |
| PDL | 用结构化伪码表达具体操作和控制 |

例如告警级别与是否已确认共同决定是否通知，判定表易于检查组合是否遗漏；处理循环则可用结构化伪码。

教材的 PDL 外层控制语法较确定，内层具体操作可按业务灵活描述。它不是必须编译运行的程序语言。结构化程序主要用顺序、选择和循环组合，强调自顶向下、逐步求精和清晰表达。

## 自测

> [!question]- 选择判定表最主要是为了展示什么？
> 条件组合与动作的对应关系，便于发现遗漏和冲突。
