# 可靠性与可用性：少出故障与快速恢复不是一回事

> [!summary] 快速复习卡片
> **作用/定位**：可靠性看“多久不出故障”，可用性看“需要服务时有多大概率能用”。
> **核心结论**：对可修复系统的经典稳态模型，可用度同时受 MTBF 和 MTTR 影响。
> **经典题型怎么做**：看到 MTBF/MTTR 先判断是否求可用度；提高 MTBF 或降低 MTTR 都会提高可用度。
> **易错点**：双机热备是提高可用性的手段，不是可靠性定义；可靠性高也不等于恢复一定快。

## 两个指标观察不同问题

- **可靠性**：系统在规定条件和规定时间内持续完成规定功能的能力。
- **可用性**：需要使用时系统处于可服务状态的程度。

同一系统可能故障很少但每次恢复很久，也可能偶尔故障却能很快切换恢复，所以两者不能互相替代。

## 经典可用度公式

对可修复系统的稳态近似：

\[
A=\frac{MTBF}{MTBF+MTTR}
\]

若 MTBF=1000 小时、MTTR=1 小时，则可用度约为 99.9001%。

## 故障发生后的服务链

```mermaid
flowchart LR
    A[故障发生] --> B[检测与定位]
    B --> C[隔离故障]
    C --> D[切换/冗余/降级]
    D --> E[修复并恢复]
```

## 历年考法落点

这类题最常把定义和公式混在一起：

- “规定时间内不发生故障” → 可靠性；
- “正常服务时间比例、MTBF/MTTR、快速恢复” → 可用性；
- “容错/冗余” → 提升可靠或可用目标的手段，要看题干最终度量什么。

## 自测
1. MTBF 不变、MTTR 下降，可用度怎么变？
2. 为什么“可靠性高”不能直接推出“可用性一定高”？
3. 双机热备属于指标还是实现策略？
