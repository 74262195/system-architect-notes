# 计算机网络 · 复习总纲

> [!tip] 10～15 分钟用法
> 从“分层 → 局域网 → IP → TCP/UDP → 应用 → 无线 → 组网与指标”闭卷复述；计算题只在本页确认公式，步骤回原子卡。

## 30 秒主线

[[网络协议与OSI七层|分层]]让通信各司其职，[[数据通信与交换技术|链路]]负责运送比特和分组；[[以太网技术|以太网]]、[[交换机]]解决局域网转发，[[IP编址与子网划分|IP]]负责跨网寻址，[[TCP与UDP协议|TCP/UDP]]把数据送到具体进程，[[应用层常用协议|应用协议]]提供网页、域名、邮件等服务；[[无线局域网802.11|Wi-Fi]]与 [[5G]]扩展接入方式，最后用 [[网络性能指标|时延吞吐]]和 [[非性能性指标|可用性]]评价网络。

## 分层、设备与协议：题眼速配

| 题干关键词 | 层次或对象 | 快速判断 |
| --- | --- | --- |
| 信号、比特 | 物理层 | 中继器只放大或再生信号 |
| 帧、MAC、FCS | 数据链路层 | 交换机按 MAC 表转发 |
| IP、路由、分片 | 网络层 | 路由器分隔广播域 |
| 端口、可靠传输、窗口 | 传输层 | TCP/UDP 把数据交给进程 |
| DNS、HTTP、SMTP | 应用层 | 按业务功能认协议 |
| 冲突域 | 交换机 | 每个交换端口形成独立冲突域 |
| 广播域 | VLAN/路由器 | 普通二层交换默认不隔离广播域 |
| 协议转换 | 网关 | 不只是转发地址，还理解并转换协议 |

OSI 顺序口诀：**物、链、网、传、会、表、应**。发送端逐层封装，接收端逐层解封装；MAC 面向当前链路一跳，IP 面向端到端逻辑寻址。

## 局域网、IP 与传输层

| 对比 | 核心区分 | 高频陷阱 |
| --- | --- | --- |
| 电路 / 报文 / 分组交换 | 独占通路 / 整报文存储转发 / 分组共享链路 | 分组交换不是没有存储转发 |
| CSMA/CD / CSMA/CA | 有线共享介质检测碰撞 / 无线尽量避免碰撞 | 现代交换式全双工以太网通常不再执行 CD |
| 交换机 / 路由器 / 网关 | 看 MAC / 看 IP / 转换协议 | 交换机默认不能隔离广播域 |
| CIDR / VLSM | 无类别聚合与表示 / 按需求使用不同前缀长度 | 都使用前缀长度，但目的侧重不同 |
| TCP / UDP | 可靠字节流 / 尽力数据报 | TCP 不保留应用消息边界，UDP 保留 |

TCP 三次握手：`SYN` → `SYN+ACK` → `ACK`；四次挥手：`FIN` → `ACK` → `FIN` → `ACK`。四次的根源是全双工连接的两个方向要分别关闭。

应用协议按功能记：DNS 解析名称，DHCP 分配网络配置，HTTP/HTTPS 访问 Web，FTP 传文件，SMTP 发邮件，POP3/IMAP 收邮件，SSH 加密远程登录，ping 常用 ICMP。

## 必背计算

### 子网划分

**算什么**：根据借位数量求子网数，根据剩余主机位求每个子网可容纳的传统可用主机数。

- $k$：从原主机部分借出的子网位数；
- $h$：划分后剩余的主机位数；
- $H$：传统题型中的可用主机地址数。

借 $k$ 位作为子网位：

$$子网数=2^k$$

中文读法：**每个子网位有两种状态，$k$ 位可以组合出 $2$ 的 $k$ 次方个子网。**

主机部分有 $h$ 位时，传统考试口径的可用主机数：

$$H=2^h-2$$

中文读法：**$h$ 个主机位共有 $2^h$ 个地址，传统题型再减去网络地址和广播地址。**网络地址由 IP 地址与子网掩码逐位与得到。计算前先确定前缀长度、块大小、网络地址和广播地址。

### 发送与传播时延

**算什么**：区分“把全部数据推上链路要多久”和“信号在介质中走完距离要多久”。

- $L$：待发送数据量，单位是 bit；
- $R$：链路速率，单位是 bit/s；
- $d$：传播距离，单位通常是 m；
- $v$：信号在介质中的传播速度，单位是 m/s；
- $t_{tx}$：发送时延；
- $t_{prop}$：传播时延。

数据量为 $L$ bit、带宽为 $R$ bit/s：

$$t_{tx}=\frac{L}{R}$$

中文读法：**发送时延等于数据量除以链路速率。**

距离为 $d$、信号传播速度为 $v$：

$$t_{prop}=\frac{d}{v}$$

中文读法：**传播时延等于传播距离除以信号速度。**

$$t_{总}=t_{tx}+t_{prop}+t_{处理}+t_{排队}$$

中文读法：**一次网络传输的总时延，由发送、传播、设备处理和排队等待四部分相加。**发送时延看“数据有多少、链路多宽”，传播时延看“路有多远、信号多快”。

### IPv4 分片

**算什么**：求每个 IPv4 分片最多能装多少数据，以及分片头中的片偏移。

- MTU：链路允许通过的最大 IP 数据报长度，单位是 Byte；
- IP 首部长度：每个分片都要携带的首部大小，单位是 Byte；
- 片偏移：本片数据在原始数据中的起点，以 $8$ Byte 为一个单位。

$$每片可装数据=MTU-IP首部长度$$

中文读法：**链路能承载的总长度，减去每片自己的 IP 首部，就是可装的数据长度。**

除最后一片外，数据长度要取不超过上式的最大 $8$ 字节整数倍；片偏移以 $8$ 字节为单位。具体步骤见 [[IPv4报文与分片]]。

### 可用性

**算什么**：计算系统在长期运行中处于可用状态的时间比例。

- $A$：可用性，常写成百分比；
- MTBF：平均故障间隔时间，中文可记为“平均正常运行多久才坏”；
- MTTR：平均修复时间，中文可记为“坏了平均多久修好”；
- MTBF 与 MTTR 必须使用相同时间单位。

$$A=\frac{MTBF}{MTBF+MTTR}$$

中文读法：**可用性等于平均正常运行时间，除以平均正常运行时间与平均修复时间之和。**

可靠性强调少故障，可维护性强调好修复，可用性综合故障间隔与修复时间。

## 无线、5G 与网络工程

- Wi-Fi 使用 CSMA/CA 与 ACK；隐藏终端场景可借助 RTS/CTS，不能把有线的碰撞检测原样搬到无线。
- Wi-Fi 4/5/6 常对应 802.11n/ac/ax。
- 5G 三大场景：eMBB 是“快”，uRLLC 是“准”，mMTC 是“多”。
- [[5G网络切片|网络切片]]是在共享物理基础设施上提供逻辑隔离、按需编排的网络，不等于每类业务各铺一张物理专网。
- 拓扑识别：总线成本低但主干关键，星型易管理但中心关键，环型按环路传递，树型便于分层，网状冗余高但成本高。
- 典型层次组网是接入、汇聚、核心；小规模网络可以合并层次，不能机械要求三层齐全。

## 最容易丢分的地方

- Ethernet FCS 用 CRC 做检错，不负责端到端可靠重传。
- IP 提供尽力交付；“可靠、有序、流量控制、拥塞控制”落到 TCP。
- 子网主机数的 $-2$ 是传统题型口径，解题要以题目对特殊地址的约定为准。
- IPv4 片偏移不是字节数，而是以 $8$ 字节为单位的数值。
- 带宽是理论能力，吞吐量是实际完成量；bit 与 Byte 相差 $8$ 倍。
- SMTP 用于发送，POP3/IMAP 用于接收；Telnet 明文，SSH 加密。
- 可用性高既可以来自 MTBF 变长，也可以来自 MTTR 变短。
