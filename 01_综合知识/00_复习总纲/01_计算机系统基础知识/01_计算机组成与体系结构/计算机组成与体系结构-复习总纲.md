## 必背公式：先认适用条件

### 数值与地址

**算什么**：把最高位为 $1$ 的补码还原成负数真值。

- $n$：补码总位数，单位是位；
- $U$：把整个补码直接当成无符号二进制数时得到的十进制数；
- $x$：补码实际表示的有符号真值。

$$x=U-2^n$$

中文读法：**真值等于无符号值，减去 $2$ 的总位数次方。**

**算什么**：根据地址线数量计算能区分多少个地址单元。

- $N$：地址线数量，单位是根；
- $2^N$：可产生的不同二进制地址数量，也就是地址单元数。

$$2^N$$

中文读法：**每根地址线有 $0$、$1$ 两种状态，$N$ 根地址线共有 $2$ 的 $N$ 次方种组合。**题目问容量时，还要乘“每个地址单元包含多少位或多少字节”。

### 流水线

**算什么**：计算多条指令进入流水线后的总执行时间、加速比和吞吐率。

- $k$：流水线段数；
- $n$：连续处理的指令或任务数量；
- $t_i$：第 $i$ 段的执行时间，常用单位是 ns、$\mu$s 或 ms；
- $\Delta t$：流水线时钟周期，由最慢的一段决定；
- $T$：流水线执行总时间；
- $S$：加速比，无单位；
- $TP$：吞吐率，单位是“条/秒”或“任务/秒”。

$$\Delta t=\max(t_i)$$

中文读法：**流水线周期等于所有阶段中最长的执行时间。**

理想等段题：

$$T=(k+n-1)\Delta t$$

中文读法：**装满流水线需要 $k$ 个周期，之后剩余 $n-1$ 个任务各增加一个周期。**

题目明确各段实际耗时且不等长：

$$T=\sum_{i=1}^{k}t_i+(n-1)\Delta t$$

其中 $\sum$ 表示“把第 $1$ 段到第 $k$ 段的时间全部相加”。中文读法：**第一条任务完整走过各段，再加上其余任务每条一个流水线周期。**

$$S=\frac{T_{\text{串行}}}{T_{\text{流水}}},\qquad TP=\frac{n}{T_{\text{流水}}}$$

中文读法：**加速比等于串行时间除以流水时间；吞吐率等于完成数量除以流水总时间。**

### Cache、RAID 与性能

**Cache 公式算什么**：按命中与未命中的概率，计算一次访问的平均耗时。

- $h$：Cache 命中率，取值为 $0$～$1$；
- $T_c$：访问 Cache 所需时间；
- $T_m$：访问主存所需时间；
- $T$：平均访问时间，时间单位必须与 $T_c$、$T_m$ 一致。

题目把命中和未命中看成二选一：

$$T=hT_c+(1-h)T_m$$

中文读法：**命中概率乘 Cache 时间，加上未命中概率乘主存时间。**

题目明确“先查 Cache，未命中再查主存”：

$$T=T_c+(1-h)T_m$$

中文读法：**每次都先付出一次 Cache 查询时间，只有未命中时才追加主存时间。**

**RAID 公式算什么**：计算磁盘阵列的可用容量。

- $N$：磁盘总块数；
- $S$：单块磁盘容量，单位可为 GB 或 TB；
- $C_0$、$C_1$、$C_5$、$C_{10}$：对应 RAID 级别的可用容量。

$C_0=NS,\qquad C_1=C_{10}=\frac{N}{2}S,\qquad C_5=(N-1)S$

中文读法：**同容量磁盘时，RAID 0 使用全部磁盘；RAID 1 和 RAID 10 用一半容量做镜像；RAID 5 用相当于一块磁盘的容量保存校验信息。**异容量 RAID 5 的经典题型按最小盘容量计算：

$C_5=(N-1)S_{min}$

完整陷阱见 [[RAID]]。

**CPU 性能公式算什么**：从指令条数、平均每条指令周期数和时钟周期计算程序运行时间。

- $IC$：程序执行的指令条数；
- $CPI$：平均每条指令需要的时钟周期数；
- $T_{clock}$：一个时钟周期的时间；
- $T_{CPU}$：CPU 执行该程序的时间。

$$T_{CPU}=IC\times CPI\times T_{clock}$$

中文读法：**程序时间等于指令条数，乘平均每条指令的周期数，再乘每个周期的时间。**

MIPS 表示“每秒执行多少百万条指令”：

$$MIPS=\frac{主频}{CPI\times10^6}$$

其中主频单位为 Hz，$10^6$ 用于把“条/秒”换成“百万条/秒”。该指标不适合脱离指令集与负载直接比较。

**Amdahl 公式算什么**：只优化程序的一部分后，计算整体能加速多少。

- $f$：可优化部分占原总执行时间的比例；
- $r$：这部分自身的加速倍数；
- $S_{Amdahl}$：优化后的整体加速比。

$$S_{Amdahl}=\frac{1}{(1-f)+\frac{f}{r}}$$

中文读法：**整体新时间比例等于未优化比例，加上可优化比例除以局部加速倍数；整体加速比是它的倒数。**

### 磁盘访问时间

**算什么**：一次传统机械磁盘访问由哪些时间构成。

$T_{访问}=T_{寻道}+T_{旋转延迟}+T_{传输}$

若转速为 $R$ 转/分钟，一圈时间为 $60/R$ 秒，平均旋转延迟通常按半圈估计。完整计算与记录布局见 [[磁盘访问时间]]。

### 海明码

**算什么**：给定数据位数，求至少需要多少个海明校验位。

- $m$：原始数据位数；
- $r$：需要增加的校验位数；
- $m+r$：编码后的总位数；
- 右侧的 $+1$：为“没有发生错误”保留一种状态。

$$2^r\ge m+r+1$$

中文读法：**$r$ 个校验位能表示 $2^r$ 种状态，这些状态至少要覆盖全部 $m+r$ 个可能出错位置，再加一种无错误状态。**校验位放在第 $1,2,4,8,\ldots$ 位，综合征按二进制解释为出错位置。完整编码与纠错见 [[海明码]]。

## 高频对比

| 对比 | 核心区分 | 典型陷阱 |
| --- | --- | --- |
| 原码 / 反码 / 补码 | 补码统一加减运算，且零唯一 | 最小负数在补码中没有对应正数 |
| 定点 / 浮点 | 定点简单精确；浮点用精度换范围 | 指数决定范围，尾数决定精度 |
| CISC / RISC | CISC 指令复杂多样；RISC 少而规整、寻址少、寄存器多 | 经典“RISC↔硬布线、CISC↔微程序”是关联，不是绝对规则 |
| 冯·诺依曼 / 哈佛 | 指令数据共享体系 / 相对独立通路 | DSP 经典题眼是哈佛结构 |
| 共享内存 / 消息传递 | 共同地址空间 / 显式发送接收 | Flynn 是分类，不是通信方式 |
| 指令寻址 / 存储器访问 | 立即/直接/间接等是 CPU 找操作数；随机/顺序/直接/相联是存储器找数据 | 两套都有“直接”，不要看到同名就当成同一个概念 |
| 直接 / 全相联 / 组相联 | 固定位置 / 任意位置 / 组内任意 | LRU 是最近最少使用，不是使用次数最少 |
| 写直达 / 写回 | 每次同步主存 / 淘汰时回写 | 写回速度快，但一致性管理更复杂 |
| 奇偶 / CRC / 海明 | 检错 / 强检错 / 定位并纠正一位错 | CRC 不能直接纠错 |
| 单工 / 半双工 / 全双工 | 单向 / 双向轮流 / 双向同时 | “能双向”不等于“全双工” |
| 同步 / 异步 | 共同节拍 / 握手协调 | 速度差大的外设更常见异步 |
| 中断 / DMA / 通道 | CPU 参与逐步减少 | DMA 仍需 CPU 初始化，不是完全没有 CPU |

## 最容易丢分的地方

- PC 保存**下一条**指令地址；顺序执行时按指令长度前进，转移指令会改写 PC。
- MAR 连接地址通路，MBR/MDR 保存读写数据；不要把 IR 当数据寄存器。
- IEEE 754 单精度是 $1+8+23$ 位；指数偏置是 $127$，特殊指数值另有含义。
- RAID 5 同容量时可用容量是 $(N-1)S$，异容量经典题先看 $S_{min}$；RAID 10 多盘容错取决于是否击穿同一镜像组。
- 地址范围题先算“结束地址 - 起始地址 + 1”，再做位扩展 × 字扩展。
- 中断断点/返回信息经典实现常保存在栈中；不要把“断点”与“全部现场”混为一谈。
- 总线“按传什么分”和“按一次传几位分”是两条分类轴，不能混成一组。
- MIPS 脱离指令集和负载不能直接比较机器优劣；Amdahl 的上限受未优化部分约束。
