# 操作系统 · 复习总纲

> [!tip] 10～15 分钟用法
> 按“CPU → 内存 → 文件 → 设备”回忆，计算题只看条件与公式；不会的题点回原子卡手推一遍。

## 30 秒主线

[[操作系统概述|操作系统]]是资源大管家：先用 [[程序与进程|进程]]、[[进程调度|调度]]和 [[线程与进程|线程]]管理 CPU，再用 [[信号量与PV基本概念|信号量]]协调并发、用 [[银行家算法安全性检查|银行家算法]]避免进入不安全状态；内存侧从 [[分页基本概念|分页]]走到 [[虚拟存储的基本概念|虚拟存储]]和四种页面置换，外存侧从 [[文件与文件系统|文件系统]]走到 [[文件多级索引|多级索引]]、[[SPOOLing]] 与 [[磁盘调度算法]]。

## CPU 与并发

| 对比 | 核心区分 | 考试提醒 |
| --- | --- | --- |
| 并发 / 并行 | 一段时间交替推进 / 同一时刻同时执行 | 单核可并发，不等于并行 |
| 进程 / 线程 | 资源容器 / 执行单元 | 同进程线程共享资源，但有独立运行现场 |
| FCFS / SJF / RR | 先来先服务 / 短作业优先 / 时间片轮转 | SJF 平均等待短但可能饥饿；RR 看响应与切换开销 |
| 互斥 / 同步 | 不能同时进入 / 按事件先后协作 | 生产者消费者同时包含两者 |
| 预防 / 避免 / 检测解除 | 破坏必要条件 / 运行前试算 / 发生后处理 | 银行家属于避免 |

**周转时间算什么**：一个进程从到达系统到执行完成，一共经历了多久。

- $T_{到达}$：进程进入就绪队列的时刻；
- $T_{完成}$：进程执行结束的时刻；
- $T_{服务}$：进程真正占用 CPU 的时间；
- $T_{周转}$：完成时刻减到达时刻；
- $T_{带权周转}$：周转时间与服务时间的比值，无单位。

$$T_{周转}=T_{完成}-T_{到达}$$

$$T_{带权周转}=\frac{T_{周转}}{T_{服务}}$$

中文读法：**周转时间等于完成时刻减到达时刻；带权周转时间等于周转时间除以实际服务时间。**

**信号量范围算什么**：判断有多少个进程正在等待同一个互斥资源。

- $S$：当前信号量的值；正值表示可用资源数，负值的绝对值常表示等待进程数；
- $n$：参与竞争的进程总数。

互斥信号量初值为 $1$，有 $n$ 个进程竞争一个资源时：

$$1-n\le S\le1$$

中文读法：**信号量最大为 $1$；最坏情况下一个进程占用资源，其余 $n-1$ 个进程等待，因此最小为 $1-n$。**

P 操作先减，结果为负则阻塞；V 操作先加，结果不大于 $0$ 时唤醒等待者。生产者通常先 P 空位再放产品，消费者先 P 产品再取产品。

**银行家公式算什么**：试算某个进程能否用现有资源完成，并在完成后扩大可用资源池。

- $Need_i$：进程 $i$ 还需要的各类资源数量；
- $Work$：试算过程中当前可用的各类资源数量；
- $Allocation_i$：已经分配给进程 $i$ 的各类资源数量；
- 向量比较 $Need_i\le Work$：每一类资源的需要量都不能超过现有量。

当 $Need_i\le Work$ 时，假设进程完成并释放已占资源：

$$Work\leftarrow Work+Allocation_i$$

箭头 $\leftarrow$ 读作“更新为”。整条式子读作：**新的可用资源等于原可用资源，加上该进程完成后归还的已分配资源。**这里不从 $Work$ 中扣除 $Need_i$，因为是在验证“能否完成并归还资源”的安全序列。

## 内存、文件与设备

**分页地址公式算什么**：把逻辑地址拆成页号和页内偏移，再换算成物理地址。

- $b$：页内偏移占用的二进制位数；
- $2^b$：页面大小，单位通常是 Byte；
- $\lfloor x\rfloor$：对 $x$ 向下取整；
- $\bmod$：取除法余数。

逻辑地址按页面大小 $2^b$ 拆分：

$$页号=\left\lfloor\frac{逻辑地址}{2^b}\right\rfloor,\qquad 页内偏移=逻辑地址\bmod2^b$$

中文读法：**逻辑地址除以页面大小，商是页号，余数是页内偏移。**

查到页框后：

$$物理地址=页框号\times页大小+页内偏移$$

中文读法：**先找到该页装入的物理页框起始地址，再加页内偏移。**

页面置换看“淘汰谁”：OPT 看未来最晚再用，FIFO 看最早进入，LRU 看过去最久未用，Clock 用访问位近似 LRU。初始空页框第一次装入也算缺页。

**位示图公式算什么**：把磁盘块号换成位示图中的字号和位号。

- 字长：每个字包含的二进制位数；
- 字号：位示图中第几个字；
- 位号：该字内部的第几位。

位示图采用从 $1$ 开始编号时：

$$字号=\left\lfloor\frac{块号-1}{字长}\right\rfloor+1$$

$$位号=(块号-1)\bmod字长+1$$

中文读法：**先把从 $1$ 开始的块号转成从 $0$ 开始计算，除以字长的商决定字号，余数决定位号，再各自加 $1$。**

**多级索引公式算什么**：计算一个索引块能放多少个地址，以及多级间接索引能找到多少个数据块。

- $B$：索引块大小，单位是 Byte；
- $a$：一个地址项大小，单位是 Byte；
- $N$：一个索引块能容纳的地址项数量；
- $k$：间接索引层级数。

若索引块大小为 $B$，地址项大小为 $a$：

$$N=\frac{B}{a},\qquad k\text{ 级间接可寻址数据块数}=N^k$$

中文读法：**每块能放的地址数等于块大小除以一个地址项大小；每增加一级索引，就再乘一次 $N$。**直接地址项只指向 $1$ 个数据块，不能当成一级间接。

## 最容易丢分的地方

- 操作系统四大特征常考并发、共享、虚拟、异步；“并发”是最基本特征之一。
- 死锁四条件：互斥、请求保持、不可剥夺、循环等待；漏一个就不是完整答案。
- 分页按固定大小切分，便于物理管理；分段按逻辑意义划分，便于共享保护。
- FIFO 淘汰“最早进入”的页，LRU 淘汰“最久没被访问”的页，时间基准不同。
- 位示图公式必须匹配题目的编号起点；从 $0$ 开始时不能套用“减 $1$ 再加 $1$”。
- SCAN 像电梯往返，CSCAN 单向服务后回到起点；算题必须先画当前磁头和运动方向。
- 嵌入式系统不一定实时，实时系统也不等于必须使用某个固定 RTOS。
