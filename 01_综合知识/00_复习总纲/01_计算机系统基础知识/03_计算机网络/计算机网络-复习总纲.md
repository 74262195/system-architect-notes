# 计算机网络：减负复习总纲

> **先看 [[计算机网络-知识点边界]]。规则：大纲定范围，教材定深度，近年真题定优先级。第一次完整学习顺序只认 [[计算机网络索引]]；这份总纲按 P0/P1/P2/P3 做复习，不另造第二条学习路线。**

## 30 秒主线

1. 网络从“为什么联网”发展到大规模互联后，首先需要共同协议和分层，所以先抓 [[网络协议与OSI七层]] 与 [[OSI与TCP-IP协议体系对比]]。
2. 分层落到设备和通信过程后，依次理解 **设备看什么 → 网络有哪些形态 → 信号怎样经过信道/交换 → 性能怎样评价**。
3. 局域网内部抓 **以太网 → 交换机 → MAC 表 → VLAN/STP**；跨网络抓 **IPv4/CIDR → ARP → 路由 → IPv4/ICMP/IPv6**。
4. 到达目标主机后抓 **TCP/UDP → 端口 → 应用协议**；接入配置顺序记 **DHCP 先给网络参数，DNS 再把域名解析成 IP**。
5. 最后用 **WLAN → 移动通信/5G → 网络拓扑 → 层次化组网 → 规划/设计/实施** 收口。

# 第一轮：先拿下 P0 + P1

## P0

### [[网络协议与OSI七层]]
必须做到：
- 帧/MAC/交换机 → 数据链路层；
- IP/ICMP/路由器 → 网络层；
- TCP/UDP/端口 → 传输层；
- HTTP/DNS/SMTP/NFS → 应用层。

### [[无线局域网802.11]]
必须做到：
- WLAN/802.11 的基本定位；
- 无线 802.11 → CSMA/CA；
- 与传统共享式以太网 CSMA/CD 区分；
- 具体旧标准速率只按已核验题源最低识别，不背完整 Wi-Fi 参数表。

## P1：稳定主线

1. [[OSI与TCP-IP协议体系对比]]：七层 ↔ TCP/IP 四层；同时认清常见**教学五层模型**只是把底部链路层、物理层重新拆开，不能把五层叫成 TCP/IP 四层。
2. [[网络互联设备]]：中继/集线、交换、路由、网关、防火墙基本定位。
3. [[交换机]]：二层交换机解决什么问题。
4. [[MAC地址与交换机转发表]]：**学源 MAC → 查目的 MAC → 定向转发/泛洪**。
5. [[子网掩码与CIDR]]：`/n` → 网络位/主机位 → 地址块。
6. [[子网划分与地址范围计算]]：网络/广播/主机范围。
7. [[TCP与UDP对比]]：可靠连接字节流 vs 无连接数据报。
8. [[应用层协议功能与端口识别]]：功能和层次先拿分，端口做校验。

> `IP编址与子网划分`、`应用层常用协议`、`路由协议与路由选择` 都只是专题导航，不算新的学习任务。

# 题干关键词 → 第一反应

| 题干信号 | 第一反应 |
| --- | --- |
| 帧 / MAC / 交换机 | 数据链路层 |
| IP / 路由器 / 路由选择 | 网络层 |
| TCP / UDP / 端口 | 传输层 |
| HTTP / DNS / SMTP / NFS | 应用层 |
| 未知目的 MAC | 交换机未知单播泛洪；不要和 ARP 请求混成一回事 |
| `/27`、网络地址、广播地址 | 先定前缀和块边界，再算范围 |
| 域名 → IP | DNS |
| 自动获得 IP/掩码/网关/DNS | DHCP |
| 当前 IPv4 链路 IP → MAC | ARP |
| 多条路由同时匹配 | 选最长前缀 |
| ping / TTL 超时 / 不可达 | ICMP |
| Wi-Fi / 802.11 | WLAN、CSMA/CA |
| 核心/汇聚/接入 | 层次化组网 |
| 需求/可行性 → 方案 → 安装切换 | 规划 → 设计 → 实施 |

# 已明确退出本章主复习线

- OSPF LSA、邻居状态机；
- BGP 路径属性和工程选路；
- 交换机/路由器厂商 CLI；
- 复杂 VLSM 地址规划；
- 802.1Q、QinQ 工程字段与配置；
- TCP TIME_WAIT、拥塞窗口、慢开始等实现细节；
- 5G NR 帧结构、核心网网元、切片编排；
- NAT 独立专题：当前第 2 版网络基础章节未明确展开，暂不自行扩展。

CRC 不重复学：算法回到校验码主线；网络这里只知道以太网 FCS 用 CRC 做差错检测。
