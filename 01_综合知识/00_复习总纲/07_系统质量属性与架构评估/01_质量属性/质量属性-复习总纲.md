# 质量属性 · 复习总纲

> 预计 10 分钟。先闭卷回答，卡住再点原子卡。

## 30 秒主线
[[质量属性-开发期与运行期]]：功能做对 ≠ 质量做好。  
[[质量属性场景六要素]]：把模糊要求变成可测场景。  
[[性能质量属性场景]]：响应时间/吞吐量。  
[[可靠性与可用性]]：多久不坏 vs 想用时能不能用。  
[[安全性质量属性场景]]：合法服务 + 阻止未授权。  
[[可修改性质量属性场景]]：变化代价与影响范围。  
[[可测试性质量属性场景]]：能否观察、控制并高效验证。  
[[易用性质量属性场景]]：任务时间、错误、满意度。

## 六要素
**刺激源 → 刺激 → 环境 → 制品 → 响应 → 响应度量**

| 题眼 | 属性 |
| --- | --- |
| 响应时间、吞吐量、期限、抖动 | 性能 |
| 规定时间内无故障 | 可靠性 |
| 正常工作比例、恢复时间 | 可用性 |
| 越权、篡改、认证、攻击检测 | 安全性 |
| 修改元素数量、人日、连带影响 | 可修改性 |
| 覆盖、测试时间、状态可观察 | 可测试性 |
| 学习曲线、任务时间、错误、满意度 | 易用性 |

## 最容易丢分
1. 高负载在某句中可能是环境，不一定是刺激。
2. 返回结果是响应，“2 秒内”才是响应度量。
3. 可靠性 ≠ 可用性。
4. 安全产品是手段，不是完整安全场景。
