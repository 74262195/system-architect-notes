# 信息系统生命周期 · 复习总纲

> 预计 6 分钟。先闭卷回答“这道题在讲哪一段”，卡住再点原子卡。本模块只有两张卡，重点不是背五步名称，而是把两套容易混的“阶段”分开。

## 一、大纲边界与优先级

大纲把**生命周期的四个阶段**列为信息系统概述的基本要求，并把开发阶段的五个子步骤作为其中一段的展开。它要的是“认得出、排得对”，不要求背每一步的交付文档清单。

| 原子卡 | exam_priority | 什么时候做 |
| --- | --- | --- |
| [[4大阶段]] | P2 | 第一轮先做到一句话说清顺序和每段回答什么，细节放第二轮 |
| [[开发阶段5子步骤]] | P2 | 第一轮先掌住“分析问要做什么、设计问怎样实现”，其余第二轮 |

本模块**没有 P0/P1 卡**。第一轮只需要两个动作：分开“一个系统的一生”和“一个组织的信息化成熟”；分开系统分析与系统设计。相邻的 [[诺兰模型]] 是 **P3**，时间紧可跳过，只留一句“讲组织成熟度的是它，不看待建系统”。

## 二、30 秒主线

产生（为什么要建、需要什么）→ 开发（总体规划 → 系统分析 → 系统设计 → 系统实施 → 系统验收）→ 运行（移交用户并持续维护）→ 消亡（更新改造、替代或报废重建）。

两点收口：开发五步只是第二段的内部展开，见 [[开发阶段5子步骤]]；描述对象一旦从“某个系统”换成“整个组织”，就转到 [[诺兰模型]]。

## 三、题干关键词 → 第一反应

| 题干看到什么 | 第一反应与动作 |
| --- | --- |
| 提出建设想法、调研、形成需求分析报告 | 判**产生**阶段；不要因为出现“分析”二字就跳进开发阶段 |
| 企业战略中的位置、总体架构、实施计划 | 开发阶段的**总体规划** |
| 组织职能、业务流程、数据流、逻辑模型 | 开发阶段的**系统分析** |
| 系统架构、数据库、模块、接口、安全方案 | 开发阶段的**系统设计** |
| 把设计落到计算机和网络、让系统可运行 | 开发阶段的**系统实施** |
| 试运行暴露性能/易用性问题、用户确认 | 开发阶段的**系统验收** |
| 已移交用户后的排错、适应环境变化 | **运行**阶段；维护不属于单独一个宏观阶段 |
| 更新改造、功能扩展、替代、报废重建 | **消亡**阶段；要判断的是时机与成本 |
| 组织内系统从分散扩张走向集成、数据治理 | 这是 [[诺兰模型]] 的题，不是生命周期四阶段 |

## 四、核心做题动作

**动作 A：先按“题干在讲谁”分成四段。** 讲需求与想法 → 产生；讲把需求做成系统 → 开发；讲移交后的使用与维护 → 运行；讲替代与退出 → 消亡。

**动作 B：开发阶段内部再问“当前要回答什么问题”。** 定方向的是总体规划，说清业务要什么的是系统分析，定实现方案的是系统设计，把方案做成可运行系统的是系统实施，由用户试运行确认的是系统验收。不要用“画了图”判断阶段，要看图在表达业务逻辑还是技术实现。

本模块没有需要保留的计算公式；四阶段和五步都按上面的分流判断即可。

## 五、高频对比

| 概念 | 核心区分 | 典型题干 | 常设陷阱 |
| --- | --- | --- | --- |
| 产生 | 提出概念、调研并形成需求分析报告 | 为什么要建、用户需要什么 | 因为出现“分析”就误判成开发阶段 |
| 开发 | 把需求变成可用系统（含五步） | 规划、分析、设计、实施、验收 | 把五步当成五个宏观阶段一起数 |
| 运行 | 移交用户后稳定使用并维护 | 排错、适应变化、完善 | 把维护写成第五个宏观阶段 |
| 消亡 | 系统退出使用的时机与成本 | 更新、扩展、替代、报废重建 | 以为消亡等于直接删除 |
| [[诺兰模型]] | 组织的信息化成熟过程 | 从扩张走向控制、集成、数据治理 | 与生命周期四阶段对调 |

## 六、最容易丢分的地方

- **需求分析在产生阶段。** 教材把调研和需求分析过程放在产生阶段，所以题干里的“分析”可能指需求分析而不是系统分析；判断依据是它在形成需求，还是在把需求变成系统。
- **维护不是第五个宏观阶段。** 维护发生在系统移交之后，属于运行阶段的工作；五步只是开发阶段内部的展开，把两套“阶段”叠在一起数就会多出一段。
- **消亡不等于删除。** 更新改造、功能扩展、替代和报废重建都是退出方式，看到这些词仍应选消亡阶段。
- **两套阶段描述对象不同。** 单个系统从提出到退出看四阶段，组织的信息化成熟看 [[诺兰模型]]；两端都在讲“阶段”，所以最容易对调。

## 八、闭卷自测

- [ ] 四阶段的顺序是什么？每段正面回答的问题分别是什么？
- [ ] 需求分析为什么在产生阶段，而不在开发阶段？
- [ ] 开发阶段五个子步骤能否按顺序说全？
- [ ] 系统分析与系统设计的最小区别是什么？能只看画了什么图吗？
- [ ] 为什么维护不算第五个宏观阶段？
- [ ] “消亡”阶段除了直接删除系统，还包括哪些退出方式？
