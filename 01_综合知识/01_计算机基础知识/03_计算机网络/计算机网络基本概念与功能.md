# 计算机网络基本概念与功能：为什么要把一堆独立计算机连起来

## 痛点：单机再强，也只能管自己

一台计算机可以算得很快、存很多数据，但如果文件只能靠 U 盘搬、打印机每人一台、服务器负载高了也不能把任务交给别的机器，整个系统就会变成一座座信息孤岛。

计算机网络要解决的不是“让网线亮起来”，而是：

> **让地理上分散、彼此独立的计算机通过通信线路和协议协同工作，实现信息传递和资源共享。**

## 一张图先看懂网络为什么存在

```mermaid
flowchart LR
    A[独立计算机] --> B[通信线路连接]
    B --> C[遵守网络协议]
    C --> D[互相通信]
    D --> E[共享资源与协同处理]
```

这里有三个关键词：

- **独立**：每台计算机本身仍能独立工作；
- **连接**：靠有线或无线通信线路互联；
- **协议**：双方必须遵守相同通信规则。

## 网络主要解决五类问题

| 功能 | 人话 | 典型场景 |
| --- | --- | --- |
| 数据通信 | 把信息从一台机器送到另一台 | 消息、文件、接口调用 |
| 资源共享 | 多台机器共同使用资源 | 文件、打印机、数据库 |
| 集中管理 | 统一配置、监控和控制 | 账号、策略、设备管理 |
| 分布式处理 | 把任务拆给多台机器 | 集群、分布式计算 |
| 负载均衡 | 避免一台机器被压垮 | 多服务器分担请求 |

所以“网络”的价值不只是通信，**共享、协同和分担**同样重要。

## 网络好不好，要看两类指标

### 性能指标：快不快

去 [[网络性能指标]] 重点看：

- 速率；
- 带宽；
- 吞吐量；
- 发送、传播、处理、排队时延；
- RTT。

### 非性能指标：好不好建设和维护

去 [[非性能性指标]] 重点看：

- 费用；
- 可靠性；
- 可扩展性；
- 可升级性；
- 易管理性；
- 可维护性；
- 标准化。

> **性能指标回答“跑得怎么样”，非性能指标回答“这个网络值不值得长期用”。**

## 考试怎么认

- “数据通信、资源共享、分布式处理、负荷均衡” → 网络功能。
- “带宽、吞吐量、时延” → 性能指标。
- “费用、可靠性、可扩展、易维护” → 非性能指标。
- 不要把“网络”理解成只有互联网；局域网、城域网、广域网、移动通信网都是网络。

## 一句话总结

> **计算机网络 = 独立计算机 + 通信线路 + 网络协议，最终目标是通信、共享和协同。**
