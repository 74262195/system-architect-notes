# 网络互联设备：从“放大信号”到“理解协议”

> [!important] 一句话结论
> 设备题按“工作层次 + 识别地址 + 能隔离什么”判断：中继器/集线器偏物理层，网桥/交换机看 MAC，路由器看 IP，网关强调异构协议转换。

## 痛点：网络变大后，设备不能只会“转发”

距离变长，信号会衰减；主机变多，所有人共享介质会碰撞；网络变多，又需要根据目的网络选择路径；若两边使用的协议体系不同，还需要翻译规则。不同问题需要不同层次的设备。

所以网络设备的发展像一条“能力升级线”：先恢复信号，再识别局部地址，接着理解 IP 网络，再完成协议转换。

## 定义：设备的层次决定它能看懂什么

| 设备 | 主要层次 | 看什么 | 主要作用 |
| --- | --- | --- | --- |
| 中继器 | 物理层 | 比特/信号 | 整形、放大、延长传输距离 |
| 集线器 | 物理层 | 比特/信号 | 将信号从一个端口复制到其他端口 |
| 网桥 | 数据链路层 | MAC 地址 | 连接网段、过滤和转发帧 |
| 交换机 | 数据链路层为主 | MAC 地址 | 多端口桥接、学习转发、隔离冲突域 |
| 路由器 | 网络层 | IP 地址和路由表 | 连接不同网络、选择路径、隔离广播域 |
| 网关 | 通常在高层 | 高层协议/数据格式 | 在异构协议或体系之间转换 |

这里的“主要层次”是考试定位，不表示现实设备只能工作在一层。例如三层交换机同时具备二层交换和三层路由能力。

## 核心机制：沿协议栈逐层增加判断能力

```mermaid
flowchart LR
  A[物理层<br/>信号] --> B[数据链路层<br/>MAC]
  B --> C[网络层<br/>IP与路由]
  C --> D[高层/跨层<br/>协议转换]
```

对应设备就是：中继器/集线器 → 网桥/交换机 → 路由器 → 网关。

设备越“聪明”，通常越能做出有语义的转发决定，但也会引入更复杂的处理和配置。考试不要只看设备名字，要看题目问的是信号、MAC、IP 还是协议转换。

## 易混对比：交换机、路由器、网关

| 对比维度 | 交换机 | 路由器 | 网关 |
| --- | --- | --- | --- |
| 主要层次 | 二层 | 三层 | 高层或跨层 |
| 核心依据 | MAC 地址表 | IP 地址、路由表 | 协议和数据格式 |
| 连接对象 | 局域网内网段/主机 | 不同 IP 网络 | 不同协议体系 |
| 广播域 | 普通交换机默认不隔离 | 端口之间隔离 | 取决于具体实现 |
| 关键词 | 帧、MAC、VLAN | 分组、IP、路由 | 协议转换、异构系统 |

**核心区分**：交换机解决“同一个局域网里送给哪块网卡”，路由器解决“跨网络往哪条路走”，网关解决“双方说的协议不一样怎么办”。

## 这个知识与考试的关系

- 看到“放大、整形、延长距离”选中继器；看到“所有端口都收到”想到集线器。
- 看到“MAC 地址表、未知单播泛洪”选交换机或网桥。
- 看到“路由表、下一跳、跨网段、IP 转发”选路由器。
- 看到“协议转换、异构网络、应用层转换”选网关。
- 看到“隔离广播域”通常选路由器；若题干明确 VLAN，也要考虑交换机的逻辑广播域划分。

## 记忆口诀

**中继看信号，交换看 MAC，路由看 IP，网关做翻译。**
