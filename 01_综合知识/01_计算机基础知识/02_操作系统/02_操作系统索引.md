# 操作系统索引

> 操作系统的全部考点按一条主线排好：**管 CPU → 管内存 → 管文件 → 管设备，最后落到处处可见的嵌入式。** 每篇开头是痛点、结尾是「下一站」，跟着走一遍就能形成整条线，而不是零散背知识点。

> [!tip] 复习入口
> 学完原子卡后，用 [[操作系统-复习总纲]] 在 10～15 分钟内闭卷召回公式、对比与陷阱。

## 主线（按阅读顺序）

| # | 篇名 | 一句话 | 为什么接得上 |
| --- | --- | --- | --- |
| 1 | [[操作系统概述]] | 大管家管四样：CPU、内存、文件、设备 | **入口篇**，先建全局地图 |
| 2 | [[进程与线程]] | 程序→进程，PCB 是身份证，三态转换 | 管家管 CPU 的第一步 |
| 3 | [[进程调度]] | 谁先上 CPU：FCFS/SJF/RR/多级 + 周转计算 | 进程排队抢 CPU，规则怎么定 |
| 4 | [[信号量与PV操作]] | 抢同一份数据会打架，P 申请 V 释放 | 抢 CPU 之外还要抢数据，要加锁 |
| 5 | [[死锁与银行家算法]] | 互相等对方手里的锁，银行家先算后借 | 锁加多了会死锁，怎么避免 |

## 必考计算清单（冲刺自检）

| 计算点 | 对应篇 | 记什么 |
| --- | --- | --- |
| 进程调度周转/平均周转 | [[进程调度]] | 周转 = 完成 − 到达 |
| PV 信号量取值范围 | [[信号量与PV操作]] | $S_{\min}=1-n$、互斥初值 1 |
| 银行家安全序列 | [[死锁与银行家算法]] | 还需 ≤ 现有，喂完归还放大池子 |
| 逻辑→物理地址 | [[存储管理]] | 物理地址 = 页框×页大小+偏移 |
| 缺页次数 / 缺页率 | [[虚拟存储与页面置换]] | LRU/FIFO 逐格数，空内存先缺页 |
| 位示图坐标 | [[文件管理]] | 字号 = 块号÷字长，位号 = 块号%字长 |
| 多级间接索引容量 | [[文件管理]] | $N=\frac{块大小}{地址项大小}$，$k$ 级间接索引可寻址 $N^k$ 个数据块；直接地址项只指向一个数据块 |
| 磁头移动总道数 | [[设备管理与磁盘调度]] | SCAN/CSCAN 先定方向再数格子 |

## 三科联动

- **综合知识**：上面 10 篇的选择题 + 计算题直接命中。
- **案例分析**：PV 生产消费、死锁/银行家常出现在案例题里的"并发与资源"小题。
- **论文素材**："资源受限、RTOS 抢占保时延"可作嵌入式/物联网类论文的论证素材。
