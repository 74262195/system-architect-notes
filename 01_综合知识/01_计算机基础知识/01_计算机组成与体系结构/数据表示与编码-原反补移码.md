# 原码 / 反码 / 补码 / 移码

## 痛点：负数怎么写进机器？减法能不能也用加法算？

机器数只有 0 和 1，没有"负号"。可温度、账户余额、偏移量都可能是负数——**负数到底怎么写？** 更麻烦的是：如果加减各造一套电路，硬件就翻倍了。

于是编码一路演进：原码先"符号位+绝对值"地写负数 → 反码把数值位取反 → 补码"取反加一"，把减法也变成加法算 → 移码专门伺候浮点阶码。**这就是四种码存在的意义：既要表示负数，又要让减法归一到加法、让比较大小变简单。**

> 记一句：**原码直观、反码过渡、补码 0 唯一是整数主流、移码只服务浮点阶码。**

## 定义（讲人话）

定长 $n$ 位机器数表示有符号数，四种编码各司其职：

- **原码**：`符号位 | 绝对值`。直观，但不能直接相加。
- **反码**：负数 = 原码数值位取反。减法转加法，但仍有 $+0/-0$ 两个零。
- **补码**：负数 = 反码加 1（取反加一）。**0 唯一**，负向多一个数，是整数主流格式。
- **移码**：补码符号位取反。编码大小与真值单调一致，专给浮点阶码用。

## 逐个认识 + 核心机制

- $n$ 位补码范围：$[-2^{n-1},\ 2^{n-1}-1]$（负向多一个，8 位能到 $-128$）
- 补码求真值：若最高位为 $1$，把整个码字视为无符号数 $U$，则真值为 $U-2^n$。
- 8 位码字 `10000000`：原码表示 $-0$，补码表示 $-128$；反码的 $-0$ 是 `11111111`。

| 对比项 | 原码 | 反码 | 补码 |
| --- | --- | --- | --- |
| 核心 | 符号+绝对值 | 数值位取反 | 反码+1 |
| 零 | $+0/-0$ | $+0/-0$ | 唯一 0 |
| 场景 | 教学 | 历史过渡 | 整数主流 |
| 考题词 | 直观 | 取反 | 取反加一、唯一0 |

**核心区分**：补码 0 唯一，省出的一码多表示一个最小负数，并把减法并入加法。

## 这个知识与考试的关系

- **选择题**：补码求真值 / 8 位补码最小数是 $-128$ / 阶码用哪种码 → 移码。
- **例题**：求 $-9$ 的 8 位补码 → $9=00001001$，取反 $11110110$，加 1 得 `11110111`。
- **经典陷阱**：把"唯一 0"说成原码的特点 ❌（是补码）；把移码说成整数运算用 ❌（浮点阶码用）。

## 记忆口诀

> **原反补移四兄弟，补码 0 唯一最实用；移码符号一反转，浮点阶码就找它。**
