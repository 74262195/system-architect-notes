# ROM 与 Flash：断电后为什么还能记得启动程序

## RAM 一断电就忘，开机代码从哪来

运行中的程序主要依赖 RAM，但 RAM 断电后数据会丢失。设备重新上电时仍需要保留固件、启动代码和配置，于是需要**非易失性存储**。

| 类型 | 关键特点 |
| --- | --- |
| MROM | 制造时写死 |
| PROM | 用户可一次性写入 |
| EPROM | 可擦除后重写，经典方式为紫外线擦除 |
| EEPROM | 可电擦写 |
| Flash | 电擦写，适合较大块数据存储 |

Flash 可以看作 EEPROM 技术路线中的重要发展形式，广泛用于固件和固态存储。

> [!warning] 易错点
> “ROM”在考试里常作为非易失性存储的代表，但现代 Flash 并不是“只能读不能写”。不要把 ROM 家族机械理解成永远不能改写。

## 一句话记住

> **RAM 是运行时临时工作区；ROM/Flash 负责断电后仍保留固件和数据，差别主要在改写能力和方式。**
