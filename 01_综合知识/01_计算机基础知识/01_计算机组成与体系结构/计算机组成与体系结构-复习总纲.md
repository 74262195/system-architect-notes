## 必背公式：先认适用条件

### 数值与地址

$n$ 位补码最高位为 $1$，若把码字视为无符号数得到 $U$：

$$x=U-2^n$$

$N$ 根地址线可区分的地址单元数为：

$$2^N$$

题目问容量时，还要乘“每个地址单元包含多少位或多少字节”。

### 流水线

设流水线有 $k$ 段，处理 $n$ 条指令，各段时间为 $t_i$：

$$\Delta t=\max(t_i)$$

理想等段题：

$$T=(k+n-1)\Delta t$$

题目明确各段实际耗时且不等长：

$$T=\sum_{i=1}^{k}t_i+(n-1)\Delta t$$

$$S=\frac{T_{\text{串行}}}{T_{\text{流水}}},\qquad TP=\frac{n}{T_{\text{流水}}}$$

### Cache、RAID 与性能

题目把命中和未命中看成二选一：

$$T=hT_c+(1-h)T_m$$

题目明确“先查 Cache，未命中再查主存”：

$$T=T_c+(1-h)T_m$$

设 $N$ 块等容量磁盘，每块为 $S$：

$$C_0=NS,qquad C_1=C_{10}=\frac{N}{2}S,qquad C_5=(N-1)S$$

$$T_{CPU}=IC\times CPI\times T_{clock}$$

$$MIPS=\frac{主频}{CPI\times10^6}$$

$$S_{Amdahl}=\frac{1}{(1-f)+\frac{f}{r}}$$

### 海明码

$m$ 是数据位数，$r$ 是校验位数，总码长为 $m+r$：

$$2^r\ge m+r+1$$

校验位放在第 $1,2,4,8,\ldots$ 位，综合征按二进制解释为出错位置。完整编码与纠错见 [[海明码]]。

## 高频对比

| 对比 | 核心区分 | 典型陷阱 |
| --- | --- | --- |
| 原码 / 反码 / 补码 | 补码统一加减运算，且零唯一 | 最小负数在补码中没有对应正数 |
| 定点 / 浮点 | 定点简单精确；浮点用精度换范围 | 指数决定范围，尾数决定精度 |
| CISC / RISC | CISC 指令复杂多样；RISC 少而规整 | 这是经典考试模型，现代实现边界已融合 |
| 直接 / 全相联 / 组相联 | 固定位置 / 任意位置 / 组内任意 | LRU 是最近最少使用，不是使用次数最少 |
| 写直达 / 写回 | 每次同步主存 / 淘汰时回写 | 写回速度快，但一致性管理更复杂 |
| 奇偶 / CRC / 海明 | 检错 / 强检错 / 定位并纠正一位错 | 奇偶校验不能指出哪一位错 |
| 中断 / DMA / 通道 | CPU 参与逐步减少 | DMA 仍需 CPU 初始化，不是完全没有 CPU |

## 最容易丢分的地方

- PC 保存**下一条**指令地址；顺序执行时按指令长度前进，转移指令会改写 PC。
- MAR 连接地址通路，MBR/MDR 保存读写数据；不要把 IR 当数据寄存器。
- IEEE 754 单精度是 $1+8+23$ 位；指数偏置是 $127$，特殊指数值另有含义。
- RAID 5 的可用容量是 $(N-1)S$，最少需要 $3$ 块盘；RAID 10 多盘容错取决于是否击穿同一镜像组。
- 总线“按传什么分”和“按一次传几位分”是两条分类轴，不能混成一组。
- MIPS 脱离指令集和负载不能直接比较机器优劣；Amdahl 的上限受未优化部分约束。

- [[操作系统-复习总纲|操作系统]]把 CPU、内存、磁盘这些硬件资源变成可分配、可保护的抽象。
