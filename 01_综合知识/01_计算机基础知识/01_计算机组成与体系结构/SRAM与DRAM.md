# SRAM 与 DRAM：为什么 Cache 和主存不用同一种芯片

## 如果 SRAM 更快，为什么内存不全用 SRAM

答案不是“做不到”，而是成本和密度不划算。

| 对比 | SRAM | DRAM |
| --- | --- | --- |
| 基本存储方式 | 双稳态电路 | 电容电荷 |
| 速度 | 快 | 相对慢 |
| 密度/成本 | 密度低、贵 | 密度高、便宜 |
| 刷新 | 不需要周期刷新 | 需要刷新 |
| 断电 | 数据丢失 | 数据丢失 |
| 典型用途 | Cache | 主存 |

DRAM 的电容会逐渐漏电，所以必须刷新；SRAM 只要持续供电，稳定状态不需要周期刷新。

## 考试怎么认

- “Cache 通常采用哪种存储器” → SRAM。
- “主存通常采用哪种 RAM” → DRAM。
- “需要刷新” → DRAM。
- “不刷新但掉电仍丢数据” → SRAM。

## 一句话记住

> **SRAM 快贵不刷新做 Cache，DRAM 慢些便宜要刷新做主存；两者都属于易失性 RAM。**
