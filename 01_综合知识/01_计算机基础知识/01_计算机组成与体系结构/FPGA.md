# FPGA：为什么它不像 CPU 那样“执行程序”，却也能做计算

## CPU 换软件，FPGA 可以重配硬件逻辑

CPU 的硬件数据通路基本固定，靠指令控制它做不同工作；FPGA 内部有大量可编程逻辑和互连资源，可以按设计重新配置成特定数字电路。

因此 FPGA 的核心优势是：

- **并行度高**：多个逻辑单元可真正同时工作。
- **可定制**：针对特定算法构造专用数据通路。
- **可重配置**：不像固定 ASIC 那样制造后就完全不能改变。

代价是开发方式、工具链和硬件资源约束都与普通 CPU 编程不同。

## 一句话记住

> **CPU 是“固定硬件跑不同指令”，FPGA 是“把可编程逻辑重新接成需要的硬件”。**
