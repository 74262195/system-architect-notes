## 跨知识点连线

| 从这里 | 连到这里 | 为什么连 |
| --- | --- | --- |
| 数据表示 | 指令与 CPU | 码字是 CPU 运算和解释的对象 |
| Cache/主存 | 分页/虚拟存储 | 一个是硬件局部性，一个是 OS 地址空间管理 |
| RAID/磁盘 | 文件系统/磁盘调度 | 硬件怎样存，OS 怎样组织和访问 |
| 总线/I/O | 中断/DMA/设备管理 | 硬件传输机制由 OS 驱动与调度 |
| CRC/FCS | 以太网 | 校验码落到链路层帧尾 |
| 进程/线程 | 端口/TCP/UDP | 端口把报文交给主机中的进程 |
| 中间件/构件 | 软件架构 | 复用、接口与分布式服务是架构材料 |
| 多媒体压缩 | 带宽/时延 | 码率降低网络负担，但增加计算或质量损失 |
| 嵌入式/RTOS | 安全攸关设计 | 截止时间、可靠性和失效安全共同约束系统 |
| CPU/网络性能 | 系统质量属性 | 局部指标最终要回到端到端负载与目标 |
