# 因果与目的关系识别

> [!info] 承接与定位
> 前面先保证题目方向不反。接下来处理最常见的逻辑链：一句话是在说“因为所以”，还是“为了达到某目标所以这样设计”。

> [!summary]- 快速复习卡片（20～40 秒）
> - 原因：because / because of / due to / since。
> - 结果：therefore / thus / result in / lead to。
> - 目的：so that / in order to / to + 动词 / the purpose is to。
> - 先画箭头：**原因 → 结果**；**措施 → 目的**。

## 一道具体英文问题

> Replication is used **so that** a service can continue to respond when one instance fails.

问：复制（replication）在这句话里的直接目的是什么？

## 逐步判断

- **主语：** `Replication`
- **谓语：** `is used`
- **目的信号：** `so that`
- **目的内容：** `a service can continue to respond`
- **条件块：** `when one instance fails`
- **关键专业词：** replication、service、instance fails。
- **中文知识映射：** 冗余/复制可在实例故障时维持服务，对应可用性/容错方向。
- **答案判断：** 直接目的不是“提高保密性”，而是**故障时继续提供服务**。

关系写成：

**replication → instance fails 时仍响应 → availability/fault tolerance**。

## 因果与目的不要混

- `because the node failed, the service became unavailable`：节点故障是**原因**。
- `use redundancy so that the service remains available`：冗余是**措施**，保持可用是**目的**。

两句都提到故障和可用性，但箭头方向不同。

## 考试第一动作

看到关系词就先圈起来，并在两边标：

- C = cause 原因
- R = result 结果
- M = measure 措施
- G = goal 目的

英文没翻完，逻辑箭头先画出来。

## 易混边界

- `for` 既可能表示“为了”，也可能只是“对于/用于”，不能单独机械判断。
- `since` 既可表示“自从”，也可表示“因为”，要看后面是不是原因句。
- `result from` 是“由……导致”，箭头方向与 `result in` 相反：A results **in** B = A→B；B results **from** A = A→B。
