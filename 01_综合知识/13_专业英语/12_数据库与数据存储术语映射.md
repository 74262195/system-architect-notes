# 数据库与数据存储术语映射

> [!info] 承接与定位
> 2018 的英语段落直接围绕 data storage、file types、legacy database、referential integrity 出题。数据库英语最有效的办法不是背所有词，而是按“表、键、事务、约束、分布”分组。

> [!summary]- 快速复习卡片（20～40 秒）
> - `primary key / foreign key`：主键 / 外键。
> - `referential integrity`：参照完整性，看到 related tables + valid links 优先想到它。
> - `transaction`：事务；ACID 是事务属性。
> - `normalization`：规范化；不要和 optimization（优化）混。
> - `partitioning / replication`：分区 / 复制，常见于分布式数据语境。

## 一道具体英文问题

> Referential integrity ensures that values linking related tables remain valid and consistent.

这句话不用逐字翻译，只需抓：

`linking related tables + valid + consistent` → **参照完整性**。

## 最小术语路由表

| 英文 | 中文定位 | 常见题眼 | 易混对象 |
|---|---|---|---|
| primary key | 主键 | uniquely identifies | foreign key |
| foreign key | 外键 | references another table | primary key |
| referential integrity | 参照完整性 | linking tables / valid references | entity integrity |
| normalization | 规范化 | redundancy / dependency | optimization |
| transaction | 事务 | commit / rollback / ACID | query |
| data storage | 数据存储 | file / database / retrieve | application logic |
| legacy database | 遗留数据库 | older/outdated technology | backup database |
| partitioning | 分区 | split data | replication |
| replication | 复制 | duplicate/copy data | partitioning |
| query | 查询 | retrieve/select data | update |

## 文件类题眼

2018 英语题还出现不同文件用途。做这类题不要背一串翻译，先看**数据是否长期核心、是否只供校验、是否记录历史/交易**。功能词比文件名本身更可靠。

## 考试第一动作

看到 `table / key / transaction / query / database / integrity / replication`，先锁定数据库知识域。随后调用中文规则，而不是在英语章重新推导范式或事务机制。

## 易混边界

- `consistency` 既可能是事务 ACID 的一致性，也可能是普通“一致”；看是否有 transaction 上下文。
- `availability` 在分布式数据库和系统质量属性中都可能出现，需结合上下文。
- `store procedure` 等 OCR/拼写异常不要照抄，应识别为正确术语 `stored procedure`。
