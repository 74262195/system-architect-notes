# 质量属性、安全与可靠性术语映射

> [!info] 承接与定位
> 质量属性最容易出现“每个词都认识，但中文概念边界串了”。本篇只建立英文题眼到中文属性的最短映射。

> [!summary]- 快速复习卡片（20～40 秒）
> - performance：响应时间、吞吐量、资源效率。
> - availability：需要服务时能否正常提供。
> - reliability：规定条件/时间内持续正确工作的能力。
> - confidentiality / integrity / availability：CIA 三要素。
> - authentication 是“你是谁”；authorization 是“你能做什么”。

## 一道具体英文问题

> A shorter recovery time after a failure mainly improves system availability.

问：为什么这里优先映射 availability，而不是 reliability？

## 英文句子拆解

- **原句：** `A shorter recovery time after a failure mainly improves system availability.`
- **主语：** `A shorter recovery time after a failure`。
- **谓语：** `improves`。
- **关键专业词：** recovery time、failure、availability。
- **否定/条件/比较信号：** `shorter` 带比较含义，强调恢复时间更短；无否定、条件。
- **中文知识映射：** 题目关注“发生故障以后多久恢复服务”，直接对应系统**可用性**。
- **答案判断：** 不能因为出现 `failure` 就机械选 reliability；若问 failure-free operation / specified time 才更直接指向可靠性。

## 大白话解释

**可靠性更像“多久不坏”，可用性更像“需要时能不能用，坏了多久恢复”。** 两者相关，但英文题会用 recovery、uptime、failure-free 等题眼区分。

## 最小术语路由表

| 英文 | 中文定位 | 题干信号 | 易混对象 |
|---|---|---|---|
| performance | 性能 | response time / throughput | availability |
| availability | 可用性 | uptime / recovery / ready for use | reliability |
| reliability | 可靠性 | failure-free / specified time | availability |
| modifiability | 可修改性 | change / add feature / effort | maintainability |
| confidentiality | 保密性 | prevent unauthorized disclosure | integrity |
| integrity | 完整性 | prevent unauthorized alteration | confidentiality |
| authentication | 认证 | identity / who you are | authorization |
| authorization | 授权 | permission / what you may do | authentication |
| fault tolerance | 容错 | continue despite faults | fault prevention |
| redundancy | 冗余 | spare/duplicate instance | backup only |

## 考试第一动作

不要看到 `security` 或 `failure` 就停止。继续找第二层题眼：secret/disclosure → confidentiality；tamper/alter → integrity；identity → authentication；permission/access right → authorization；recovery/uptime → availability。

## 易混边界

- CIA 中的 availability 与架构质量属性“可用性”语义相通，但题目可能从安全三要素角度考。
- `safety` 更偏“不会造成不可接受的伤害/事故”，`security` 更偏抵御未授权行为，两者不是同一个“安全”。
- reliability 与 availability 有联系但不能互换；一个系统可能经常坏但恢复极快，也可能很少坏但一坏很久。
