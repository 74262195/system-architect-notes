# 比较转折与对照关系

> [!info] 承接与定位
> 条件词规定“什么时候成立”，比较词则经常直接告诉你“两个相近概念到底差在哪里”。专业英语的干扰项常来自同一知识域，所以这种边界尤其重要。

> [!summary]- 快速复习卡片（20～40 秒）
> - `unlike`：与……不同。
> - `whereas/while`：前后对照。
> - `however`：后面常出现真正转折点。
> - `rather than`：选择后者所否定的对象。
> - 比较句先写成 A vs B 两列，再看题目问哪一侧。

## 一道具体英文问题

> **Unlike** asymmetric encryption, symmetric encryption usually uses the same secret key for encryption and decryption and is efficient for bulk data.

问：这句话突出 symmetric encryption 的哪两个特点？

## 逐步判断

- **主语：** `symmetric encryption`
- **谓语：** `uses`、`is`
- **比较信号：** `Unlike asymmetric encryption`
- **关键专业词：** same secret key、encryption/decryption、bulk data。
- **中文知识映射：** 对称加密通常加解密共享密钥，适合大量数据的高效加密；非对称加密密钥成对。
- **否定/条件信号：** 无。
- **答案判断：** 题目突出的是**同一秘密密钥 + 大数据处理效率较高**，不是“公钥可公开”。

把句子压成对照表：

| symmetric | asymmetric |
|---|---|
| same/shared secret key | public/private key pair |
| bulk data efficiency | 常用于密钥交换、签名等场景 |

## 转折词为什么比生词更值钱

> The design is simple; **however**, it does not scale well.

即使 `scale` 一时不熟，`however` 已告诉你：后半句与前半句方向相反，真正限制通常在后面。

## 考试第一动作

遇到 `unlike / whereas / while / however / rather than / compared with`，先画一条竖线，把两侧对象分开，再从中文知识里找“唯一差异”。

## 易混边界

- `while` 既可表示“当……时”，也可表示“然而/而”，要看前后是否在对照两个事实。
- `more`、`less` 必须看比较对象，不能只翻“更多/更少”。
- 技术概念的比较只服务于题目；不要在本章重新扩写完整安全算法教材。
