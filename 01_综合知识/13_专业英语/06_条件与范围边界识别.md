# 条件与范围边界识别

> [!info] 承接与定位
> 因果告诉你“为什么”，条件告诉你“在什么前提下结论才成立”。技术题里一个条件词被漏掉，就会把局部规则误当成永远成立。

> [!summary]- 快速复习卡片（20～40 秒）
> - `if/when`：在该条件下。
> - `unless`：除非；可先改写成“if not”。
> - `only if`：只有在……条件下，方向不要倒。
> - `until`：一直到某条件发生之前/为止。
> - 先把“条件框”圈出来，再判断主句结论。

## 一道具体英文问题

> **If** a transaction has acquired an exclusive lock on a row, another transaction cannot modify that row **until** the lock is released.

问：第二个事务什么时候才能修改这行？

## 逐步判断

- **条件：** `If a transaction has acquired an exclusive lock on a row`
- **主句主语：** `another transaction`
- **主句谓语：** `cannot modify`
- **时间/解除边界：** `until the lock is released`
- **关键专业词：** transaction、exclusive lock、row、released。
- **中文知识映射：** 数据库并发控制中的排他锁。
- **否定信号：** `cannot`，但它处在规则结论内，不是让你找错误选项。
- **答案判断：** 必须等**排他锁释放后**，另一个事务才可修改。

## `only if` 为什么容易反

> A write is allowed **only if** the user is authorized.

意思是：**写操作成立 → 用户必须已授权。**

不能反推出“只要授权就一定会发生写操作”。`only if` 给的是必要条件。

## `unless` 的最低成本处理

> The backup node is not activated unless the primary node fails.

先改写：

> If the primary node does **not** fail, the backup node is not activated.

不要为了做英语题重新学习完整条件逻辑，只要把它恢复成你熟悉的中文边界。

## 考试第一动作

圈出 `if / when / unless / only if / until`，然后问：

**“这句话哪一部分是前提？哪一部分才是结论？”**

## 易混边界

- `when` 在技术说明里常表示条件/触发，不一定强调具体时间点。
- `if` 不等于一定发生，只描述成立条件。
- `only if` 与 `if` 方向不同，遇到选项互换前后件时尤其要警惕。
