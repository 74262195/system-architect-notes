# 应用数学、项目与新技术术语映射

> [!info] 承接与定位
> 这是综合知识专业英语的尾卡：把剩余跨域词建立最低成本入口。目标不是再开三个新英语词典，而是保证题目换成英文时不会因为一个关键名词认不出中文知识。

> [!summary]- 快速复习卡片（20～40 秒）
> - critical path / slack → 网络计划与关键路径。
> - probability / expected value / simulation → 应用数学。
> - schedule / milestone / risk → 项目管理语境。
> - edge computing / digital twin / stream processing → 新技术语境。
> - 本篇只负责“认出来并回原章”，不重做计算和机制。

## 一道具体英文问题

> Activities on the critical path have no scheduling flexibility that can delay without affecting the project completion time.

问：看到 `critical path` 后应该停在英语翻译，还是回到哪个中文知识点？

## 英文句子拆解

- **原句：** `Activities on the critical path have no scheduling flexibility that can delay without affecting the project completion time.`
- **主语：** `Activities on the critical path`。
- **谓语：** `have`。
- **关键专业词：** critical path、scheduling、project completion time。
- **否定/条件/比较信号：** `no` 是否定信号；`without affecting` 表示“不影响”的边界。
- **中文知识映射：** 第 12 章应用数学中的**网络计划与关键路径**。
- **答案判断：** 题目一旦继续给活动工期、依赖关系并要求判断总工期，就应回 `[[10_网络计划与关键路径]]` 做中文计算；不能把 critical path 误认成 shortest path。

## 大白话解释

专业英语只负责把 `critical path` 认成“关键路径”。**认出来以后，真正怎么算仍由第 12 章负责。** 这正是本章“不复制前 12 章正文”的边界。

## 最小术语路由表

| 英文题眼 | 中文定位 | 易混点 |
|---|---|---|
| critical path | 关键路径 | shortest path 最短路径 |
| slack / float | 时差/松弛时间 | duration 工期 |
| probability | 概率 | possibility 日常“可能性”不一定是数值概率 |
| expected value | 期望值 | most likely value 最可能值 |
| simulation | 模拟 | mathematical proof 证明 |
| milestone | 里程碑 | ordinary task 普通任务 |
| risk | 风险 | issue 已发生问题 |
| edge computing | 边缘计算 | cloud computing 云计算 |
| digital twin | 数字孪生 | ordinary simulation 普通模拟 |
| stream processing | 流处理 | batch processing 批处理 |

## 考试第一动作

看到跨域术语先完成两步：

1. 用关键词判断中文知识域；
2. 问自己“这题只考术语识别，还是已经开始考原知识的计算/机制？”

如果已经进入计算或机制，立刻回到原章节思路，不在英语层停留。

## 易混边界

- `critical path` 是决定项目总工期的链，不是图论的 shortest path。
- `risk` 是尚未确定发生但可能影响目标的事件/条件；`issue` 往往指已出现的问题，具体以题干语境为准。
- 新技术英文名变化快，本章不维护产品名清单，只认教材/大纲对应的稳定概念词。
