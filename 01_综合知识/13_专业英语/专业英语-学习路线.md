# 专业英语-学习路线

> [!info] 这一章不是“先背词，再做题”
> 固定动作是：**先看题目要求 → 圈关系信号 → 找主干 → 抓专业词 → 映射中文知识 → 用上下文排除。**

```mermaid
flowchart LR
    A["题目要求"] --> B["关系信号"]
    B --> C["句子主干"]
    C --> D["专业词/缩写"]
    D --> E["中文知识域"]
    E --> F["选项排除"]
```

## 第一段：先让英文段落“可拆”

1. [[01_上下文完形与空格定位]]：空格不是从四个单词开始猜，先判断这里缺“动作、对象、类别还是关系”。
2. [[02_长句主干与修饰剥离]]：先找谁做什么，再把 which/that 等修饰接回去。
3. [[03_定义题与定义信号]]：看到 defined as、refers to、is the…that，优先做术语定义映射。

## 第二段：关系词决定题意方向

4. [[04_否定例外与错误项识别]]：先把 NOT/EXCEPT/INCORRECT 翻译成做题动作。
5. [[05_因果与目的关系识别]]：分清“为什么”和“为了什么”。
6. [[06_条件与范围边界识别]]：if/when/unless/only if 会改变结论成立范围。
7. [[07_比较转折与对照关系]]：unlike/whereas/however 常直接暴露两个选项的边界。
8. [[08_流程顺序与篇章衔接]]：first/next/once/finally 把一整段流程串起来。
9. [[09_缩写与英文全称还原]]：缩写先还原全称，再用关键词定位中文章节。

## 一轮复习怎么走

- **第一遍：** 只做 01～09，每篇看例句时必须口头说出“主语、谓语、信号词、中文知识点”。
- **第二遍：** 只看 10～15 的术语路由表，看到英文先说“属于哪个中文知识域”，不要先追求逐字翻译。
- **第三遍：** 找历年 Q71—Q75 共用段落，先遮住选项，用上下文猜空格需要哪一类概念，再打开选项排除。
