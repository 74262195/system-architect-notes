# 软件架构术语映射

> [!info] 承接与定位
> 从这里开始不再训练新的英语技巧，而是把英文题眼送回已经学过的中文知识。2009、2010、2013、2014 的英语段落都明显偏向架构语境，因此先建立架构术语路由。

> [!summary]- 快速复习卡片（20～40 秒）
> - `component + connector + constraint`：优先想到架构风格/结构。
> - `view` 是看到的架构表示；`viewpoint` 是规定如何构造/解释 view 的约定，不要混。
> - `reference architecture` 强调某领域高层元素及关系的参考组织。
> - `allocation` 常提示“软件元素映射到硬件/环境”。

## 一道具体英文问题

> A component-and-connector structure focuses on runtime elements and their interactions.

问：这句话应该映射到哪个中文架构概念？

## 英文句子拆解

- **原句：** `A component-and-connector structure focuses on runtime elements and their interactions.`
- **主语：** `A component-and-connector structure`。
- **谓语：** `focuses on`。
- **关键专业词：** component-and-connector、runtime elements、interactions。
- **否定/条件/比较信号：** 无。
- **中文知识映射：** 软件架构结构分类中的“构件—连接件结构”，重点是运行时元素及其交互。
- **答案判断：** 如果选项在“模块结构 / C&C 结构 / 分配结构”之间选择，应选 **component-and-connector structure**。

## 大白话解释

看到 `runtime + interactions`，题目关心的是系统运行时“谁和谁交互”，而不是代码模块怎样静态组织，也不是软件怎样映射到硬件。

## 最小术语路由表

| 英文题眼 | 中文定位 | 常见题干信号 | 易混对象 |
|---|---|---|---|
| architectural style | 架构风格 | family / vocabulary / constraints | pattern |
| architectural pattern | 架构模式 | recurring organization / element types | style |
| component | 构件 | runtime/software element | module |
| connector | 连接件 | interaction / communication | component |
| module structure | 模块结构 | code/data units | C&C structure |
| component-and-connector structure | 构件—连接件结构 | runtime behavior / interactions | module structure |
| allocation structure | 分配结构 | relate software to hardware/environment | module structure |
| view | 架构视图 | representation of concerns | viewpoint |
| viewpoint | 视点/视角约定 | conventions for constructing a view | view |
| reference architecture | 参考架构 | domain / high-level elements | application architecture |

## 考试第一动作

不要先翻译整段。先找是否同时出现 `component / connector / structure / architecture / view`。若两个以上同时出现，先把整段锁到“软件架构”知识域，再用中文定义排除相近选项。

## 易混边界

- `module` 更偏静态代码/数据单元，`component` 在很多架构语境更偏运行时元素；具体仍以题干定义为准。
- `pattern` 和 `style` 在不同教材中表达可能接近，考试时优先匹配题干给出的定义特征。
- 本篇不重讲架构风格分类；需要机制时回到软件架构设计知识域。
