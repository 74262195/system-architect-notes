# 定义题与定义信号

> [!info] 承接与定位
> 长句能拆开以后，最值得优先识别的是“这句话其实正在下定义”。历年专业英语常把中文已学定义换成英文，再让你从相近术语中选一个。

> [!summary]- 快速复习卡片（20～40 秒）
> - 定义信号：`is/are`、`is defined as`、`refers to`、`is the ... that`、`means`。
> - 先找“被定义对象”和“定义核心”，不要先翻修饰词。
> - 定义核心常是：**它是什么类别 + 它最关键的区别特征**。
> - 相近选项只看共有词会误选，必须对上区别特征。

## 一道具体英文问题

> The rule that keeps values linking related tables valid and consistent is called **( )**.

A. data compression  
B. referential integrity  
C. load balancing  
D. encapsulation

## 逐步判断

- **原句：** The rule that keeps values linking related tables valid and consistent is called ( ).
- **主语：** `The rule`
- **谓语：** `is called`
- **关键专业词：** `related tables`、`values linking`、`valid and consistent`
- **定义信号：** `is called`
- **中文知识映射：** 表之间通过主键/外键关联，约束关联值有效一致，对应“参照完整性”。
- **否定/条件/比较信号：** 无。
- **答案判断：** B `referential integrity`。

这里无需把每个词翻得很漂亮，只要抓住：

**related tables + linking values + valid/consistent → 参照完整性。**

## 四种常见定义外壳

| 英文外壳 | 做题时改写成 |
|---|---|
| X is defined as Y | “Y 是 X 的定义” |
| X refers to Y | “X 指的是 Y” |
| X is the ... that ... | “具有这些特征的东西叫 X” |
| ... is called X | “前面的描述对应 X” |

## 考试第一动作

先在定义句两边画线：

**术语名 ↔ 区别特征。**

如果空格在术语名位置，就拿区别特征去筛选；如果空格在定义内容位置，就反过来用术语名调用中文知识。

## 易混边界

- `availability`、`reliability`、`security` 都可能出现“system can...”句式，不能只看 `system`。
- `architectural style`、`pattern`、`view`、`viewpoint` 都属于架构语境，但定义核心不同。
- 选项里出现原句同词，不代表正确；考试经常用“同域近义词”制造干扰。
