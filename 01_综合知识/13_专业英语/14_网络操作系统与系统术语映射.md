# 网络、操作系统与系统术语映射

> [!info] 承接与定位
> 这一组词在综合知识里已经学过，但本轮可靠英语样本对它们的直接覆盖弱于架构和数据库，所以只保留“看到词先路由”的 P2 入口，不冒充高频。

> [!summary]- 快速复习卡片（20～40 秒）
> - protocol/routing/subnet/bandwidth → 网络。
> - process/thread/scheduling/deadlock → 操作系统。
> - cache/hit/miss → 存储层次与计算机组成。
> - 看到术语只负责定位，计算与机制回原中文章节。

## 最小例句

> A routing protocol determines how routing information is exchanged so that packets can be forwarded toward their destinations.

中文定位：routing protocol / packets / destinations 同时出现，先锁定**计算机网络—路由**。本章不重新讲路由算法。

## 最小术语路由表

| 英文题眼 | 中文定位 | 易混点 |
|---|---|---|
| protocol | 协议 | 不是某个具体端口 |
| routing | 路由 | switching 交换不完全等同路由 |
| subnet / subnet mask | 子网 / 子网掩码 | host address |
| bandwidth | 带宽 | throughput 实际吞吐量 |
| process | 进程 | thread 线程 |
| thread | 线程 | process 进程 |
| scheduling | 调度 | synchronization 同步 |
| deadlock | 死锁 | starvation 饥饿 |
| cache hit / miss | Cache 命中 / 未命中 | page fault 缺页不是同一层概念 |

## 考试第一动作

看到词后先回答：“它属于网络、操作系统还是计算机组成？”域锁定后，再调用前面章节里的中文机制。若题干同时出现多个域，例如 `network failure` + `failover`，再根据题目到底问通信还是可用性决定主知识域。

## 易混边界

- `bandwidth` 是链路/信道容量类概念，`throughput` 是实际达到的传输速率，题干可能故意混用。
- `concurrency` 是并发，既可出现在操作系统，也可出现在数据库事务；必须看 process/thread 还是 transaction/lock。
- `latency` 是延迟，可出现在网络、存储、系统性能多个语境，不能单词定域。
