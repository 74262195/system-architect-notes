# 函数依赖与属性闭包

> [!summary] 快速复习卡片
> - **核心结论**：`X → Y` 表示在这个关系语义中，X 的值能唯一确定 Y；属性闭包 X⁺ 是从 X 出发能推出的全部属性。
> - **做题入口**：求闭包时，从 X 开始，只要某条依赖左边已包含，就把右边加入，直到再也加不动。

函数依赖是**语义约束**，不能只看某一时刻表里“碰巧没有重复”就断定成立。

例如学号在业务规则上唯一对应学生姓名，可以写 `学号 → 姓名`。某天表里所有学生年龄刚好不同，并不能因此推出 `年龄 → 学号`。

## 闭包怎么求

给定属性集 X：

1. `X⁺` 先放入 X 自己；
2. 遍历函数依赖，如果某条依赖左边已经全部在 `X⁺` 中，就把右边加入；
3. 重复，直到没有新属性可以加入。

例：`F={A→B, B→D, D→E}`。

从 `{A}` 开始：`A → AB → ABD → ABDE`，所以 `A⁺={A,B,D,E}`。

Armstrong 三条基本公理先理解即可：自反、增广、传递；合并、分解、伪传递可以由它们推出。

## 真题怎么考

- 2020-H2-06：比较不同属性集的闭包是否等于全集，并据此判断候选码。
- 2022-H2-07：直接考 Armstrong 公理体系中的分解规则。

## 自测

> [!question]- 若 X⁺ 已包含关系的全部属性，X 就一定是候选码吗？
> 不一定。X 是超码；还要检查是否能删掉 X 中某个属性仍决定全部属性，只有最小超码才是候选码。
