# E-R 图转关系模式：实体和联系怎样落成表

> [!summary]- 快速复习卡片（学完再看）
> **作用/定位**：把全局 E-R 概念模型翻译为关系数据库可处理的关系模式，是逻辑结构设计的起点。
> **核心规则**：实体转表；1:1 可把对方码和联系属性并入一方，并用外码的唯一性保证最多对应一条；1:N 通常在 N 方放 1 方码；M:N 必须单独建联系关系。
> **题干信号 → 第一反应**：先判联系基数，再决定码和联系属性放在哪里。
> **易错点**：M:N 不能把多条对方编号塞进一个单元格；必须生成独立关系模式。

[[ER图合并与冲突]] 已经得到一张一致的全局 E-R 图，但它仍在描述业务世界。关系数据库不会直接存“学生选修课程”这句话，而是要知道有哪些关系模式、各自有哪些属性和码。

**转换的总原则是：每个实体先有自己的表；联系如何落表，取决于它是 1:1、1:N 还是 M:N。**

## 第一步：实体转关系模式

一个实体通常转换为一个关系模式：

| E-R 图中的内容 | 转换后 |
| --- | --- |
| 实体名 | 关系模式名 |
| 实体属性 | 关系属性 |
| 实体标识符 | 关系的码 |

例如“学生(学号, 姓名)”实体，转换为 `学生(学号, 姓名)`；其中学号是该关系的码。这里的“关系模式”是表结构定义，不能和某一时刻已经存进去的具体数据行混为一谈。

## 第二步：按联系基数处理

用“部门—员工”“学生—课程”贯穿判断：

| 联系 | 怎么落表 | 为什么 |
| --- | --- | --- |
| **1:1** | 通常不单建关系；可把联系并入任一方，加入另一方的码和联系属性 | 每边最多对应一条，合并后不会出现一方要保存多个对方码 |
| **1:N** | 通常并入 N 方；在 N 方加入 1 方的码和联系属性 | 每个 N 方记录只需指向一个 1 方记录 |
| **M:N** | 必须新建独立关系；放入两端实体的码和联系属性 | 任一方都可能对应多条对方记录，不能用一个字段装多值 |

例如：

- 一个部门有多名员工，每名员工属于一个部门：
  `部门(部门号, 部门名)` 与 `员工(员工号, 姓名, 部门号)`。部门号放到员工（N 方）中。
- 一个学校最多有一名正校长，一个正校长也只任职于一所学校：
  `学校(学校号, 学校名)` 与 `校长(校长号, 姓名, 学校号, 任职日)`。若业务规定每位校长都必须任职，且学校可以暂时没有正校长，可把联系放进 `校长`：`校长.学校号` 是引用 `学校.学校号` 的**非空外码**，并加 **UNIQUE**，从而每位校长恰好关联一所学校，而每所学校至多关联一位校长。`任职日` 是“任职”联系的属性，随联系并入校长关系；两张表原有主码不变。

也可在 `学校` 表放 `校长号` 外码并加 UNIQUE。此时若学校允许空缺，外码可空；若每所学校都必须有正校长，则还要设为非空。**放在哪边不是只看 1:1 基数：还要看哪边允许暂时没有关联对象、哪边必须参与，以及联系属性放置是否自然。**无论选哪边，外码都要唯一，才能阻止两条记录指向同一对象；非空只表达所放这一侧必须参与，不能单独强制另一侧也必须参与。
- 学生可选多门课，一门课也有多名学生：
  `学生(学号, 姓名)`、`课程(课程号, 课程名)`、`选课(学号, 课程号, 成绩)`。选课中的学号、课程号共同构成联系关系的码。

“成绩”属于学生与课程这一次选课，不属于学生本身，也不属于课程本身，所以应和两端码一起进入 `选课` 关系。

## 做题时的固定动作

1. 先列出实体各自的关系模式和码。
2. 圈出每条联系的基数：1:1、1:N 或 M:N。
3. 看联系有没有自己的属性，例如选课成绩、入职日期。
4. 按上表决定联系并到哪里；若是 M:N，直接新建关系模式。
5. 最后再进入 [[逻辑设计与完整性视图]]，检查规范化、完整性约束和用户视图。

> [!important] 不是“有联系就建一张表”
> 1:1、1:N 通常可并入现有关系；只有 M:N 的联系必须独立成关系模式。题目若给了联系属性，即使不新建表，也不能把它遗漏。

## 真题怎么考

题目常把“E-R 转换”换成外键放置或关系模式补全。第一步永远是识别联系基数：看到“一部门对应多员工”，把部门码放在员工一侧；看到双方都可有多个对方对象，建立独立联系关系。

## 自测

1. 部门 1:N 员工，部门号通常放在哪张表？

> [!answer]- 第 1 题答案与解析
> **答案**：员工表。
> **解析**：员工是 N 方；每名员工记录保存一个所属部门号即可。

2. 学生和课程是 M:N，且选课时有成绩，应该怎样转换？

> [!answer]- 第 2 题答案与解析
> **答案**：单独建 `选课(学号, 课程号, 成绩)`。
> **解析**：M:N 的每一端都可能对应多个对方对象；两端码共同标识一次选课，成绩描述这次联系。

3. 学校可以暂时没有正校长，但每位正校长必须只任职于一所学校。把联系放在 `校长` 表时，`学校号` 外码应有哪些关键约束？

> [!answer]- 第 3 题答案与解析
> **答案**：设为非空外码并加唯一约束。
> **解析**：非空保证每位校长都关联一所存在的学校；唯一保证同一学校号不能被多位校长重复引用。学校允许空缺，所以把外码放在 `学校` 表时则可允许空值；两种放置方式都需结合参与约束决定。
