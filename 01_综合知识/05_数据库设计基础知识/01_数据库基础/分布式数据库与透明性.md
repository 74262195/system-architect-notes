# 分布式数据库与透明性

> [!summary] 快速复习卡片
> **作用/定位**：分布式数据库把逻辑上统一的数据分散到多个场地保存和处理，同时尽量隐藏这种分布细节。
> **核心结论**：位置透明隐藏“存在哪里”；分片透明隐藏“怎样切分”；复制透明隐藏“复制了几份/在哪些节点”。
> **题干怎么认**：看到“用户无需知道物理位置”直接想到**位置透明**。
> **易错点**：透明性不是“数据真的没有分布”，而是对用户隐藏实现细节。

一套数据库为了靠近业务地点、扩展容量或提高可用性，可以把数据放在多个节点。问题是：如果用户每次查询都必须知道“这张表切成几片、哪片在哪台服务器、哪片有副本”，应用会非常复杂。

所以分布式数据库强调各种**透明性**：让用户尽可能像访问一个统一数据库那样使用它。

| 透明性 | 隐藏的细节 |
| --- | --- |
| 分片透明 | 逻辑关系被怎样拆成片段 |
| 位置透明 | 某份数据具体存放在哪个场地/节点 |
| 复制透明 | 数据是否有副本以及副本位于哪里 |
| 逻辑透明 | 局部系统的数据模型等差异尽量不暴露给用户 |

## 真题怎么考

- 2020-H2-08：直接问“用户无需知道数据存放的物理位置”是哪种透明性，答案入口就是**位置透明**。
- 2019-H2-08：考分布式数据库相对于集中式数据库增加的模式层次，说明考试不只会考“分布式数据库定义”，还会考其结构化实现概念。

## 和 NoSQL 的区别

“分布式数据库”描述的是数据跨节点组织与管理；“NoSQL”描述的是一大类非传统关系型数据模型/数据库产品。两者可以重叠，但不是同义词。
