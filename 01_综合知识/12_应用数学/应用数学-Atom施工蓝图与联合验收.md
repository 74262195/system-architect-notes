# 应用数学-Atom施工蓝图与联合验收

> [!info] G4-12-BUILD 施工蓝图
> 本轮先锁定范围和 Atom，再进入正文。大纲负责回答“必须覆盖什么”，教材/辅导资料负责回答“怎样算、怎样判断”。当前仓库未发现可直接读取的应用数学题干级真题，因此所有 Atom 的 `exam_priority` 暂记为 `待评估`，不凭印象标高频。

## 1. 大纲真实范围

考试大纲（第二版）PDF 62 明确列出：

1. 概率统计应用；
2. 图论应用；
3. 组合分析；
4. 算法的选择与应用：数值算法、非数值算法；
5. 运筹方法：网络计划技术、线性规划、预测、决策、库存管理、模拟；
6. 数学建模。

能力要求是“掌握应用数学的基础知识”。因此本轮不扩成大学概率论、图论、运筹学教材，也不因辅导资料出现某个算法名就擅自扩充大纲范围。

> [!warning] OCR 边界
> 大纲文本块由 OCR 辅助生成。本轮只用它锁定范围，不从断裂 OCR 恢复公式、数值或图形。公式采用最小、定义性表达；存在题干口径差异时正文明确使用条件。

## 4. 证据矩阵

- **范围最高证据：** 考试大纲（第二版）PDF 62。
- **图论/线性规划/决策的做题过程：** 《系统架构设计师考试32小时通关（第二版，2023）》第 24 小时“应用数学”；其中最小生成树、最大流、线性规划、决策论均有过程或练习。
- **网络计划：** 同一辅导资料项目管理部分提供网络图、最早/最迟时间与关键路径过程；大纲又明确把网络计划技术列入应用数学运筹方法。
- **概率统计、组合、预测、库存、模拟、数学建模：** 大纲锁定范围；本轮只写基础定义、最小计算或方法流程，不从 OCR 猜复杂公式。
- **真题：** 当前 `04_真题错题` 仅发现信息系统、操作系统和通用错题索引，没有应用数学题干级材料可直接核验，因此所有 Atom 的 `exam_priority` 保持 `待评估`。

## 5. 边界裁决

1. 不把“动态规划”单独提升为稳定 Atom；辅导资料虽出现该节，但大纲只明确要求数值/非数值算法的选择与应用。
2. 不把最短路径、最小生成树、最大流混成“图论算法大全”；各自保持独立主问题。
3. 库存管理本轮不擅自引入 EOQ 等未从当前证据稳定核对的公式。
4. 预测只在题目明确指定简单移动平均等方法时演示代入，不把某一种预测法冒充整个大纲范围。
5. 数学建模只教“现实 → 模型 → 求解 → 验证”的考试/工程动作，不展开高等数学证明。
