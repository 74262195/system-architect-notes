## 2. 题干关键词 → 题型动作

| 看到什么 | 先算什么 / 先做什么 |
| --- | --- |
| 或/至少一个、同时、不发生、已知…发生 | 并集、交集、补集、条件概率 |
| 多个离散结果 + 各自概率 + 期望/平均 | 列「结果—概率」表，算 $\sum x_ip_i$ |
| 平均水平、波动、稳定性 | 先分「问中心」还是「问离散」 |
| 一个点到另一个点最省 | 最短路径（边权须非负） |
| 全部站点连通、总建设成本最小 | 最小生成树（选 $n-1$ 条边、避环） |
| 容量、源点、汇点、最多通过多少 | 最大流（找增广路取瓶颈） |
| 选/排、职位、顺序是否重要 | 交换两个对象看结果是否改变 |
| 求数值近似/误差，还是求结构/次序/路径 | 数值算法 vs 非数值算法 |
| 任务依赖、工期、最早完成 | 网络计划正推最早时间 |
| 资源上限、收益最大或成本最小、各做多少 | 线性规划建模四件套 |
| 指定移动平均等方法预测下一期 | 按题目窗口算，不自行加数据 |
| 收益表 + 没有可靠状态概率 | 不确定型决策五准则 |
| 订货、持有、缺货成本 | 按题目口径比相关总成本 |
| 规则可描述、随机因素多、解析解难 | 模拟：重复运行后汇总指标 |
| 现实描述要变成变量、目标、约束 | 数学建模翻译闭环 |

## 3. 核心公式与流程

### 3.1 概率：并、交、补与条件概率
- 并集 $P(A\cup B)=P(A)+P(B)-P(A\cap B)$（「或/至少一个」先加再扣一次重复）；补集 $P(\bar A)=1-P(A)$。概率无单位，结果必须在 $0\sim1$。
- 条件概率 $P(A\mid B)=\dfrac{P(A\cap B)}{P(B)}$，适用条件 $P(B)>0$，含义是把样本空间缩到 $B$；互斥看 $P(A\cap B)=0$（不能同时发生），独立看 $P(A\cap B)=P(A)P(B)$（一个发生不改变另一个的概率），题目不给独立条件就不能相乘。
- 卡片例题：$P(A)=0.6$、$P(B)=0.5$、$P(A\cap B)=0.3$ → 至少一种 $0.6+0.5-0.3=0.8$；$P(A\mid B)=0.3/0.5=0.6$。

### 3.2 期望：加权平均，不是众数
$$E(X)=\sum_i x_i p_i$$
- $x_i$：第 $i$ 个可能结果，单位随结果（工时、收益点等）；$p_i$：对应概率，无单位。适用条件：构成完整分布，先检查 $\sum p_i=1$。若题干以乐观/最可能/悲观三个工期值给出，那是三点估算而不是概率期望，用 [[10_网络计划与关键路径]] 的 $E=(O+4M+P)/6$。
- 卡片例题：10、20、30 工时对应 0.2、0.5、0.3 → $10\times0.2+20\times0.5+30\times0.3=21$ 工时；20 只是最可能值（概率最大），不是期望。

### 3.3 均值、方差、标准差
- 均值 $\bar x=\dfrac{\sum x_i}{n}$，单位同原数据；总体方差 $\sigma^2=\dfrac{\sum(x_i-\bar x)^2}{n}$，单位是原数据单位的**平方**；标准差 $\sigma=\sqrt{\sigma^2}$，开方后单位回到原数据。题目写「样本方差」时分母口径可能是 $n-1$，不要与总体方差的 $n$ 混用。
- 卡片例题：2、4、6 ms 当作完整总体 → $\bar x=4$ ms，$\sigma^2=8/3\ \mathrm{ms^2}$，$\sigma\approx1.63$ ms。

### 3.4 最短路径：非负权逐轮确定
- 步骤：起点写 $0$、其余写 $\infty$ → 每轮选最小暂定距离点并确定 → 用「当前点距离 $+$ 边权」更新邻居 → 目标确定后回溯前驱得路径。适用条件：边权非负，出现负权边不要机械套用。
- 卡片例题：A-B=4、A-C=1、C-B=2、B-D=1、C-D=5 → 最短距离 **4**（单位与边权一致），路径 A→C→B→D。

### 3.5 最小生成树：选边且避免成环
- Kruskal：边按权升序 → 逐条试选 → 会成环就跳过 → 选满 $n-1$ 条边停止；Prim：从一点长树，每轮选连接「树内—树外」的最小边。适用条件与输出：全部节点连通且总边权最小，输出 $n-1$ 条边，不是某两点最短路径。
- 卡片例题：AB=1、BC=2、AC=3、BD=4、CD=5 → 选 $1+2+4$，跳过会成环的 AC(3)，总权 **7**（单位与边权一致）。

### 3.6 最大流：沿增广路累加
- 链条：在残量网络找 S→T 增广路 → 取该路径最小剩余容量（瓶颈）→ 沿正向边加流、沿反向边撤流 → 重复。
- 停止条件：**残量网络中找不到任何增广路**；「原图正向边看似断开」不够，源点总出容量只能当验算上界。
- 卡片例题：S→A=3、S→B=2、A→B=1、A→T=2、B→T=3 → 依次增广 2、2、1，最大流 **5**（单位与容量一致）。反向残量边表示撤销已送流量以改道，不代表原网络真有该反向边。

### 3.7 排列与组合
- 顺序（职位/身份）重要：$A_n^m=\dfrac{n!}{(n-m)!}$，如 $A_5^2=5\times4=20$；顺序不重要：$C_n^m=\dfrac{n!}{m!(n-m)!}$，如 $C_5^2=10$。
- 判断法：交换两个已选对象，结果变则排列、不变则组合；连续多阶段完成用乘法原理，互斥几类任选其一用加法原理；代入前检查 $m\le n$。

### 3.8 数值算法 vs 非数值算法
- 看**最终输出**：连续数值近似、误差控制、迭代 → 数值算法；结构、次序、查找、路径、关系 → 非数值算法。最短路径虽比较边权数字，处理对象是离散图结构，仍归非数值算法。

### 3.9 网络计划：正推最早时间与关键路径
$$E_j=\max_{i\to j}\left(E_i+d_{ij}\right)$$
- $E$：节点最早时间（天）；$d_{ij}$：活动工期（天）。起点 $E_S=0$；汇合节点取各前驱「最早时间 $+$ 工期」的**最大值**；终点最早时间即最早总工期。卡片例题：S→A=3、S→B=2、A→C=4、B→C=3、C→T=2 → $E_C=\max(3+4,\ 2+3)=7$，$E_T=9$ 天，关键路径 S→A→C→T。
- 关键路径＝决定总工期、没有可用机动时间的任务链；简单确定型网络中就是总工期最长的起点—终点路径，且**可能不止一条**。
- 三点估算（工期给乐观 $O$／最可能 $M$／悲观 $P$ 时）：$E=\dfrac{O+4M+P}{6}$；$E$ 不等于 $M$，算完用 $E$ 代替工期再走网络计划。
- 总时差 $=$ 最迟开始 $-$ 最早开始 $=$ 最迟完成 $-$ 最早完成；$=0$ 表示在关键路径上不能拖，$>0$ 就是"最多能拖延几天"的答案。逆推时终点最迟时间先取它的最早时间，往前减工期、分叉取最小值。
- 真题口径：2019 第 70 题（D 可延迟 2 天）、2021 第 70 题（C 期望 13 天、总时差 2 天 → 最多拖 2 天）。详见 [[10_网络计划与关键路径]]。

### 3.10 线性规划：建模四件套 + 顶点比较
- 四件套：决策变量（含单位）→ 目标函数（最大/最小）→ 约束条件（一条现实限制一条式）→ 非负/整数条件。卡片例题：$\max Z=3x+2y$，约束 $x+y\le4$、$x\le2$、$y\le3$、$x\ge0,\ y\ge0$；$x,y$ 单位「项」，$Z$ 单位「收益点」。
- 求顶点：边界两两联立求交点，再代回**全部**约束筛可行 → (0,0)、(2,0)、(2,2)、(1,3)、(0,3)，(2,3) 因 $x+y=5>4$ 剔除；目标值 0、6、**10**、9、6，最优 10 在 (2,2)。
- 适用条件：线性目标 + 凸可行域二维基础题；若最优解存在，至少一个顶点最优。

### 3.11 预测：简单移动平均
$$F_{t+1}=\frac{X_t+X_{t-1}+\cdots+X_{t-m+1}}{m}$$
- $F$：预测值；$X$：实际观测值；$m$：窗口期数（预测值单位同实际观测值）。适用条件：题目明确指定方法与窗口（本篇只演示简单移动平均）。卡片例题：最近 3 期 10、12、14 → $(10+12+14)/3=12$；新实际值出现后窗口前移，最老数据移出；加权移动平均权重不同，不能简单除以期数。

### 3.12 不确定型决策：同一张收益表五种准则
- 适用条件：知道各状态结果、但**没有可靠状态概率**；有概率时先考虑可算期望的风险型决策。
- 乐观：行最大 80/50/60，大中取大 → **A**；悲观：行最小 20/45/30，收益表小中取大 → **B**。
- 折中：$\text{折中值}=\alpha\times\text{最好}+(1-\alpha)\times\text{最坏}$，$\alpha=0.6$ 时 A=56、B=48、C=48 → **A**；等可能：平均 50/47.5/45 → **A**；后悔值：后悔值＝该状态最好收益 $-$ 本方案收益（S1 最好 80、S2 最好 60），A/B/C 最大后悔 40/30/50 → **B**。

### 3.13 库存：按题目口径比相关总成本
- 相关总成本＝题目列出的订货成本 $+$ 持有成本（缺货成本是否计入看题目口径）；订货频繁与平均库存高通常此消彼长。
- 卡片例题：A 为 $300+700=1000$，B 为 $500+400=900$ → 在「暂不考虑缺货差异」的同口径下选 **B**（成本单位随题目成本项）；本卡未收录 EOQ 等定量公式，题目给公式才用。

### 3.14 模拟：流程与状态更新
- 流程：明确问题与指标 → 抽象状态和规则 → 准备输入 → 重复运行 → 汇总指标 → 与现实/边界校验。状态更新：开始服务时刻＝到达时刻与上一请求完成时刻的**较晚者**。
- 卡片例题（第 0、1、3 分钟到达、每个服务 2 分钟）等待为 0、1、1，平均 $(0+1+1)/3=2/3$ 分钟；10 次运行 2 次超阈值 → $2/10=20\%$。适用条件：规则可描述、可重复运行、解析解困难；模拟结果是模型条件下的近似，不等于现实真值，也不自动保证最优。

### 3.15 数学建模：翻译闭环
- 闭环：明确目标 → 必要假设 → 定义变量和单位 → 目标/关系式 → 现实约束 → 选方法 → 求结果 → 回现实验证，不符合则改假设。卡片例题：$\min C=4x+7y$（元/小时），约束 $2x+4y\ge6$（vCPU）、$4x+8y\ge12$（GiB）、$100x+180y\ge280$（次/秒），$x,y\in\mathbb{Z}_{\ge0}$。
- 代 $x=1$、$y=1$ 得 6 vCPU、12 GiB、280 次/秒、11 元/小时：满足全部约束只是**可行方案**，代入一个点不能证明最优；模型 ≠ 算法 ≠ 答案。

## 4. 易错陷阱（为什么容易错）

1. **把最可能值当期望**：概率最大只说明它最可能出现，期望要把所有结果的数值乘概率再求和（得到 21），选它是选了众数。
2. **互斥当成独立**：互斥是「不能同时发生」，独立是「一个发生不改变另一个的概率」；把两者混同就会错误相乘。
3. **拿最短路径思路找关键路径**：工期由最慢的任务链决定，链越长越可能决定总工期，求「最短」正好反了；多条链并列最长时它们都是关键路径，只答一条会漏答案。
4. **凭直觉判断机动余量**：机动余量要用总时差算，等于「最迟开始 − 最早开始」（或「最迟完成 − 最早完成」），不能凭感觉；总时差为 0 的活动不能拖。公式与两道真题演算见 [[10_网络计划与关键路径]]。
5. **最大流用「正向边是否断开」判停**：反向残量边可能仍能改道，必须残量网络中也找不到增广路；源点出容量只是验算上界。
6. **把可行解当最优解**：满足约束只说明可行；先用全部约束筛掉 (2,3)，再比较剩下顶点的目标值。变量含义没锁定时，「最多 4」还容易写成 $\ge4$。
7. **总体方差与样本方差分母混用**：一个是 $n$、一个可能是 $n-1$，题目口径不同结果不同。
8. **把预测值当实际值**：预测是方法的输出；出现新数据后窗口要前移，滑出的旧数据不能再算进去。

## 5. 高频对比

**① 最短路径 / 最小生成树 / 最大流**

| 对比项 | 最短路径 | 最小生成树 | 最大流 |
| --- | --- | --- | --- |
| 优化目标与输出 | 指定两点路径代价最小，输出路线+距离 | 全部节点连通、总边权最小，输出 $n-1$ 条边 | 源点到汇点总通过量最大，输出一个总流量值 |
| 关键条件 | 边权非负 | 连通且避免成环 | 边上是容量上限，需残量网络 |
| 停止/验算 | 目标点被确定 | 已选满 $n-1$ 条边 | 残量网络无增广路 |

**② 不确定型决策五准则（同一张收益表）**

| 准则 | 每行先看什么 | 再取什么 | 本题选择 |
| --- | --- | --- | --- |
| 乐观 | 最大收益 | 大中取大 | A |
| 悲观 | 最小收益 | 小中取大 | B |
| 折中（$\alpha=0.6$） | 最好/最坏加权 | 取最大折中值 | A |
| 等可能 | 平均收益 | 取最大 | A |
| 后悔值 | 该状态最好 $-$ 本方案 | 最大后悔中取最小 | B |

**③ 线性规划 vs 整数规划**

| 对比项 | 线性规划 | 题干要求「整项/整台」时 |
| --- | --- | --- |
| 变量取值 | 连续 | 非负整数 |
| 卡片例子与风险 | 任务数量连续，最优 (2,2) | 实例只能整台开通，$x,y\in\mathbb{Z}_{\ge0}$；漏整数条件会算出无法开通的「半台实例」 |

**④ 方差 vs 标准差；排列 vs 组合**

| 对比项 | 方差 $\sigma^2$ | 标准差 $\sigma$ | 排列 $A_n^m$ | 组合 $C_n^m$ |
| --- | --- | --- | --- | --- |
| 关键差别 | 单位是原数据的平方 | 单位与原数据相同，$\sigma=\sqrt{\sigma^2}$ | 顺序/身份重要，交换后是新结果 | 顺序不重要，交换后仍是同一结果 |
| 卡片例子 | $8/3\ \mathrm{ms^2}$ | $\approx1.63$ ms | $A_5^2=20$ | $C_5^2=10$ |

## 7. 闭卷自测

1. 「至少一个」「同时」「不发生」「已知 B 发生」分别对应哪种概率关系与公式？
2. 给出概率 0.2/0.5/0.3 下 10、20、30 三个结果，为什么答案不是 20？
