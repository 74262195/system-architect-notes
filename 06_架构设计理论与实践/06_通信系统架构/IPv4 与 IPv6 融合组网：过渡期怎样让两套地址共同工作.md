# IPv4 与 IPv6 融合组网：过渡期怎样让两套地址共同工作

> [!summary]- 快速复习卡片（学完再看）
> **核心结论**：过渡期常用双栈、隧道和地址翻译；选什么取决于两端能力与是否必须互通。
> **题干信号 → 第一反应**：设备同时支持两套协议 → 双栈；要穿过不支持新协议的网络 → 隧道；两套地址族直接互访 → 翻译。

IPv4 不能一夜替换，IPv6 也不能只在一小段网络中孤立运行。**融合组网是在共存期让 IPv4 与 IPv6 按条件共同提供连接，常见办法是双协议栈、隧道和地址翻译。**

双栈让节点同时运行两套协议；隧道把一种协议包进另一种网络中穿越；地址翻译在两类地址之间转换。它们解决的问题不同，不能把“有 IPv6”直接等同于“所有旧业务自动可达”。

## 考试怎么判断

先看两端是否都能运行 IPv6：能同时支持就先想双栈；中间网络不支持时想隧道；需要 IPv4 与 IPv6 主机直接沟通时想翻译。

## 自测

1. 两端要用 IPv6 通信，中间仍是 IPv4 网络，优先识别什么过渡思路？

> [!answer]- 第 1 题答案与解析
> **答案**：隧道技术。
> **解析**：它让 IPv6 流量借 IPv4 网络穿越；不是把两端改成只用 IPv4。
