# IPv4 与 IPv6 融合组网：过渡期怎样让两套地址共同工作

> [!summary]- 快速复习卡片（学完再看）
> **核心结论**：过渡期常用双栈、隧道和地址翻译；选什么取决于两端能力与是否必须互通。
> **题干信号 → 第一反应**：设备同时支持两套协议 → 双栈；要穿过不支持新协议的网络 → 隧道；两套地址族直接互访 → 翻译。

IPv4 不能一夜替换，IPv6 也不能只在一小段网络中孤立运行。假设园区里的新终端要访问旧服务器，沿途可能遇到同时支持两种协议的设备、只懂 IPv4 的骨干网，或只提供 IPv4 服务的服务器。**融合组网要根据卡点选择办法：两端和沿途都能处理同一种协议就直接转发；中间网络只懂另一种协议就封装穿越；两端地址族不同且需要互通就经地址转换设备衔接。**

### 同一访问目标的三种报文走法

以下是帮助理解的教学例子。三种方式都为了让终端访问业务，但报文经过网络时做的事不同。

| 网络条件 | 报文怎样走 | 能解决什么，边界在哪里 |
| --- | --- | --- |
| 终端、服务器和相关网络设备都支持 IPv4 与 IPv6 | 双栈节点各自运行 IPv4 和 IPv6 协议栈；本次通信选定一种地址族后，报文按该协议经路由转发到同样能处理该协议的对端。 | 两端可分别服务 IPv4 与 IPv6 通信；双栈本身不负责把一台纯 IPv6 主机发出的报文自动变成 IPv4。 |
| 两端要用 IPv6，但中间骨干网只转发 IPv4 | 隧道入口把完整的 IPv6 报文封装进 IPv4 报文；中间设备只根据外层 IPv4 地址把它送到隧道出口；出口去掉外层 IPv4 封装，再按原 IPv6 报文继续转发。 | 两个隧道端点之间的 IPv4 网络只需能转发外层报文；隧道端点之间必须有 IPv4 可达性。中间普通 IPv4 设备不会因此学会解析内层 IPv6。 |
| 终端只用 IPv6，旧服务器只用 IPv4 | 地址转换设备按照配置的地址映射，把通信一侧的 IPv6 地址与另一侧可用的 IPv4 地址对应起来，并维护映射关系；请求转换后按 IPv4 转发到服务器，返回流量再按对应关系转换回来。 | 解决两种地址族之间的衔接；它需要转换设备和有效映射，不能与“把原报文套进外层包头”的隧道混为一谈。 |

因此先问清楚卡点：是端点协议能力不同，还是只有中间承载网络不支持目标协议。前者考虑翻译，后者考虑隧道；双方都具备两套栈时才可直接按双栈通信。具体技术名称、部署条件和教材中的历史方案以题目语境为准。

## 考试怎么判断

题干若给出“节点同时支持两套协议”，先判断双栈；若给出“IPv6 报文要经过 IPv4 网络”，先判断隧道，并检查是否有能封装/解封装的端点及 IPv4 可达性；若两端分别是纯 IPv4 与纯 IPv6、要求互访，先判断是否有地址转换设备和映射。先认清报文在哪一段、使用哪种地址族，再选技术，不因题干只出现“升级 IPv6”就直接选隧道。

## 自测

1. 两端要用 IPv6 通信，中间仍是 IPv4 网络，优先识别什么过渡思路？

> [!answer]- 第 1 题答案与解析
> **答案**：隧道技术。
> **解析**：它让 IPv6 流量借 IPv4 网络穿越；不是把两端改成只用 IPv4。

2. 一台纯 IPv6 终端要访问一台纯 IPv4 服务器，只有双栈终端但没有地址转换设备，能否据此认定两者已互通？

> [!answer]- 第 2 题答案与解析
> **答案**：不能。
> **解析**：双栈表示同一节点运行两套协议栈，不会自动把纯 IPv6 端的报文转换为 IPv4；还需满足题设要求的互通机制，例如配置了地址映射的转换设备。
